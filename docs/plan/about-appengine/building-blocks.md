## Building blocks

The user interface of a Dynatrace App is written as a React single-page application and uses TypeScript to enhance the developer experience. The Dynatrace platform provides an extensive toolkit to make the life of an app developer as easy as possible:

- The [**Strato Design System**](https://developer.dynatrace.com/contents/docs/design/about-strato-design-system.md/) and design tokens provide fundamental and customizable UI components.
- [**TypeScript SDKs**](https://developer.dynatrace.com/contents/docs/develop/sdks/index.md/) allow Apps to interact with the [Dynatrace platform services](https://developer.dynatrace.com/develop/platform-services.md) (querying data, document service, state service, etc.).
- [**App functions**](https://developer.dynatrace.com/develop/guides/app-functions.md) as backend for your App, which are written in TypeScript and run within the [Dynatrace JavaScript runtime](https://developer.dynatrace.com/contents/docs/develop/reference/javascript-runtime.md/).
- The [**App Toolkit**](https://developer.dynatrace.com/quickstart/app-toolkit.md) allows you to easily create, build, and deploy both apps and their functions.
