The `AutomationSelect` component allows you to choose one or more options from a collapsed dropdown menu. When used to create an action, it also allows you to switch to expression mode, which displays an [`AutomationTextInput`](https://developer.dynatrace.com/develop/reference/react-components/automation-action/AutomationTextInput.md) for entering a dynamic [expression](https://dt-url.net/workflows-expression-reference).
