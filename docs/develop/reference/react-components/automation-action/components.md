## Components

| Component                                                                                                                                        | Description                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AutomationConnectionPicker](https://developer.dynatrace.com/develop/reference/react-components/automation-action/AutomationConnectionPicker.md) | Allows the user to select a connection (settings object) for third party system connection details, connection selection by workflow expression, links to create/edit a connection and user feedback about connection availability. |
| [AutomationTextInput](https://developer.dynatrace.com/develop/reference/react-components/automation-action/AutomationTextInput.md)               | Text input with workflow expression support. There's no dedicated expression mode; workflow expression support is inline.                                                                                                           |
| [AutomationNumberInput](https://developer.dynatrace.com/develop/reference/react-components/automation-action/AutomationNumberInput.md)           | Numeric input with workflow expression support.                                                                                                                                                                                     |
| [AutomationSelect](https://developer.dynatrace.com/develop/reference/react-components/automation-action/AutomationSelect.md)                     | Dropdown select with workflow expression support.                                                                                                                                                                                   |
| [AutomationCodeEditor](https://developer.dynatrace.com/develop/reference/react-components/automation-action/AutomationCodeEditor.md)             | Code editor with workflow expression support. There's no dedicated expression mode; workflow expression support is inline.                                                                                                          |
