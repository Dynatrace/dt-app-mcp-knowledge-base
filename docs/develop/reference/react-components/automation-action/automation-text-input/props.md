## Props

**`AutomationTextInputProps`**

| Prop          | Type                      | Default | Description                                         |
| ------------- | ------------------------- | ------- | --------------------------------------------------- |
| `value`       | `string`                  | `''`    | The content of the input.                           |
| `onChange`    | `(value: string) => void` |         | Callback that is called when the value changes.     |
| `placeholder` | `string`                  |         | Initially displayed when there is no other content. |
