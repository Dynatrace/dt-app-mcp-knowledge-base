The purpose of these React components is the implementation of automation action widgets for workflow task configuration. The automation components support specific functionality when these widgets are rendered in the Workflows app for workflow editing, like [expression](https://dt-url.net/workflows-expression-reference) mode, [expression](https://dt-url.net/workflows-expression-reference) auto-completion, and [expression](https://dt-url.net/workflows-expression-reference) chip rendering.
