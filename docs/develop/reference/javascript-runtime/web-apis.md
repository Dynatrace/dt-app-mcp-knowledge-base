## Web APIs

Web APIs are fundamental building blocks when writing web applications. Below is a list of all the APIs and interfaces (object types) available within the Dynatrace JavaScript runtime. To learn more about these APIs, visit [Web API docs on MDN](https://developer.mozilla.org/en-US/docs/Web/API).

> **Caution**
>
> Deprecated properties of Web APIs might not be supported.
