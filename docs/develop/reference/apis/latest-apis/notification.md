### Notification

**[Notification](https://wkf10640.apps.dynatrace.com/platform/swagger-ui/index.html?urls.primaryName=Notification)**: Manage self notifications with the Notification Service API. This API was deprecated on 9 Jul 2025 and will be sunset on 31 Dec 2026. Use the event notifications API provided in the Notification Service v2 instead.

**[Notification v2](https://wkf10640.apps.dynatrace.com/platform/swagger-ui/index.html?urls.primaryName=Notification+v2)**: Manage resource/event notifications with the Notification Service API.
