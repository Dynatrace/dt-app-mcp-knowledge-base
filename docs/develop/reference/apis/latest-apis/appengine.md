### AppEngine

**[AppEngine - App Functions](https://wkf10640.apps.dynatrace.com/platform/swagger-ui/index.html?urls.primaryName=AppEngine+-+App+Functions)**: The App Functions API is responsible for triggering server-side functions of installed Dynatrace apps.

**[AppEngine - EdgeConnect](https://wkf10640.apps.dynatrace.com/platform/swagger-ui/index.html?urls.primaryName=AppEngine+-+EdgeConnect)**: The EdgeConnect API manages EdgeConnect configurations that specify which HTTP requests matching what URL host patterns will be forwarded to and executed by that EdgeConnect.

**[AppEngine - Function Executor](https://wkf10640.apps.dynatrace.com/platform/swagger-ui/index.html?urls.primaryName=AppEngine+-+Function+Executor)**: The Function Executor API is responsible for executing custom JavaScript code in the Dynatrace JavaScript runtime.

**[AppEngine - Registry](https://wkf10640.apps.dynatrace.com/platform/swagger-ui/index.html?urls.primaryName=AppEngine+-+Registry)**: The Registry is responsible for installing, updating, uninstalling apps and getting detailed app information.
