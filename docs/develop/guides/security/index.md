When developing Dynatrace Apps you should consider all kind of security aspects from the very beginning. This section provides you with guides to make sure your app is not affected by security vulnerabilites, it is only using a minimal set of permissions and secrets are handled correctly.

- [Add permission scopes to use Dynatrace APIs](https://developer.dynatrace.com/develop/guides/security/add-permission-scopes-to-use-dynatrace-apis.md): Add permission scopes to your Dynatrace App configuration.
- [Configure CSP rules](https://developer.dynatrace.com/develop/guides/security/configure-csp-rules.md): Information about Content Security Policy (CSP) rules within Dynatrace Apps
- [Manage secrets](https://developer.dynatrace.com/develop/guides/security/manage-secrets.md): Best practices to manage secrets in Dynatrace Apps for accessing external services
- [Manage dependencies for third-party libraries](https://developer.dynatrace.com/develop/guides/security/manage-third-party-library-dependencies.md): Best practices for using third-party libraries
- [Query user permissions](https://developer.dynatrace.com/develop/guides/security/query-user-permissions.md): Query user permissions in your Dynatrace App.
