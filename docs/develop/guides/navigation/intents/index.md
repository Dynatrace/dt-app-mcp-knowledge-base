We use the intents mechanism to **extend an app's functionality**. An intent is a message object you define in an app that allows you to pass the user flow from one app to another.

Discover more about how to **send, receive,** and **debug** intents in Dynatrace apps. Plus, explore relevant use cases and examples on this topic.

- [About intents](https://developer.dynatrace.com/develop/guides/navigation/intents/about-intents.md): Learn how intents enable context-aware cross-app navigation in Dynatrace, including explicit intents, add-ons, and the Open with dialog.
- [Add-on intents](https://developer.dynatrace.com/develop/guides/navigation/intents/addon-intents.md): Implement add-on intents for quick tasks in your app.
- [Debug intents](https://developer.dynatrace.com/develop/guides/navigation/intents/debug-intents.md): Debug your intents using AppShell methods.
- [Receive intents](https://developer.dynatrace.com/develop/guides/navigation/intents/receive-intents.md): Receive intents with data that trigger actions in your app.
- [Send intents](https://developer.dynatrace.com/develop/guides/navigation/intents/send-intents.md): Send intents from your app to a receiving app.
