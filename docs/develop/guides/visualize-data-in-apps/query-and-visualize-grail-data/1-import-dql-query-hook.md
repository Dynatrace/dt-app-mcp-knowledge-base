### 1. Import DQL query hook

Import the `useDql` hook from the `@dynatrace-sdk/react-hooks` package in your React component.

```ts testable
import { useDql } from '@dynatrace-sdk/react-hooks';
```

> **Tip**
>
> Alternatively, you can use the `queryExecutionClient` from the `@dynatrace-sdk/client-query` package. To learn more, visit [Storage – Query Service](https://developer.dynatrace.com/contents/docs/develop/sdks/client-query/index.md/#queryexecutionclient).
