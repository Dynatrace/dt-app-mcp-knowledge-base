## 1. Create the key binding

A shortcut or `keyBinding` consists of [modifiers](https://developer.dynatrace.com/develop/guides/keyboard-shortcuts.md#available-modifiers) and a [key](https://developer.dynatrace.com/develop/guides/keyboard-shortcuts.md#available-keys). It can have a single key and any number of modifiers. Some examples are `Control+k`, `Shift+/`, and `Control+Shift+m`.

First, create a `keyBinding` for your app based on actual shortcuts.
