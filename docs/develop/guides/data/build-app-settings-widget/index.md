Give your app's users a settings form. The form renders inside the app and as a widget in **Settings**, the same component handles both, writing the UI once. The form uses the app settings React hooks from `@dynatrace-sdk/react-hooks`, which is already part of the app template and is built on the `@dynatrace-sdk/client-app-settings-v2` SDK. You must add the `app-settings:objects:read` and `app-settings:objects:write` scopes to your app.
