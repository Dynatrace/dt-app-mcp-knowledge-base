## Install the latest version

First, ensure you're using the latest version of App Toolkit before troubleshooting. The latest version is available at the public [npm](https://www.npmjs.com/package/dt-app) registry.

You should also ensure you're using a Node.js version officially supported by the App Toolkit (usually the latest LTS version of Node.js). App Toolkit will warn you if you use a Node.js version that's not officially supported with the following message:

```bash
dt-app is operating in an unofficially supported Node.js environment.
To prevent potential issues, it's recommended to utilize the app with Node.js ${majorNode.jsVersion}.
```

If you see this message, adjust the version of your Node.js environment accordingly.
