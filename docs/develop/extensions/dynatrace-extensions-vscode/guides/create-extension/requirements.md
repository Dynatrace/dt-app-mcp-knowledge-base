## Requirements

You'll need the following:

- [Visual Studio Code](https://code.visualstudio.com/download) with the [Extensions Add-On](https://developer.dynatrace.com/develop/extensions/dynatrace-extensions-vscode.md) installed and configured.
- [Python 3.10](https://www.python.org/downloads/)
- [dt-extensions-sdk](https://pypi.org/project/dt-extensions-sdk/)
- Dynatrace 1.286+
