## Visualize data

For now, we're only sending metric data points to Dynatrace.

We can visualize these metrics via `Dashboards`, `Notebooks` or the `Metric Explorer`:

![dashboards](https://developer.dynatrace.com/assets/images/python-tutorial-dashboards-e5975a5d1dfee537809b20cdab2eaf8a.png)

![notebooks](https://developer.dynatrace.com/assets/images/python-tutorial-notebooks-ed487d4f18702962a388108da0c67830.png)

![metric explorer](https://developer.dynatrace.com/assets/images/python-tutorial-metric-explorer-c3d6300f79e9b23ad637545a49605b30.png)

A full fledged extension would include dashboards, topology, screens, and more.
For the complete code example, visit [RabbitMQ extension on GitHub](https://github.com/dynatrace-extensions/python-rabbitmq).
For more information about extending Dynatrace, visit [Extend Dynatrace documentaion](https://docs.dynatrace.com/docs/shortlink/section-extend-dynatrace).
