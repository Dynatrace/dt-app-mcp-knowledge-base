**Dynatrace Extensions** is an add-on for Visual Studio Code that supports all aspects of developing Extensions 2.0 running on Dynatrace. Find it by searching the [VS Code extensions marketplace](https://marketplace.visualstudio.com/items?itemName=DynatracePlatformExtensions.dynatrace-extensions).

It gives you access to a specialized toolkit that's ready to use and helps you out with the following:

1. Operational efficiency
2. Content creation
3. Content validation

Check out the instructions for [getting started](https://developer.dynatrace.com/develop/extensions/dynatrace-extensions-vscode/getting-started.md), or keep reading to learn some of its features.
