**Dynatrace Extensions** runs as a NodeJS application within VS Code's runtime, coexisting with all other extensions installed in your editor. The application will always start along with your editor, regardless of whether you're working on an extensions project. This behavior makes for quite a complex environment that may not consistently execute normal features as planned.

Continue reading to see how you can troubleshoot when the extension isn't running as expected and how you can reach out if you need further support.
