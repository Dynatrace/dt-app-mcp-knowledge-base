All Dynatrace platform service APIs are [semantically versioned](https://semver.org/) with this format:

```text
<Major>.<Minor>.<Patch>
```

> **Note**
>
> Only the **Major** version is visible on the service [URL path](https://developer.dynatrace.com/develop/platform-services/core-concepts.md#url-structure) and the [SDK name](https://developer.dynatrace.com/develop/platform-services/core-concepts.md#sdk).
