### ActiveGateTokenEnforcement

The status of ActiveGate tokens enforcement.

| Name                      | Type                  | Description                                                 |
| ------------------------- | --------------------- | ----------------------------------------------------------- |
| autoEnforced              | boolean               | If `true`, ActiveGate tokens are enforced automatically.    |
| autoEnforcementEstimation | [Duration](#duration) | Defines a period of time.                                   |
| manualEnforced            | boolean               | If `true`, ActiveGate tokens are manually enforced by user. |
