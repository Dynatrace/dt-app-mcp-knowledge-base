### TrackingLinkUpdate

External tracking link URL association to be set for the remediable entity of the security problem.

| Name                   | Type   | Description                                                                                                                                                                                               |
| ---------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| displayName (required) | string | The desired tracking link display name (title) set for the remediation item, e.g. 'ISSUE-123'.                                                                                                            |
| url (required)         | string | The desired tracking link url set for the remediation item, e.g. [https://example.com/ISSUE-123](https://example.com/ISSUE-123) Note that only valid URLs with 'http' or 'https' protocols are supported. |
