### SyntheticOnDemandTriggeredMonitor

Contains the list of on-demand executions of the monitor.

| Name                  | Type                                                                                              | Description                       |
| --------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------- |
| executions (required) | Array\<[SyntheticOnDemandTriggeredExecutionDetails](#syntheticondemandtriggeredexecutiondetails)> | The list of triggered executions. |
| monitorId (required)  | string                                                                                            | The monitor identifier.           |
