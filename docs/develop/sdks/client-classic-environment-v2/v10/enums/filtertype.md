- `eq`,
- `ne`,
- `prefix`,
- `in`,
- `remainder`,
- `suffix`,
- `contains`,
- `existsKey`,
- `series`,
- `or`,
- `and`,
- `not`,
- `ge`,
- `gt`,
- `le`,
- `lt`,
- `otherwise`.
