### EntityIcon

The icon of a monitored entity.

| Name              | Type           | Description                                                                                                                      |
| ----------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| customIconPath    | null \| string | The user-defined icon of the entity. Specify the [barista](https://dt-url.net/u403suy) ID of the icon or a URL of your own icon. |
| primaryIconType   | string         | The primary icon of the entity. Specified by the [barista](https://dt-url.net/u403suy) ID of the icon.                           |
| secondaryIconType | null \| string | The secondary icon of the entity. Specified by the [barista](https://dt-url.net/u403suy) ID of the icon.                         |
