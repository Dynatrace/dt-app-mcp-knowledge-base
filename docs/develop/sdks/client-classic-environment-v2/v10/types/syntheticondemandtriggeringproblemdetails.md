### SyntheticOnDemandTriggeringProblemDetails

Contains the details of problems encountered while triggering on-demand executions.

| Name                   | Type           | Description                         |
| ---------------------- | -------------- | ----------------------------------- |
| cause (required)       | string         | The cause of not triggering entity. |
| details (required)     | null \| string | The details of triggering problem.  |
| entityId (required)    | null \| string | The entity identifier.              |
| executionId (required) | null \| string | The execution identifier.           |
| locationId             | null \| string | The location identifier.            |
