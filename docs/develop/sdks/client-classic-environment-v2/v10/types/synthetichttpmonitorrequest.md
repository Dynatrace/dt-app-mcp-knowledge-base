### SyntheticHttpMonitorRequest

Http monitor's settings.

| Name                                   | Type                                                                                              | Description                                                                                                                                                                                                                          |
| -------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| advancedSettings                       | null \| [SyntheticHttpMonitorAdvancedDto](#synthetichttpmonitoradvanceddto)                       | Http monitor's settings.                                                                                                                                                                                                             |
| cookies                                | null \| Array\<null \| [SyntheticMonitorCookieDto](#syntheticmonitorcookiedto)>                   | The cookies of the monitor.                                                                                                                                                                                                          |
| description                            | null \| string                                                                                    | Monitor description                                                                                                                                                                                                                  |
| enabled                                | boolean                                                                                           | If true, the monitor is enabled.<br /><br />**Default:** `true`                                                                                                                                                                      |
| externalId                             | null \| string                                                                                    | Stable identifier used by configuration-as-code tools (such as Monaco) to manage this monitor across environments. Unique per environment.                                                                                           |
| frequencyMin                           | null \| number                                                                                    | The frequency of the monitor, in minutes. Default value depends on the monitor type (1 minute for MULTI_PROTOCOL and HTTP, 15 minutes for BROWSER).                                                                                 |
| locations (required)                   | Array\<string>                                                                                    | The locations to which the monitor is assigned.                                                                                                                                                                                      |
| manuallyAssignedEntities               | null \| Array\<null \| string>                                                                    | Manually assigned entities.                                                                                                                                                                                                          |
| name (required)                        | string                                                                                            | The name of the monitor.                                                                                                                                                                                                             |
| performanceThresholds                  | null \| [SyntheticMonitorPerformanceThresholdsDto](#syntheticmonitorperformancethresholdsdto)     | Performance thresholds configuration.                                                                                                                                                                                                |
| primaryGrailTags                       | null \| Array\<null \| [SyntheticMonitorPrimaryGrailTagDto](#syntheticmonitorprimarygrailtagdto)> | Primary Grail tags as a list of key-value pairs. Up to 10 tags. Those fields are only available for SaaS and not for Managed.                                                                                                        |
| steps (required)                       | Array\<[SyntheticHttpMonitorStepDto](#synthetichttpmonitorstepdto)>                               | The steps of the monitor.                                                                                                                                                                                                            |
| syntheticMonitorOutageHandlingSettings | null \| [SyntheticMonitorOutageHandlingSettingsDto](#syntheticmonitoroutagehandlingsettingsdto)   | Outage handling configuration.                                                                                                                                                                                                       |
| tags                                   | null \| Array\<null \| [SyntheticTagWithSourceDto](#synthetictagwithsourcedto)>                   | A set of tags assigned to the monitor. You can specify only the value of the tag here and the `CONTEXTLESS` context and source 'USER' will be added automatically. But preferred option is usage of SyntheticTagWithSourceDto model. |
| type (required)                        | "BROWSER" \| "HTTP" \| "MULTI_PROTOCOL"                                                          | Monitor type.                                                                                                                                                                                                                        |
