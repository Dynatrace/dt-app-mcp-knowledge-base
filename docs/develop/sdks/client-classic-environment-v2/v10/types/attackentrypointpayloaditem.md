### AttackEntrypointPayloadItem

A list of values that has possibly been truncated.

| Name           | Type                                            | Description                           |
| -------------- | ----------------------------------------------- | ------------------------------------- |
| truncationInfo | [TruncationInfo](#truncationinfo)               | Information on a possible truncation. |
| values         | Array\<[EntrypointPayload](#entrypointpayload)> | Values of the list.                   |
