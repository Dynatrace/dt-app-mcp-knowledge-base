### UpdateJobList

A list of update jobs of the ActiveGate.

| Name       | Type                            | Description                                                    |
| ---------- | ------------------------------- | -------------------------------------------------------------- |
| agId       | string                          | The ID of the ActiveGate.<br /><br />**Example:** `0x3efdd092` |
| updateJobs | Array\<[UpdateJob](#updatejob)> | A list of update jobs of the ActiveGate.                       |
