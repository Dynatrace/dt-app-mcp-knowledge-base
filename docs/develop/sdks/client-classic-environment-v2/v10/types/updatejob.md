### UpdateJob

Configuration of the ActiveGate update job.

| Name                     | Type                                                                                           | Description                                                                                                                                                                                                                         |
| ------------------------ | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| agType                   | null \| "CLUSTER" \| "ENVIRONMENT" \| "ENVIRONMENT_MULTI"                                     | The type of the ActiveGate.<br /><br />**Example:** `ENVIRONMENT`                                                                                                                                                                   |
| cancelable               | null \| boolean                                                                                | The job can (`true`) or can't (`false`) be cancelled at the moment.<br /><br />**Example:** `false`                                                                                                                                 |
| duration                 | null \| number                                                                                 | The duration of the update, in milliseconds.<br /><br />**Example:** `3608000`                                                                                                                                                      |
| environments             | Array\<null \| string>                                                                         | A list of environments (specified by IDs) the ActiveGate can connect to.                                                                                                                                                            |
| error                    | null \| string                                                                                 | The information about update error.                                                                                                                                                                                                 |
| jobId                    | string                                                                                         | The ID of the update job.<br /><br />**Example:** `-3524498778810258605`                                                                                                                                                            |
| jobState                 | "SCHEDULED" \| "PENDING" \| "FAILED" \| "IN_PROGRESS" \| "ROLLBACK" \| "SKIPPED" \| "SUCCEED" | The status of the update job.<br /><br />**Example:** `SUCCEED`                                                                                                                                                                     |
| startVersion             | null \| string                                                                                 | The initial version of the ActiveGate.<br /><br />**Example:** `1.185.0.20200201-120000`                                                                                                                                            |
| targetVersion (required) | null \| string                                                                                 | The target version of the update. Specify the version in the `<major>.<minor>.<revision>.<timestamp>` format. To update to the latest available version, use the `latest` value. <br /><br />**Example:** `1.190.0.20200301-130000` |
| timestamp                | null \| number                                                                                 | The timestamp of the update job completion. The `null` value means the job is still running. <br /><br />**Example:** `1582031917814`                                                                                               |
| updateMethod             | null \| "AUTOMATIC" \| "MANUAL_INSTALLATION" \| "ON_DEMAND"                                  | The method of updating the ActiveGate or its component.<br /><br />**Example:** `AUTOMATIC`                                                                                                                                         |
| updateType               | "SYNTHETIC" \| "ACTIVE_GATE" \| "REMOTE_PLUGIN_AGENT" \| "Z_REMOTE"                        | The component to be updated.<br /><br />**Example:** `ACTIVE_GATE`                                                                                                                                                                  |
