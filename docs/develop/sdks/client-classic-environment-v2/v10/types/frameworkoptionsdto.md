### FrameworkOptionsDto

JS framework options of a JS Agent.

| Name          | Type            | Description                                                                           |
| ------------- | --------------- | ------------------------------------------------------------------------------------- |
| activeXObject | null \| boolean | activeXObject support. If not defined in request, it will be set to false by default. |
| angular       | null \| boolean | Angular support. If not defined in request, it will be set to false by default.       |
| dojo          | null \| boolean | Dojo support. If not defined in request, it will be set to false by default.          |
| extJs         | null \| boolean | extJs support. If not defined in request, it will be set to false by default.         |
| icefaces      | null \| boolean | icefaces support. If not defined in request, it will be set to false by default.      |
| jQuery        | null \| boolean | jquery support. If not defined in request, it will be set to false by default.        |
| mooTools      | null \| boolean | mooTools support. If not defined in request, it will be set to false by default.      |
| prototype     | null \| boolean | prototype support. If not defined in request, it will be set to false by default.     |
