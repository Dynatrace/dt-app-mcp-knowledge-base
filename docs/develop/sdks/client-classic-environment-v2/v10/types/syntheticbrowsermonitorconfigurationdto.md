### SyntheticBrowserMonitorConfigurationDto

Browser Monitor configuration.

| Name                     | Type                                                                            | Description                                                                                                                                    |
| ------------------------ | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| blockedRequests          | null \| Array\<null \| string>                                                  | All requests matching the specified patterns will be blocked during the execution of the monitor.                                              |
| browserPermissions       | null \| [BrowserPermissionsDto](#browserpermissionsdto)                         | Permissions settings for browser.                                                                                                              |
| bypassCSP                | null \| boolean                                                                 | Bypass ContentSecurity Policy for monitored pages. If not defined in request, it will be set to false by default.                              |
| chromiumStartupFlags     | null \| [ChromiumStartupFlagsDto](#chromiumstartupflagsdto)                     | Chromium startup flags of a Browser Monitor.                                                                                                   |
| clientCertificates       | null \| Array\<null \| [ClientCertificateDto](#clientcertificatedto)>           | Identifier of stored client's certificate.                                                                                                     |
| cookies                  | null \| Array\<null \| [SyntheticMonitorCookieDto](#syntheticmonitorcookiedto)> | Cookies list.                                                                                                                                  |
| device (required)        | [TestDeviceDto](#testdevicedto)                                                 | Test device of a Browser Monitor.                                                                                                              |
| enablement               | null \| [EnablementDto](#enablementdto)                                         | Browser monitor enablement settings.                                                                                                           |
| experimentalProperties   | null \| Array\<null \| [MonitorPropertyDto](#monitorpropertydto)>               | Experimental properties list.                                                                                                                  |
| filteredRequests         | null \| [FilteredRequestsDto](#filteredrequestsdto)                             | Filtered requests of a Browser Monitor.                                                                                                        |
| ignoredErrorCodes        | null \| [IgnoredErrorCodesDto](#ignorederrorcodesdto)                           | Ignored Error Codes of a Browser Monitor.                                                                                                      |
| javaScriptSettings       | null \| [JavaScriptAgentSettingsDto](#javascriptagentsettingsdto)               | JavaScript Agent Settings.                                                                                                                     |
| monitorCrossOriginFrames | null \| boolean                                                                 | Capture performance metrics for pages loaded in cross origin frames. If not defined in request, it will fall back to monitorFrames by default. |
| monitorFrames            | null \| boolean                                                                 | Capture performance metrics for pages loaded in frames. If not defined in request, it will be set to false by default.                         |
| networkThrottling        | null \| [NetworkThrottlingDto](#networkthrottlingdto)                           | Network throttling of a Browser Monitor.                                                                                                       |
| proxy                    | null \| [ProxyDto](#proxydto)                                                   | Browser Monitor proxy.                                                                                                                         |
| requestHeaderOptions     | null \| [RequestHeaderOptionsDto](#requestheaderoptionsdto)                     | Header Options of a Browser Monitor.                                                                                                           |
| useIESupportedAgent      | null \| boolean                                                                 | useIESupportedAgent flag. If not defined in request, it will be set to false by default.                                                       |
| userAgent                | null \| string                                                                  | User agent                                                                                                                                     |
