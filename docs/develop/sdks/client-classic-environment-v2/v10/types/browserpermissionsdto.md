### BrowserPermissionsDto

Permissions settings for browser.

| Name          | Type            | Description                                                                              |
| ------------- | --------------- | ---------------------------------------------------------------------------------------- |
| camera        | null \| boolean | Camera permission. If not defined in request, it will be set to false by default.        |
| location      | null \| boolean | Location permission. If not defined in request, it will be set to false by default.      |
| microphone    | null \| boolean | Microphone permission. If not defined in request, it will be set to false by default.    |
| notifications | null \| boolean | Notifications permission. If not defined in request, it will be set to false by default. |
