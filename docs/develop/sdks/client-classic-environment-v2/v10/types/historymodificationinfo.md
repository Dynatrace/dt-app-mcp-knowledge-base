### HistoryModificationInfo

Modification information about the setting.

| Name                        | Type   | Description                                                                                                                                  |
| --------------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| lastModifiedBy              | string | The unique identifier of the user who performed the most recent modification.<br /><br />**Example:** `fab17b7a-2eb2-4c95-b818-743d94be2c30` |
| lastModifiedReason          | string | Reason for system change<br /><br />**Example:** `default settings creation`                                                                 |
| lastModifiedTime (required) | Date   | Timestamp when the setting was last modified in ISO 8601 format (yyyy-MM-dd'T'HH:mm:ss.SSS'Z')                                               |
