### EntityTypePropertyDto

The property of a monitored entity.

| Name        | Type   | Description                                                           |
| ----------- | ------ | --------------------------------------------------------------------- |
| displayName | string | The display-name of the property.<br /><br />**Example:** `cpu cores` |
| id          | string | The ID of the property.<br /><br />**Example:** `cpuCores`            |
| type        | string | The type of the property.<br /><br />**Example:** `Number`            |
