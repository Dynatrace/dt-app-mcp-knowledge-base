### MinimalExtension

A list of extensions.

| Name                     | Type   | Description                                                                                                          |
| ------------------------ | ------ | -------------------------------------------------------------------------------------------------------------------- |
| extensionName (required) | string | Extension name                                                                                                       |
| version (required)       | string | Extension version<br /><br />**Example:** `1.2.3`<br />Pattern: `^(0\|[1-9]\d*)(\.(0\|[1-9]\d*))?(\.(0\|[1-9]\d*))?` |
