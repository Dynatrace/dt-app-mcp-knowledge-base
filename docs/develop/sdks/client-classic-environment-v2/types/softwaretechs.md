### SoftwareTechs

Contains information about the used software technology.

| Name         | Type   | Description                                                         |
| ------------ | ------ | ------------------------------------------------------------------- |
| edition      | string | The edition of the technology.<br /><br />**Example:** `OpenJDK`    |
| technology   | string | The type of the technology.<br /><br />**Example:** `JAVA`          |
| verbatimType | string | The verbatim type of the technology.<br /><br />**Example:** `Java` |
| version      | string | The version of the technology.<br /><br />**Example:** `11.0.10`    |
