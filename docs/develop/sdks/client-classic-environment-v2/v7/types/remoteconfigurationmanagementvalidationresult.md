### RemoteConfigurationManagementValidationResult

The result of remote configuration management validation.

| Name              | Type                                                                                                                    | Description                                 |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| invalidEntities   | Array\<[RemoteConfigurationManagementEntityValidationError](#remoteconfigurationmanagemententityvalidationerror)>       | A list of validation errors for entities.   |
| invalidOperations | Array\<[RemoteConfigurationManagementOperationValidationError](#remoteconfigurationmanagementoperationvalidationerror)> | A list of validation errors for operations. |
