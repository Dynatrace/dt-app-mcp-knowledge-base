### Duration

Defines a period of time.

| Name             | Type                                                    | Description                                        |
| ---------------- | ------------------------------------------------------- | -------------------------------------------------- |
| unit             | "DAYS" \| "HOURS" \| "MILLIS" \| "MINUTES" \| "SECONDS" | The unit of time. If not set, millisecond is used. |
| value (required) | number                                                  | The amount of time.                                |
