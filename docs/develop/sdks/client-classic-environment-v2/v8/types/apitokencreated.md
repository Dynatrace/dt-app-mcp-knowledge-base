### ApiTokenCreated

The newly created token.

| Name           | Type   | Description                                                                                                                                         |
| -------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| expirationDate | string | The token expiration date in ISO 8601 format (`yyyy-MM-dd'T'HH:mm:ss.SSS'Z'`).<br /><br />**Example:** `2020-11-12T08:15:30.144Z`                   |
| id             | string | The ID of the token, consisting of prefix and public part of the token.<br /><br />**Example:** `dt0c01.ST2EY72KQINMH574WMNVI7YN`                   |
| token          | string | The secret of the token.<br /><br />**Example:** `dt0c01.ST2EY72KQINMH574WMNVI7YN.G3DFPBEJYMODIDAEX454M7YWBUVEFOWKPRVMWFASS64NFH52PX6BNDVFFM572RZM` |
