### PermissionContext

Optional context data

| Name                | Type   | Description                                                                            |
| ------------------- | ------ | -------------------------------------------------------------------------------------- |
| schemaId (required) | string | Settings schema id for conditional permission<br /><br />**Example:** `service:schema` |
| scope (required)    | string | Settings scope for conditional permission<br /><br />**Example:** `environment`        |
