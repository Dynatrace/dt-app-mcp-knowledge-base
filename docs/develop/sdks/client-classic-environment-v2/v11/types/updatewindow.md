| Name          | Type   | Description                                                                                                                 |

| id (required) | string | Identifier of maintenance window<br /><br />**Example:** `vu9U3hXa3q0AAAABADdkeW5hdHJhY2Uuc2V0dGluZ3MuZGVwbG95bWVudC5tYW5h` |
| name          | string | The name of maintenance window<br /><br />**Example:** `Daily maintenance window`                                           |
