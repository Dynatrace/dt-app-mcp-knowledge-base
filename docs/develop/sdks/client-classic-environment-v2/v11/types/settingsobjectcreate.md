### SettingsObjectCreate

Configuration of a new settings object.

| Name                | Type     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| externalId          | string   | External identifier for the object being created                                                                                                                                                                                                                                                                                                                                                                                                                   |
| insertAfter         | string   | The position of the new object. The new object will be added after the specified one. If `null` (or unset), the new object will be placed in the last position. If set to an empty string, the new object will be placed in the first position. Only applicable for objects based on schemas with ordered objects (schema's `ordered` parameter is set to `true`). <br /><br />**Example:** `Y2ktaGdyb3VwLTEyMythZjhjOThlOS0wN2I0LTMyMGEtOTQzNi02NTEyMmVlNWY4NGQ=` |
| objectId            | string   | The ID of the settings object that should be replaced. Only applicable if an external identifier is provided. <br /><br />**Example:** `Y2ktaGdyb3VwLTEyMythZjhjOThlOS0wN2I0LTMyMGEtOTQzNi02NTEyMmVlNWY4NGQ=`                                                                                                                                                                                                                                                      |
| schemaId (required) | string   | The schema on which the object is based.<br /><br />**Example:** `builtin:container.built-in-monitoring-rule`                                                                                                                                                                                                                                                                                                                                                      |
| schemaVersion       | string   | The version of the schema on which the object is based.<br /><br />**Example:** `1.0.0`                                                                                                                                                                                                                                                                                                                                                                            |
| scope (required)    | string   | The scope that the object targets. For more details, please see [Dynatrace Documentation](https://dt-url.net/ky03459).<br /><br />**Example:** `HOST-D3A3C5A146830A79`                                                                                                                                                                                                                                                                                             |
| value (required)    | AnyValue | The value of the setting. It defines the actual values of settings' parameters. The actual content depends on the object's schema. <br /><br />**Example:** `{"autoMonitoring":true}`                                                                                                                                                                                                                                                                              |
