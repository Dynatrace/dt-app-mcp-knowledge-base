### ConfigurationMetadata

Metadata useful for debugging

| Name                         | Type           | Description                                                                                       |
| ---------------------------- | -------------- | ------------------------------------------------------------------------------------------------- |
| clusterVersion               | string         | Dynatrace version.<br /><br />**Example:** `1.192.1`                                              |
| configurationVersions        | Array\<number> | A sorted list of the version numbers of the configuration.<br /><br />**Example:** `[4,2]`        |
| currentConfigurationVersions | Array\<string> | A sorted list of version numbers of the configuration.<br /><br />**Example:** `["1.0.4","1.23"]` |
