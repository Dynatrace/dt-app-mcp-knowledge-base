### SLO

Parameters of a service-level objective (SLO).

| Name                                      | Type                                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| burnRateMetricKey (required)              | string                              | The key for the SLO's error budget burn rate func metric.<br /><br />**Example:** `func:slo.errorBudgetBurnRate.payment_service_availability`                                                                                                                                                                                                                                                                                                                                                                                                             |
| ~~denominatorValue~~**DEPRECATED**        | number                              | The denominator value used to evaluate the SLO when **useRateMetric** is set to `false`.<br /><br />**Example:** `90`                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| description                               | string                              | A short description of the SLO.<br /><br />**Example:** `Rate of successful payments per week`                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| enabled (required)                        | boolean                             | The SLO is enabled (`true`) or disabled (`false`).<br /><br />**Example:** `true`                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| error (required)                          | string                              | The error of the SLO calculation. If the value differs from `NONE`, there is something wrong with the SLO calculation. <br /><br />**Example:** `NONE`                                                                                                                                                                                                                                                                                                                                                                                                    |
| errorBudget (required)                    | number                              | The error budget of the calculated SLO. The error budget is the difference between the calculated and target values. A positive number means all is good; a negative number means trouble. Has the value of the evaluated error budget or the value of `-1`: * If there is an error with the SLO calculation; in that case check the value of the&#x20;
  **error**
   property.
* If the evaluate parameter has not been set to&#x20;
  `true`
  ; in that case the&#x20;
  **error**
   property will contain no error. <br /><br />**Example:** `1.25` |
| errorBudgetBurnRate (required)            | [SloBurnRate](#sloburnrate)         | Error budget burn rate evaluation of a service-level objective (SLO).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| errorBudgetMetricKey (required)           | string                              | The key for the SLO's error budget func metric.<br /><br />**Example:** `func:slo.errorBudget.payment_service_availability`                                                                                                                                                                                                                                                                                                                                                                                                                               |
| evaluatedPercentage (required)            | number                              | The calculated status value of the SLO. Has the value of the evaluated SLO status or the value of `-1`: * If there is an error with the SLO calculation; in that case check the value of the&#x20;
  **error**
   property.
* If the evaluate parameter has not been set to&#x20;
  `true`
  ; in that case the&#x20;
  **error**
   property will contain no error. <br /><br />**Example:** `96.25`                                                                                                                                                     |
| evaluationType (required)                 | "AGGREGATE"                         | The evaluation type of the SLO.<br /><br />**Example:** `AGGREGATE`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| filter (required)                         | string                              | The entity filter for the SLO evaluation. The total length of the entitySelector string in SLOs is limited to 1,000 characters. Use the [syntax of entity selector](https://dt-url.net/entityselector).<br /><br />**Example:** `type("SERVICE")`                                                                                                                                                                                                                                                                                                         |
| id (required)                             | string                              | The ID of the SLO<br /><br />**Example:** `123e4567-e89b-42d3-a456-556642440000`                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ~~metricDenominator~~**DEPRECATED**       | string                              | The total count metric (the denominator in rate calculation). Required when the **useRateMetric** is set to `false`. <br /><br />**Example:** `builtin:service.requestCount.server`                                                                                                                                                                                                                                                                                                                                                                       |
| metricExpression (required)               | string                              | The percentage-based metric expression for the calculation of the SLO.<br /><br />**Example:** `(100)*(builtin:service.errors.server.successCount:splitBy())/(builtin:service.requestCount.server:splitBy())`                                                                                                                                                                                                                                                                                                                                             |
| metricKey (required)                      | string                              | The key for the SLO's status func metric.<br /><br />**Example:** `func:slo.payment_service_availability`                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| metricName (required)                     | string                              | The name that is used to create SLO func metrics keys. Once created, metric name cannot be changed.<br /><br />**Example:** `payment_service_availability`                                                                                                                                                                                                                                                                                                                                                                                                |
| ~~metricNumerator~~**DEPRECATED**         | string                              | The metric for the count of successes (the numerator in rate calculation). Required when the **useRateMetric** is set to `false`. <br /><br />**Example:** `builtin:service.errors.server.successCount`                                                                                                                                                                                                                                                                                                                                                   |
| ~~metricRate~~**DEPRECATED**              | string                              | The percentage-based metric for the calculation of the SLO. Required when the **useRateMetric** is set to `true`. <br /><br />**Example:** `builtin:service.successes.server.rate`                                                                                                                                                                                                                                                                                                                                                                        |
| name (required)                           | string                              | The name of the SLO.<br /><br />**Example:** `Payment service availability`                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| normalizedErrorBudgetMetricKey (required) | string                              | The key for the SLO's normalized error budget func metric.<br /><br />**Example:** `func:slo.normalizedErrorBudget.payment_service_availability`                                                                                                                                                                                                                                                                                                                                                                                                          |
| ~~numeratorValue~~**DEPRECATED**          | number                              | The numerator value used to evaluate the SLO when **useRateMetric** is set to `false`.<br /><br />**Example:** `80`                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ~~problemFilters~~**DEPRECATED**          | Array\<string>                      | The entity filter for fetching the number of problems related to an SLO. Auto-generated in case no filter has been added to the SLO.<br /><br />**Example:** `[type("SERVICE")]`                                                                                                                                                                                                                                                                                                                                                                          |
| relatedOpenProblems                       | number                              | Number of open problems related to the SLO. Has the value of `-1` if there's an error with fetching SLO related problems.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| relatedTotalProblems                      | number                              | Total number of problems related to the SLO. Has the value of `-1` if there's an error with fetching SLO related problems.                                                                                                                                                                                                                                                                                                                                                                                                                                |
| status (required)                         | "WARNING" \| "SUCCESS" \| "FAILURE" | The status of the calculated SLO.<br /><br />**Example:** `WARNING`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| target (required)                         | number                              | The target value of the SLO.<br /><br />**Example:** `95`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| timeframe (required)                      | string                              | The timeframe for the SLO evaluation. Use the syntax of the global timeframe selector.<br /><br />**Example:** `-1d`                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ~~useRateMetric~~**DEPRECATED**           | boolean                             | The type of the metric to use for SLO calculation: * `true`
  : An existing percentage-based metric.
* `false`
  : A ratio of two metrics. For a list of available metrics, see [Built-in metric page](https://dt-url.net/be03kow) or try the [GET metrics](https://dt-url.net/8e43kxf) API call. <br /><br />**Example:** `true`                                                                                                                                                                                                                         |
| warning (required)                        | number                              | The warning value of the SLO. At warning state the SLO is still fulfilled but is getting close to failure. <br /><br />**Example:** `97.5`                                                                                                                                                                                                                                                                                                                                                                                                                |
