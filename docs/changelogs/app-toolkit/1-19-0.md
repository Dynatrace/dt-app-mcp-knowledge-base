## 1.19.0

### Features

- Add support for `app.selfMonitoringAgent` and `server.showWarnings` in the Vite dev server. (APPDEV-18984)
- Improve the settings widget template scaffolded by `dt-app setting create` with real load/save, permission states, and example fields. (APPDEV-19456)

### Bugfixes

- Exclude `@vanilla-extract/css` from Vite `optimizeDeps` in HMR dev mode to prevent pre-bundler from stripping file-scope hooks, which caused "Styles were unable to be assigned to a file" at runtime. (APPDEV-19980)
- Stop the dev spinner when a watch-mode build fails or is canceled. (APPDEV-19909)
- Accept only `.md`, `.yaml`, `.yml` and `.json` skill reference files. (APPDEV-19881)
- Fix deleted app functions still being served after deletion in the dev server. (APPDEV-19882)
- Serve custom UI assets when using the `--hmr` dev server. (APPDEV-19787)
