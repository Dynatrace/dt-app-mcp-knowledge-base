## 1.17.0 (2026-08-31) \{#1170}

### Features

- Add support for TypeScript 6. Full compatibility with all Strato packages cannot be guaranteed — some depend on `react-intl` which may still require TypeScript 5. If you encounter related errors, override `react-intl` to a compatible typescript version. (APPDEV-17010)
- Report bundled skills and references via telemetry on signed deploy and publish. (APPDEV-19472)
- Allow any file type as an AI skill reference. (APPDEV-19516)
- Add `dt-app mcp add` to register the dt-app-mcp MCP server with Claude Code in a project-scoped .mcp.json file. (APPDEV-18915)

### Bugfixes

- Remove deprecated envFile warning when starting the dev server. (APPDEV-19420)
- Resolve module preload for public dashboards when using optimized builds. (APPDEV-19619)
- Restore missing authentication on publish signing and dev permissions. (APPDEV-15090, APPDEV-19454)
- Loosen up name and description length constraints for skills and references. (APPDEV-19471)
- Show a spinner and no Node warning when installing dependencies for actions and widgets. (APPDEV-19415)
- Stop wrapping settings widgets during build and dev. (APPDEV-19515)
