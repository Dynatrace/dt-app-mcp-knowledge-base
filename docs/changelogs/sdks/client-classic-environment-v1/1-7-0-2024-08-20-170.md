## 1.7.0 (2024-08-20) \{#170}

### Features

- Add `getJsAllAvailableVersions` and `getJsConfiguredVersions` methods to *RumJavaScriptTagManagementClient*
- Support arm64 arch in *DeploymentClient* methods
- Allow including `java-graal-native` module in agent installer methods of *DeploymentClient*

### Bugfixes

- Fix typings for models that use arbitrary values
- Add deprecated tags to generated models and fix descriptions for reference objects
- Improved default error handler to match the common error structure
- Use structural typeguards for errors
