## 2.0.0 (2026-09-23) \{#200}

### Major changes

- BREAKING: Change `RevisionDiff.modificationInfo` from `ModificationInfo` to `ModificationInfoHistory`.
- Added new `lastModifiedToken` property to history response API which is populated with the public token identifier if applicable, and removed fields that are never set
- Add the optional `missingPermissions` field to `ErrorDetails` for 403 responses that report missing permissions.

### Patch changes

- A `package.json` containing `{"type":"module"}` is now emitted into the `esm/` output directory of each published package. This allows Node.js and bundlers to correctly identify the ESM output as ES modules without requiring the `.mjs` file extension.
