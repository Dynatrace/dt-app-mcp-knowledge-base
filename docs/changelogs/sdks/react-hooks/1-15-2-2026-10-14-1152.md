## 1.15.2 (2026-10-14) \{#1152}

### Patch changes

- A `package.json` containing `{"type":"module"}` is now emitted into the `esm/` output directory of each published package. This allows Node.js and bundlers to correctly identify the ESM output as ES modules without requiring the `.mjs` file extension.
- `useDql` now sends a default `requestTimeoutMilliseconds` of 1000 on execute and poll requests, so the backend responds as soon as the result is ready instead of the hook sleeping a full `pollRate` between polls. The delay between polls now accounts for the time a poll already took. Set `requestTimeoutMilliseconds` in the query params to override the default.
