## 1.15.3 (2026-10-15) \{#1153}

### Patch changes

- `useDql` sends the default `requestTimeoutMilliseconds` of 1000 only on the initial execute request, no longer on poll requests, so running queries don't hold poll requests open on the backend. Polling is back to waiting a fixed `pollRate` before every poll, including the first one. Fast queries still resolve in the execute call.
