## 10.0.0 (2026-10-01) \{#1000}

### Major changes

- BREAKING: Remove `SyntheticConfigDto`. Split it into `SyntheticConfigResponse` (returned by `getConfiguration`, same required fields as before) and `SyntheticConfigRequest` (body of `updateConfiguration`, all fields now optional and nullable). Update any code that imports or references `SyntheticConfigDto` to use whichever new type matches its use.
- BREAKING: Make `nodes` required on `SyntheticPrivateLocationUpdate`. Callers building an update payload must now supply `nodes` (pass an empty array if the location has none).
- BREAKING: Many request and response models gained `| null` on properties that were previously non-nullable, including required fields such as `UpdateJob.targetVersion`, `SyntheticHttpMonitorResponse.syntheticMonitorOutageHandlingSettings`, and `SyntheticBrowserMonitorResponse.keyPerformanceMetrics`. Code compiled with strict null checks that dereferences these fields without a guard needs updating.

### Patch changes

- A `package.json` containing `{"type":"module"}` is now emitted into the `esm/` output directory of each published package. This allows Node.js and bundlers to correctly identify the ESM output as ES modules without requiring the `.mjs` file extension.
