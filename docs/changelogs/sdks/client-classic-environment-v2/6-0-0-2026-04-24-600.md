## 6.0.0 (2026-04-24) \{#600}

### Breaking Changes

- Changed `LogRecord.eventType` from a fixed union (`'K8S' | 'LOG' | 'SFM'`) to `string`, allowing any event type value. Removed `LogRecordEventType` enum.
- Removed `ActiveGateTokenActiveGateType` and `ActiveGateTokenCreateActiveGateType` enums.
- Removed `EnablementDtoPerformanceMetric` enum.
- Removed `ExtensionEventDto`, `ExtensionEventDtoStatus`, and `ExtensionEventsList` interfaces (extension configuration/monitoring events).
- Removed `GetEnvironmentConfigurationEventsQueryStatus` and `GetExtensionMonitoringConfigurationEventsQueryStatus` enums.
- Removed `getEnvironmentConfigurationEvents` and `getExtensionMonitoringConfigurationEvents` methods from `Extensions_2_0Client`.

### Features

- Added new **ActiveGate Tokens Enforcement** API (`activeGatesActiveGateTokensEnforcementClient`) for querying the status of ActiveGate token enforcement.
- Added new **ActiveGate Remote Configuration Management** API (`activeGatesRemoteConfigurationManagementClient`) for managing ActiveGate configurations remotely, including job creation, listing, preview, validation, and cancellation.
- Added new **OneAgent Remote Configuration Management** API (`oneAgentRemoteConfigurationManagementClient`) for managing OneAgent configurations remotely, including job creation, listing, preview, validation, and cancellation.
- Added new **JavaScript Mapping Files** API (`javaScriptMappingFilesClient`) for managing JavaScript source maps, minified files, and source files, including upload, metadata update, listing, and deletion.
- Added new **Mobile Deobfuscation and Symbolication** API support for React Native mapping files, including upload, metadata update, listing, and deletion per platform (Android/iOS).
- Added `listJmxProcesses` and `getJmxProcess` methods to `Extensions_2_0Client` for discovering Java processes available for JMX metric collection.
- Added `getAlertTemplate` method to `Extensions_2_0Client` for retrieving extension alert templates.
- Added new **Synthetic HTTP Monitor** models (`SyntheticHttpMonitorRequest`, `SyntheticHttpMonitorResponse`, `SyntheticHttpMonitorStepDto`, `SyntheticHttpConfigurationDto`, `SyntheticHttpMonitorAdvancedDto`, `SyntheticHttpAuthenticationDto`).
- Updated `PlainKeystrokesInputDto.masked` field description to clarify it indicates whether the `textValue` field is encoded by the recorder and should be decoded by VUP.
- Simplified `LogMessageJson` documentation, replacing the verbose inline description with a concise reference to external documentation.

### Bug Fixes

- Fixed `SyntheticOnDemandMonitorExecutionsClient.rerun` to expect HTTP status `200` instead of `201`.
