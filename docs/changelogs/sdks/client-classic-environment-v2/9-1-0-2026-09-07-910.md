## 9.1.0 (2026-09-07) \{#910}

### Minor changes

- Add optional `externalId` to `SyntheticBrowserMonitorRequest`, `SyntheticBrowserMonitorResponse`, `SyntheticHttpMonitorRequest`, `SyntheticHttpMonitorResponse`, `SyntheticMonitorSummaryDto`, `SyntheticMultiProtocolMonitorRequest`, and `SyntheticMultiProtocolMonitorResponse`. Lets configuration-as-code tools (e.g. Monaco) track a stable identifier per monitor.
- Add `'ncc' | 'otel-collector' | 'target-allocator' | 'edge-connect'` to the `ContainerImageComponent.type` union and matching new members (`Ncc`, `OtelCollector`, `TargetAllocator`, `EdgeConnect`) to the deprecated `ContainerImageComponentType` enum.
