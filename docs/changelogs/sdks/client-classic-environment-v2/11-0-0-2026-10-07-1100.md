## 11.0.0 (2026-10-07) \{#1100}

### Major changes

- Remove the `IngestClient` class and the `ingestClient` instance. Use `LogsClient` / `logsClient` instead of `IngestClient` / `ingestClient` for `storeLog`, and `MetricsClient` / `metricsClient` instead for `ingest`.
- Removed nullable (null) types from generated TypeScript models and API responses in the public SDK contract.
