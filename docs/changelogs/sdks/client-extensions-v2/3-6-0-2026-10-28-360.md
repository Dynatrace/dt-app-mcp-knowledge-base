## 3.6.0 (2026-10-28) \{#360}

### Minor changes

- Added the optional `spaceAware` field (`boolean`) to `SchemaDefinitionRestDto`. When `true`, space-based access control is enabled for the schema. It only applies when `multiObject` is `true` and `ordered` is `false`.
- Added `PROBLEM_RESOLUTION_PATH_RULES` as a possible value for the `type` of `AssetInfo`, and the matching `ProblemResolutionPathRules` member of the `AssetInfoType` enum.
- Added the optional `maxObjectCount` field (`number`) to `SchemaConstraintRestDto`, and `MULTI_SCOPE_MAX_OBJECT_COUNT` as a possible value for its `type`, with the matching `MultiScopeMaxObjectCount` member of the `SchemaConstraintRestDtoType` enum. The constraint limits the number of objects over all scopes. It only denies additions.
- Added the required `metadata` field to `Extension` and `ExtensionUploadResponse`, typed as the new `ExtensionMetadata` and `ExtensionUploadResponseMetadata` string maps (`[propName: string]: string | undefined`). They hold additional non-asset information about the extension as key-value pairs.

### Patch changes

- Updated the minimum required versions of `@dynatrace-sdk/http-client` (`^1.5.2`) and `@dynatrace-sdk/shared-errors` (`^1.1.0`).
