## 1.1.0 (2026-03-02) \{#110}

### Minor changes

- Monitoring configurations returned by `/monitoring-configurations` and `/monitoring-configurations/{configuration-id}` endpoints will now include `modificationInfo` if available.
- Added `markedForDeletion` as an additional field in the extension information returned from `/listExtensions` endpoint.
- Added `markedForDeletion` as an optional filter value in the `/listExtensions` endpoint.
- Increased maximum page size on listing monitoring configurations from 100 to 500.
