## 3.7.0 (2026-11-10) \{#370}

### Minor changes

- Added `warnings` list to `EnvironmentConfiguration`. It contains warnings for the extension environment configuration assets, for example when imported assets couldn't be read. Request it with `addFields: "warnings"`.
- Added `WARNING` and `ERROR` as possible values of the `status` field of `EnvironmentConfiguration`, and the matching `Warning` and `Error` members of the `EnvironmentConfigurationStatus` enum. `ERROR` means at least one asset failed to install. `WARNING` means the installed assets couldn't be fully read. Code that switches on `status` needs to handle both new values.
