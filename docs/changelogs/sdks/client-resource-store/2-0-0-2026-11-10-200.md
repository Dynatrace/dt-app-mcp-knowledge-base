## 2.0.0 (2026-11-10) \{#200}

### Major changes

- BREAKING: Replace the error model of the Resource Store client. `ErrorEnvelope.error` is now `ErrorResponse` (`code: number`, `message: string`, optional `details: ErrorResponseDetails`) instead of `ExceptionalReturn`. `ErrorResponseDetails` adds `constraintViolations`, `errorMessage`, `missingPermissions` and `missingScopes`. The new `ErrorResponseDetailsConstraintViolations` type has `message` and `parameterDescriptor`.
- BREAKING: Remove the exported types `ExceptionalReturn`, `ErrorInfo`, `CustomValidationErrorInfo`, `InvalidAuditEventsErrorInfo`, `MediaTypeErrorInfo`, `ParameterErrorInfo`, `ProxyErrorInfo`, `QueryFrontendRawErrorInfo` and `RequestBodyErrorInfo`. Code that reads `error.errorDetails` from `ErrorEnvelopeError` must switch to `error.details`.

### Patch changes

- Updated the minimum required versions of `@dynatrace-sdk/http-client` (`^1.5.2`) and `@dynatrace-sdk/shared-errors` (`^1.1.0`).
