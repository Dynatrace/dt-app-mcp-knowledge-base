## 2.7.0 (2026-09-30) \{#270}

### Minor changes

- Add the optional `maintenanceWindowTriggerBehavior` field to `DavisProblemConfig`, controlling whether a Davis problem trigger fires while a maintenance window is active, inactive, or in all cases (`"always"`, `"inside"`, `"outside"`; default `"always"`).

### Patch changes

- A `package.json` containing `{"type":"module"}` is now emitted into the `esm/` output directory of each published package. This allows Node.js and bundlers to correctly identify the ESM output as ES modules without requiring the `.mjs` file extension.
