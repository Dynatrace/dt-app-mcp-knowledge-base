## 2.0.0 (2025-01-20) \{#200}

### Breaking changes

- Created distinct components and changed references from `SelfNotificationRequest` to `SelfNotificationCreate` and `SelfNotificationUpdate`.
- Replaced inline enums with reusable components such as `DavisEventTriggerConfigType`, `DavisProblemTriggerConfigType`, and `EventQueryTriggerConfigType`.
- Updated the `input` property description to reference `SelfNotificationInput` instead of `SendDefaultNotificationInput`.

### Minor changes

- Added `nullable` attribute to `createdBy` and `lastModifiedBy` properties in `ModificationInfo`.
