## 4.0.0 (2026-10-20) \{#400}

### Major changes

- `getDefaultCspProperties` has moved from `appEngineRegistrySchemaManifestClient` to the new `appEngineRegistryDefaultCspClient`. Update call sites accordingly.

### Minor changes

- Add missingScopes and missingPermissions property in the response for HTTP 403 errors.
- Add actions API.

### Patch changes

- A `package.json` containing `{"type":"module"}` is now emitted into the `esm/` output directory of each published package. This allows Node.js and bundlers to correctly identify the ESM output as ES modules without requiring the `.mjs` file extension.
