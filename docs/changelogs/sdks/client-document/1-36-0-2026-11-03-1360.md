## 1.36.0 (2026-11-03) \{#1360}

### Minor changes

- Add `requestDocumentAccess` to request access to a document. The document owner is notified by email. Returns the request status (`owner-notified` or `access-already-granted`).
- Add `NotImplemented` error class and `isNotImplemented` helper for environments where access requests are disabled (501 response).

### Patch changes

- Updated `adminAccess` parameter documentation to clarify that for system-owned documents (ready-made and extension-shipped), admin access is limited to hiding them and creating/maintaining direct `read`-shares; other owner operations remain unsupported for those documents.
- Updated direct-share endpoints (`deleteDirectShare`, `listDirectShareMembers`, `updateDirectShareMembers`) to document that for system-owned documents, direct-share management requires admin access (`admin-access=true`).
- Added "Admin control" section to the API overview describing how administrators can override default visibility for system-owned documents.
- Updated `downloadDocumentContent` to reflect that caching headers (`Cache-Control`, `ETag`, `If-None-Match`) are available for all document types, not just public images.
- Updated the minimum required versions of `@dynatrace-sdk/http-client` (`^1.5.2`) and `@dynatrace-sdk/shared-errors` (`^1.1.0`).
