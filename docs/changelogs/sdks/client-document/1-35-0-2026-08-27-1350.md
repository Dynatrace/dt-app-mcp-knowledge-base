## 1.35.0 (2026-08-27) \{#1350}

### Minor changes

- Add makePrivate and makePublic endpoints
- Allow admin hide ready-made documents via makePrivate and makePublic endpoints
- Deprecate isPrivate parameter of updateDocument endpoint
- add Cache-Control (private, no-cache) and ETag header to getDocumentContent response, exlusively for public image-type documents only
- content and metadata properties for the FullDocument response returned by getDocument  are now marked as required, as they are always present.
