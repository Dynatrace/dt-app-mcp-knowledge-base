## 1.0.3 (2026-09-11) \{#103}

### Patch changes

- Percent-encode `functionName` in `functions.call`. The value was spliced into the request path unencoded, so a caller-influenced function name could append query parameters the calling code never intended - `myFn?admin=true` reached the app function as `GET /api/myFn?admin=true` - or restructure the path. `functionName` is now sent as a single, inert path segment. This also covers `useAppFunction` in `@dynatrace-sdk/react-hooks`, which passes its `name` parameter straight through. (APPDEV-19698)
- Generated TypeScript declarations are now rolled up into a single `types/index.d.ts` per entry point. (APPDEV-11700)
