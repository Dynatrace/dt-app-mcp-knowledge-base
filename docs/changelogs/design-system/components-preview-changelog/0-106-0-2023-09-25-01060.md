## 0.106.0 (2023-09-25) \{#01060}

### Minor Changes

- 19c0a9b1a: Changed `SingleValue` label default color.

- 0927170a2: Added `Histogram` chart.

- 6887ef5b6: Made `Annotations` description prop optional.

- b8cd64814: DataTable: Column resizing is now possible also when one or more columns have autoWidth defined.

- 91d11c330: Added tooltip and legend configuration for single and multi meter bar charts.

- c9c62bee8: Meter bar and multi meter bar charts can now automatically generate the value label.

- dee63fe6b: DataTable - We now provide a "selected rows actions" feature that allows you to perform actions on one or multiple rows in the DataTable simultaneously.

- d6b9d8251: Added 'vulnerability-status' color palette to charts.

- 50db3e4b4: The `Tabs` component now passes the remaining props and also allows for controlling the overflow behavior of the tab panel.

- 159e905ee: Align the DataTable's pagination UI with the latest design.

- ba2f3facc: BREAKING CHANGE: The DataTable's default cell styling is not applied by default anymore for custom cells. Migrations are provided to re-apply it for existing occurrences.

- ff96aad75: Improved slots layout display for meter and multi meter bar.

- 7b5549f57: BREAKING-CHANGE: Size definition prop value changed for single and multi meter bar components as follow:

  - size100 replaced by size8;
  - size200 replaced by size16;
  - size300 replaced by size24;

- 2fb6f11fa: Fixed icon not showing in Annotations custom actions.

### Patch Changes

- 606a5f51a: DataTable - Now when a custom rendered header contains an interactive element it can properly emit a trigger event.

- d7c545630: Multiple tooltips reset the timers correctly and close or open accordingly when moving from one trigger to the next.

- ae499f244: Custom icons in the annotations now scale as expected in all supported browsers.

- 4c2623d5f: Fixed the `CategoricalBarChart` legend, should hide when there is no legend to display.

- 153214126: Form controls with overlays (select, timeframeselector, datepicker) now use an imperativeHandle instead of a element ref. The handle supports access to the wrapping element and the trigger as well to an open and close functionality.

  BREAKING-CHANGE: The ref structure changed but migrations are provided and should cover most of the use-cases. In case the migrations didn't work properly, the outer element of the component can now be accessed with `ref.current?.element` and the trigger with `ref.current?.triggerRef?`.

- b3e1dee3e: `SingleValue` icon and unit is not cropped on Windows anymore.

- 2c6938610: `CodeSnippet` with DQL selected now correctly escapes quotes within strings.

- c8cb48787: `Page` no longer crashes when dismissing a panel that has no calculated size yet.

- a11175558: DataTable - padding is no longer missing if a formatter is used in a column definition.

- 63cc4caa5: `CodeSnippet` with DQL selected now doesn't highlight numbers attached to functions or identifiers.

- bb82995b8: Links within accent chips now have better contrast when focused with the keyboard.

- Updated dependencies \[58053f192]
  - @dynatrace/strato-design-tokens\@0.18.0
