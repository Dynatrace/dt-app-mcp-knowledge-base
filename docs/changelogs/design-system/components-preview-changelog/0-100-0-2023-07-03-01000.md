## 0.100.0 (2023-07-03) \{#01000}

### Minor Changes

- 1670293ab: Fixed toolbar rendering even if no config was present.

- bc7a99374: Deprecated `Table` has been removed from the library. Alternatively use either the `DataTable` or `SimpleTable`.

- 77a82c7dd: Introduced Trend component integrated with the `SingleValue`. Redesigned `SingleValue` internal layout to give more space to Sparkline.

- 5409fd318: Introduced alignment functionality as a prop to the `SingleValue` component.

- 2093aca18: Experimental support for react 18 has been added.

  This is the first draft containing compatibility for react 18. Please do not upgrade to react 18 in your applications when working on production applications as there are still some issues to be resolved.

- bb6052918: The `Avatar` component can now be polymorphed.

- 488579a75: The page content can now be scrolled while the tooltip's series action menu and the legend menu are open.

- d1ecb3801: `TimeseriesChart` data points are now displayed at the middle of a timeframe.

- 201976390: `react-intl` is now listed as a peerDependency, effectively lifting the hard version lock. You are now able to use your own version of `react-intl`. Migrations to add `react-intl` in the previously used version are provided.

- 5598528ee: Added Empty and Error state feature into the CategoricalBarChart.

- 6c7312d1e: Added empty and error state to pie and donut.

### Patch Changes

- a4729e45e: The fixed collapsed toolbar menu now correctly triggers the overlays x-Axis zoom and pan functionalities.
- 48e0b7fc7: `DataTable`: Now the pagination defaultPageSize can be properly exported in the configuration.
- 49a3fd23d: BREAKING CHANGE: Removed unused prop `onSeriesClick` from `CategoricalBarChart` and `TimeseriesChart`.
- 85b6fc8ad: Fixed the Timeseries toolbar A11y. Ensured that the keydown shortcuts were working correctly. Triggered X Axis zoom and Panning actions with the enter key. In Panning mode, allowed cancellation with the escape key.
- 973bb2fe9: Fixed SelectIndicator rendering issue when using useListboxOptionsWithIcon when passing too long texts. Fixed SelectSection title causing issues when passing too long texts.
- 3a14a2f8f: `DataTable`: If empty user actions are defined cell no longer disappears.
- 61a97bedf: Fixes an issue when clicking an element inside the roving focus container and navigating away with Shift+Tab, then with Tab.
- 4eabbf08d: `DataTable` defaultSelectedRows now work correctly without pagination.
- fb4fe6e59: Editors now consider min-height and max-height of wrapping flex container when using fullHeight.
- 4b818c488: DQL query results displayed in a `DataTable` instance are now correctly serialized, when downloaded as csv. Arrays and Records are not currently supported.
- ed479fa81: CodeEditor's autocomplete overlay now stacks correctly above a Surface component.
