## 0.98.0 (2023-06-05) \{#0980}

### Minor Changes

- b9b1d688f: `DataTable` now accepts a `loading` prop, which will display one of these 3 loading states:

  1. When the data table is initially loaded and columns and data are being loaded.
  2. When the table is loading new data.
  3. When the user switches to a new page and the data is being loaded.

- 28c4d1817: Added empty, error and loading state core components.

- c3376c0c7: Menu.Content now allows a `avoidCollisions` prop to be set (defaults to true). It can be used to override the default positioning behavior which is trying to avoid collisions.

- e31624091: `DataTable` row expansion can be controlled through props.

- c0118cfb6: The `Codesnippet` now correctly copies the selected content only.

- 8ac8e8e5d: Added support for uncontrolled detail view and sidebar for the page component.

- 0d4bc697d: Charts Toolbar: Hide grip control when draggable is false.

- faf6dfd0d: Added unit prop to `SingleValue`.

- b83b72f35: `List` typography component has been redesigned.

- 197351ea5: `TimeseriesChart`: Added toolbar configuration to shared config provider.

- 7b821a4a6: The defaultValue for an uncontrolled `Switch` component is now optional.

- b11e8abb8: `DataTable`: If rowSeparation and rowDensity are set to empty values during DataTable configuration import, they will fallback to default values.

- 40ad7f47d: Fixed wrong font-weight in `Surface`.

- 34cd87587: Toolbar: Collapse depending on container size.

- b919144ce: Extended the properties that could be configured via Shared Config to the Sparkline when is within a SingleValue.

  - Color, showTicks and variant, are now configurable.

- 93c31ebec: Icons now support custom sizes and predefined sizes were updated.

  **BREAKING-CHANGE**: Icon size "large" was changed from 64 to 32 pixels, and "text" option was removed. Migrations are provided.

- 1c03c05d0: Adds a controlState to the `TimeframeSelector`.

- 49bf663f2: Implemented the categorical bar chart custom actions.

- 5ab764941: `Toast`: Added support for JSX in the message for formatting.

- 012ba0ab5: All Editors now accept `AriaLabelingProps` as part of the props.

- 7f60303f4: `DataTable` doesn't show the expandable content anymore if it's outside the virtualized viewport while the row is inside.

- d748dbb4e: `Tabs` can now be rendered conditionally.

- 8fdf01497: Add units and proper value formatting to `DataTable`.

- fac19bc85: The scrollbar colors have changed.

- 0496b6bc0: **BREAKING-CHANGE**: Adjusted DataTable Toolbar API:

  - `DataTable.Toolbar.DownloadData` changed to `DataTable.DownloadData`
  - `DataTable.Toolbar.FontStyle` changed to `DataTable.FontStyle`
  - `DataTable.Toolbar.LineWrap` changed to `DataTable.LineWrap`
  - `DataTable.Toolbar.VisibilitySettings` changed to `DataTable.VisibilitySettings`

  Migrations are provided.

- bdb976a35: DataTable and SimpleTable now allow for configuring vertical alignment as well.
