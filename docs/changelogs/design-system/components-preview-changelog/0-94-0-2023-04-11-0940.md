## 0.94.0 (2023-04-11) \{#0940}

### Minor Changes

- 146105e18: When column groups are present, include parent header also in the downloaded csv file.

- 136a64171: DataTable pagination go to end/start now also reset row selection. In this regard, they now behave the same as next/previous.

- d5b8ddaa5: Cut and paste are now no longer possible for read-only editors.

- adc8fca27: New toasts are now shown at the bottom instead of the top.

- c49ee0302: The `Button` now supports loading states and shows an indeterminate `ProgressCircle` when loading.

- 4d7ee26e6: The RunQueryButton now uses the ProgressCircle to display the loading state.

- fee77609a: Release the `NewPage` component as stable `Page`. Page panels now also support `minWidth`.

  #### Breaking changes

  - The previously deprecated `Page` component is replaced by the new page component.
  - The old page's `SideBar` is renamed to `Sidebar` with the replacement of the page.
  - Mandatory `dismissed` and `onDismissChange` prop on the `Sidebar`.
  - The compounds of the page (`Header`, `Sidebar`, `Main`, and `DetailView`) must be rendered as direct children of the page.

  The following example will no longer work:

  ```jsx
  <Page>
    <Page.Header></Page.Header>
    <Routes>
      {/* route 1 */}
      <>
        <Page.Sidebar></Page.Sidebar>
        <Page.Main></Page.Main>
      </>
      {/* route2 */}
      <>
        <Page.Sidebar></Page.Sidebar>
        <Page.Main></Page.Main>
        <Page.DetailView></Page.DetailView>
      </>
    </Routes>
  </Page>
  ```

  You will have to restructure your app and either pull out the page to the topmost level and add the routes to the corresponding panels, or create a page for each route.

  ```jsx
  <Page>
    <Page.Header></Page.Header>
    <Page.Sidebar></Page.Sidebar>
    <Page.Main>
      <Routes>...</Routes>
    </Page.Main>
    <Page.DetailView>
      <Routes>...</Routes>
    </Page.DetailView>
  </Page>
  ```

  ```jsx
  <Routes>
    {/* route 1 */}
    <Page>
      <Page.Header></Page.Header>
      <Page.Sidebar></Page.Sidebar>
      <Page.Main></Page.Main>
    </Page>
    {/* route2 */}
    <Page>
      <Page.Header></Page.Header>
      <Page.Sidebar></Page.Sidebar>
      <Page.Main></Page.Main>
      <Page.DetailView></Page.DetailView>
    </Page>
  </Routes>
  ```

- 829c403c2: The Switch component has a new design and internally uses an input now.

- af603da28: Removed icon in front of FilterBar.
