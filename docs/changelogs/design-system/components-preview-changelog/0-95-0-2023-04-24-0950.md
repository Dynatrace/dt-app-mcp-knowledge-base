## 0.95.0 (2023-04-24) \{#0950}

### Minor Changes

- 0f6fd4cbd: DataTable: Overscan for virtualization is now set to 5 to improve performance.

- 9565adc69: DataTable: Now if all sub-columns are hidden, the header height will collapse to one row.

- fef794dd4: CodeSnippet: Selecting and copying with 'ctrl/cmd + c' doesn't copy the line-numbers anymore.

- 3d5249924: Fixed `Divider` layout in the `TitleBar` when using it inside Flex layouts.

- 164247799: DataTable: The threshold for the rows (used for row highlighting) can be configured and applied at the DataTable level as table props.

  BREAKING CHANGE: Row highlighting is not possible to configure via column definition anymore. Property `highlightRow` is removed from Threshold options.

  Before:

  ```
  const column: TableColumn[] = [
    {
      header: 'Firstname',
      accessor: 'firstname',
      thresholds: [
        {
          value: 'Emery',
          comparator: 'equal-to',
          color: 'red',
          ~~highlightRow: true,~~
        },
      ],
    }
  ];

  ```

  Now the row highlighting must be defined on the table level by using data table prop `rowThresholds`.

  See [usage examples](https://developer.dynatrace.com/design/components-preview/tables/DataTable/#highlight-rows)

  After:

  ```
  <DataTable
    rowThresholds={[
      {
        id: 'firstname', // column accessor/id must be specified
        value: 'Emery',
        comparator: 'equal-to',
        color: 'red'
      },
    ]}
  />

  ```

- 73fe1d161: DataTable: Under certain scenarios header groups are not aligned properly.

- 9cd012cc0: Heading: The semantic level is now set to same level as the visual level, if not specifically specified with the 'as' property.

- 68b5500d6: In the DataTable, default column actions are not rendered on expandable/selectable cells anymore.

- 6097dd0b9: Unify component prop interface names and fix DOMProps imports.

  #### Breaking changes

  - Renamed component prop interfaces `CheckboxProps*` to `Checkbox*Props`
  - Renamed component prop interfaces `SwitchProps*` to `Switch*Props`
  - Renamed component prop interfaces `TabsProps*` to `Tabs*Props`

- c37db1add: In the DataTable, if all regular columns are hidden now the expandable and selectable columns are also hidden.

- 668b98aa9: CodeSnippet/CodeEditor: design is now aligned

- 502c64d42: Page compounds can now be rendered anywhere in the page's subtree and no longer need to be direct children of the page.

- 8218d489d: Fixes ability to resize when the table is fullWidth. Also, changes the column width allocation when fullWidth is enabled. Instead of all columns proportionately expanded, all columns remain same and additional space is taken by the last column or last column is expanded to take remaining space.

### Patch Changes

- 36ae00add: Fixed bug in the `DQLEditor` where `onVisibilityHandler` reference was never updated on re-render.
