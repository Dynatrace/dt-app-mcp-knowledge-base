### Patch Changes

- edc78cc13d: `DQLEditor` autocomplete now opens correctly when `DQLEditor` is inside a Drawer.

- e9139563cb: The button now exposes `disabled` and `aria-disabled` props to allow for natively disabling a button.

  #### Breaking changes

  - The `disabled` prop now adds the native `disabled` attribute to the underlying `button` element.
  - `aria-disabled` behaves according to the [MDN documentation](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-disabled) -> only semantically disables the button; events need to be handled by the app dev.

  ##### Migration Guide

  We don't automatically migrate the `disabled` prop to `aria-disabled`, since we don't know which events would need to be cancelled. If you want to keep the button focusable for accessibility reasons, change the `disabled` prop to `aria-disabled` and handle events accordingly to avoid triggering an action.
