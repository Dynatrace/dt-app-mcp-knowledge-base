## 0.99.0 (2023-06-19) \{#0990}

### Minor Changes

- d34cb7582: Added Empty and Error state feature into the `TimeseriesChart`.

- 284ac779d: `DataTable` default minimum column width is now 30 instead of 100.

- d3a9fb046: The surface now adds interactive styles autonomously when using it as an interactive element.

  BREAKING CHANGES: Removal of the interactive prop from the surface. It automatically styles all interactive surfaces, meaning all surfaces have a tabIndex or an underlying `a` or `button` HTML tag. There are migrations to remove the interactive prop and for interactive elements it shouldn't change anything. All those elements that do not rely on an interactive HTML syntax would need some manual adjustment to align the focus behavior.

- 647109204: Changed the `SingleValue` internal layout. Now the value, label, unit and sparkline are better positioned and distributed, and only have the vertical layout.

- 7cd78637d: Adds an `Inner` element to the `DonutChart`. This allows you to customize the middle section within the `DonutChart`.

- 1d8017046: Removed the visible focus outline in clearable multiselects.

- ed6ba5b51: In the `DataTable` component a callback event `onColumnResize` is exposed that will be triggered when the user resizes a table column.

- 32c07f5d9: Remove value dimension from name of timeseries converter result if it is identical for all timeseries.

- 9350a30ee: Charts color palettes apdex, log-status, log-level and vulnerability-risk-level now automatically map the colors to the values.

- 27ade7951: BREAKING CHANGE: `DonutChart`: Added new parameters to the Inner Component function.

- 74c84a37d: Height calculation in `Page Panel` and `Page Drawer` is now aligned.

- f04435037: Adds support for anchors as part of the `ActionGroup`.

- c7e162faf: Adds support for custom series actions for `PieChart` and `DonutChart`.

### Patch Changes

- dd30f691e: Fixed misplaced Timeseries and Categorical magnifiers and grid lines when the chart was center aligned.
- 5612598e0: In the `DataTable`, when the column actions are enabled, the column group header should not contain an empty actions menu when actions are unavailable.
- 3dec855d6: `Button` with fixed width and prefix and/or suffix elements no longer overflow.
- 981372c05: `useRovingFocus` hook now consistently sets focus when navigating away from a container with shift+tab. It now also correctly navigates to the new item when changing the initialIndex dynamically and tabbing inside the container.
- a1fc9f454: Fixed bars being misplaced in the `CategoricalBarChart` when having single dimensions and grouped mode.
- 1ba673398: Bump `@visx` version to ^3.0.0.
- 59296ec26: `DataTable`: Reselection works now when only reselecting 1 item less and onSelectionChange is called with correct values when selecting multiple rows.
- 3001bbfa3: In the `DataTable` the correct row will be selected when any rows are expanded.
- 20ca129b7: Fixed toolbar expanding out of chart bounds.
- 122e43b75: Fixed thresholds not being shown with infinite values in TimeseriesChart and CategoricalBarChart.
- 37000193f: `TextArea` can now set its width to full, content (default), or a specific width.
- 2c09d45a0: Improve the formatting of the CSV data of the categorial chart
- 5640fd9a6: `Ellipsis` is now correctly styled if used in a `Link`.
- 2a915f948: Keep focus in dql and code editor when pressing tab.
- d6b11aa3c: Fixed width of `ProgressBar` in Flex containers.
- c84d71d06: Fixed the `Timeseries` X axis zoom selector opacity when accessing through keyboard shortcuts.
