## 2.14.1 (2026-02-05) \{#2141}

### Updates

#### DataTable

- Columns no longer disappear during horizontal scrolling when both an extended width config (`{ type: 'auto' | 'content'; maxWidth?: number }`) and an explicit column size (via `defaultColumnSizing`, `columnSizing`, or by resizing the column) are set for a column. (APPDEV-16121)
- Column widths are now correctly remeasured on rerender. (APPDEV-15908)
