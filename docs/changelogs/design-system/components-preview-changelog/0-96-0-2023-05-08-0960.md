## 0.96.0 (2023-05-08) \{#0960}

### Minor Changes

- 5ce5e0ed3: You can now configure a customizable message to be displayed in the absence of data in the `DataTable` component.

- e24851c3a: Extend `IntentButton` to support recommending an appId and intentId.

  #### Breaking changes

  - Removed `IntentIconButton`. Use `IntentButton` with iconOnly property instead.

- 1cfdbdf68: With changes to column resizing when fullWidth is set to true, header groups alignment is broken in certain scenarios.

- 247fa2212: On `DataTable` columns you can now use SDK formatting i.e. you can specify column formatting with the notation of `@dynatrace-sdk/util-formatters`.

- 97e8fa426: `useBreakpoint` hook with an array query will no longer cause re-renders.

### Patch Changes

- 2193f373a: Using a simple text input no longer throws a warning that it's switching from uncontrolled to controlled.
- 3f3bed6b2: `DataTable` select all button now works correctly in Firefox.
- cc2558137: `FilterBar` now calls `onFilterChange` only once when multiple items are added at the same time using the `MoreMenu`.
- 858cf0caa: The multiple `Select` trigger now correctly displays text values of complex options.
- 84b973a0d: `CodeSnippet` no longer applies rounded corners in nested elements.
- 3b9f2f0ff: In the `DataTable` cells with user actions defined, the `autoWidth` setting is not resizing the column based on the content.
- 89bdf552a: The `FilterBar` `onFilterChange` callback is no longer cached.
- acb747085: Introduced alignment property for `Menu.Content` that determines how the menu is aligned relative to its trigger.
- 6b3d7e6d7: The `FormField` no longer nests labels in case a custom label is used.
- 6e5ab1f51: The `FilterBar` can now display the text of custom labels and the MoreMenu now truncates multiple items with an ellipsis when they overflow. Also, when using custom labels in the `FilterBar.Item`, the input id and the label can now be properly connected with the htmlFor attribute.
- 2d20942c8: Fixed regression that caused overflowing cell content to be cut off without ellipsis in DataTable.
- dcd7c829f: Editors background no longer bleeds out of it's container.
- e8ee33d2b: Increase scrollbar visibility in Firefox.
- Updated dependencies \[d47ee3cc8]
