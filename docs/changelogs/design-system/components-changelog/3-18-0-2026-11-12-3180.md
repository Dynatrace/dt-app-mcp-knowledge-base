## 3.18.0 (2026-11-12) \{#3180}

### Dependency updates

- `@dynatrace/strato-icons` was updated to version `2.7.0`.

### Updates

#### General

- Fixed the development-only warnings that also showed up in the browser console of your users in production and in your test runs. (APPDEV-21045)

#### Buttons

- Disabled emphasized buttons now show the correct neutral disabled background in visual refresh mode. (APPDEV-19745)

#### Charts

- The "Change mode" button in the chart toolbar now has an accessible name, so screen readers announce what it does. (APPDEV-20400)
- Legend tooltips now close when users scroll the legend, instead of following the item outside the chart. (APPDEV-20340)

#### Editors

- You can now pass `null` as `value` or `defaultValue` to `CodeEditor` and `DQLEditor`, so the editor starts empty and keeps its controlled or uncontrolled mode.
- `onValidityChange` now behaves the same as for form controls: it reports errors once they are shown to the user, emits only when the set of errors changes, and reports a `pending` state once while linting runs. (APPDEV-19740)
- Fixed missing behavior tracking attributes on interactive elements and on overlays rendered outside their component, so user interactions are attributed to the correct component. (APPDEV-19829)

#### Filters

- Disabled and read-only fields now use the neutral disabled background in visual refresh mode, and read-only error fields use an emphasized critical outline. Error fields also now use the surface background instead of a critical background in visual refresh mode. (APPDEV-19745)
- You can now pass `null` as `value` or `defaultValue` to `FilterField`, so the field starts empty and keeps its controlled or uncontrolled mode.
- `onValidityChange` now behaves the same as for form controls: it reports errors once they are shown to the user, emits only when the set of errors changes, and reports a `pending` state once while an asynchronous validation runs. (APPDEV-19740)

#### Forms

- Fixed form fields inside a `Form` that showed a control's error message twice, for example a min or max error. (APPDEV-19307)
- Disabled and read-only fields now use the neutral disabled background in visual refresh mode, and read-only error fields retain their surface background with an emphasized critical outline. Error fields also now use the surface background instead of a critical background in visual refresh mode. (APPDEV-19745)
- Placeholder text on interactive inputs now renders at reduced opacity in visual refresh mode to improve differentiation between placeholder text and user-entered content. (APPDEV-19745)
- You can now pass `null` as `value` or `defaultValue` to `TextInput`, `PasswordInput`, `SearchInput`, `TextArea`, `Checkbox`, `Switch`, `RadioGroup`, `ToggleButtonGroup`, and `Select`, so the control starts empty and keeps its controlled or uncontrolled mode.
- `onValidityChange` now behaves the same for every form control: it reports errors once they are shown to the user, emits only when the set of errors changes, and reports a `pending` state once while an asynchronous validation runs. (APPDEV-19740)

#### AiResponse

- Links to intents, apps, and documents in the current environment now open inside the platform, so users no longer land in a new browser tab. (APPDEV-20666)

#### AnnotationsChart

- Fixed the missing bottom separator below the last track. (APPDEV-18335)

#### AppHeader

- The app icon is now loaded once and reused instead of being requested again on every window focus, network reconnect, or remount. (APPDEV-16455)

#### Chip

- Fixed the `emphasized` variant's Visual Refresh outline rendering wider and with vertically shifted content compared to the `accent` variant. (APPDEV-20202)
- Fixed the vertical offset between a value wrapped in `TextEllipsis` and the prefix or suffix icon. (APPDEV-20996)

#### CodeEditor

- Added `ActionsMenu` slot with a built-in "Copy" action, and support for a "Download" action and custom menu items. (APPDEV-20039)

#### Combobox

- Disabled options are no longer selected, and `onChange` no longer fires, when users type their text and move focus away. (APPDEV-21071)

#### DataTable

- Added a warning in development when a table with more than 100 rows renders all of them because its height isn't limited, so you can spot tables where row virtualization has no effect. (APPDEV-20971)
- Improved the scroll performance. When rows cannot render in time during fast scrolling, they now show placeholder cells until scrolling slows down. (APPDEV-20981)
- Fixed centered and end-aligned virtual scrolling offsets to account for the visible viewport and row borders. (APPDEV-20852)
- Fixed a redundant vertical scrollbar that appeared when the table was rendered inside a `Modal` or another container that scales while animating. (APPDEV-20984)
- Fixed columns redistributing and jumping to the right shortly after the table was rendered inside a `Modal` or another container that scales while animating.
- Fixed the unwanted vertical scrollbar at fractional browser zoom levels such as 110%, which also made the scrollbars flicker when hovering rows. (APPDEV-21054)
- Fixed the column widths that were not measured when scrolling sideways after the table was sorted, paginated, or scrolled down. (APPDEV-20981)

#### DateTimePicker

- Fixed the validation error showing a maximum date when only `min` is set. (APPDEV-20868)
- Fixed the one-hour shift of typed PM times on days with a daylight saving time change, which also affected `DateTimeRangePicker` and `TimeframeSelector`. (APPDEV-21033)
- Fixed pasting a date, such as `2025-12-01`, into a `type="date"` picker so it no longer shifts to the previous day in timezones ahead of UTC. (APPDEV-20856)

#### DQLEditor

- Added `Download` action to the `ActionsMenu`. (APPDEV-20039)

#### FeatureHighlight

- Reduced the border around the `Visual` from 2px to 1px to match the Visual Refresh. (APPDEV-20598)

#### FilterComposition

- The `FilterCompositionMenuGroup` now shows at most five items at the top level. With six or more operators, it keeps the first four and moves the rest into a **Show more** submenu. (APPDEV-19817)
- Fixed the apply button changing width between the fetch, apply, refresh, and cancel states. The width now fits the longest label in the active language. (APPDEV-20032)

#### FilterField

- Fixed key suggestions containing square brackets being applied without double quotes, which marked the key as invalid. (APPDEV-21024)
- With the visual refresh enabled, statements that wrap onto multiple rows now stay inside the input outline instead of overlapping its bottom edge. (APPDEV-20755)
- Shortened the descriptions of the `in` and `not in` operators to "Matches a value in a list" and "Doesn't match a value in a list".

#### FocusScope

- Fixed the initial focus with `contain` or `autoFocus` moving away from an element the content had already focused on mount.

#### Highlight

- Fixed a crash ("Maximum call stack size exceeded") when the highlighted term matched a very large number of times. (APPDEV-20793)
- The page no longer becomes unresponsive when a term has many consecutive matches, for example in long text made of a repeated character. (APPDEV-20918)

#### HistogramChart

- Fixed compact annotation markers rendering extra shapes below them. Compact value markers are now a single rounded rectangle. (APPDEV-20778)

#### InputGroup

- Fixed vertical misalignment between `FormField` content and sibling `TimeframeSelector` or `Button` elements when visual refresh is enabled. (APPDEV-20731)
- Fixed the calendar toggle in `TimeframeSelector` drawing above an adjacent `Button`, such as an "Apply" button, when a sibling date/time field had focus, with visual refresh enabled. (APPDEV-20731)

#### Markdown

- Fixed a crash when a table re-renders after its cell content was changed outside of React, for example by browser translation. (APPDEV-20987)

#### MeterBarChart

- Updated the toolbar button to the small emphasized button style, matching the DataTable cell actions. (APPDEV-20771)

#### Microguide

- Reduced the border around the `Visual` from 2px to 1px to match the Visual Refresh. (APPDEV-20598)

#### MultiMeterBarChart

- Updated the toolbar button to the small emphasized button style, matching the DataTable cell actions. (APPDEV-20771)

#### NumberInputV2

- Fixed the inability to type decimal numbers with zeros after the decimal separator in controlled inputs. (APPDEV-20991)

#### SecretInput

- You can now use `SecretInput` to let users enter write-only secrets, such as API tokens, that are shown as a fixed mask and can only be replaced, never displayed again. (PS-51980)

#### SegmentSelector

- Reduced redundant segment requests by sharing one cached lookup between the trigger label, validation and segment selection. (APPDEV-20969)

#### SimpleTable

- Fixed custom cell and header renderers remounting on every render, which reset their state, focus, and text selection. (APPDEV-20987)

#### Stepper

- You can now build a guided multi-step flow with `createStepper()`, which returns a `Stepper` with `Stepper.Step` and `Stepper.Control`, plus the `useStepper` and `useStep` hooks. (APPDEV-19687)

#### TimeseriesChart

- Fixed compact annotation markers rendering extra shapes below them. Compact value markers are now a single rounded rectangle. (APPDEV-20778)

#### Tooltip

- Fixed a memory leak where each tooltip created a new mutation observer on every render and never released it on unmount. (APPDEV-21113)
- Fixed the border and shadow being cut off at the edge of the viewport by keeping a small gap between the tooltip and the edge, including on viewports narrower than the tooltip. (APPDEV-20900)

#### XYChart

- Fixed compact annotation markers rendering extra shapes below them. Compact value markers are now a single rounded rectangle. (APPDEV-20778)
- Fixed the crosshair and magnifiers staying visible after pinning an annotation tooltip while a chart tooltip was pinned. (APPDEV-21000)
- Fixed the crosshair being hidden behind the outline of highlighted bars and rectangles, so it is now always visible on top of them. (APPDEV-20209)
- Fixed the top label of a y-axis with a unit formatter overlapping the nearest tick label, so all y-axis labels stay readable. (APPDEV-20858)
- Fixed X-axis thresholds with `Infinity` or `-Infinity` bounds stopping 10px short of the plot edge, so their pills and background bands now extend to the edge like on the Y axis.
