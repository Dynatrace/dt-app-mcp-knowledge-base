## 3.17.0 (2026-10-29) \{#3170}

[Agentic upgrade instructions](https://developer.dynatrace.com/changelogs/design-system/components-changelog/agentic-update/3.17.0.md)

### Dependency updates

- `@dynatrace/strato-design-tokens` was updated to version `1.8.1`.

### Updates

#### General

- Visual Refresh boxShadow token overrides are now the default tokens. (APPDEV-20557)

#### Buttons

- Fixed missing behavior tracking attributes on overlays rendered outside their component and on the menu trigger, so user interactions are attributed to the correct component. (APPDEV-19827)

#### Charts

- Fixed the scrambled, reversed text and broken characters in middle-truncated chart texts, such as tooltip descriptions, that contain emoji. (APPDEV-20661)
- Fixed the missing screen reader announcement when copying a series name from the chart legend actions menu. (APPDEV-20401)

#### Editors

- Fixed `CodeEditor` and `DQLEditor` with a placeholder rendering far too tall when their container is resized shortly after mounting, for example in a drawer. (APPDEV-20753)

#### Forms

- Fixed missing behavior tracking attributes on interactive elements and on overlays rendered outside their component, so user interactions are attributed to the correct component. (APPDEV-19827)
- Added the `data-dt-component` attribute to `FormFieldMessages`. (APPDEV-19827)

#### Layouts

- `PageLayout.Details` now opens directly as a drawer on narrow screens when mounted conditionally, instead of briefly rendering its desktop layout. (APPDEV-20753)
- Fixed the top padding of the drawers in `PageLayout` and `Page`, which is now 20px instead of 16px. (APPDEV-20538)

#### AppHeader

- Removed the divider between the action items and the menus to reduce visual noise. (APPDEV-20791)
- Fixed missing behavior tracking attributes on the navigation and overflow menus, so user interactions with them are attributed to the correct component. (APPDEV-19830)

#### CategoricalBarChart

- CategoricalBarChart now uses XYChart as its underlying rendering engine. (APPDEV-19005)

#### Combobox

- Added `Combobox`, a single-select form control with an always-visible text input that lets users filter options or create new values by typing. (APPDEV-19437)

#### DataTable

- You can now disable the interactivity of individual rows with `interactiveRows.disableRowInteractivity`. (APPDEV-18040)
- Right pinned columns now resize in the direction of the arrow keys. (APPDEV-20496)
- Pinned columns now stay aligned with their header cells after resizing via the keyboard or double-click. (APPDEV-20496)
- Updated hover and focus states in interactive rows previously overriding the row's background color. (APPDEV-19746)
- Updated the cell and column action trigger button styles. (APPDEV-19746)
- Fixed layout when the table is empty and uses row actions: right-pinned columns are no longer offset by a gap. (APPDEV-20370)
- The Gantt column header now shows "No timestamps available." instead of an empty axis when the table has no data and the column has neither an `annotationsHeader` nor an explicit `min` and `max`. (APPDEV-20370)
- Fixed the issue that prevented keyboard navigation from moving past expanded rows when using `interactiveRows`. (APPDEV-18040)

#### DateTimePicker

- Fixed the focus trap that prevented users from moving focus backwards out of the input field with "Shift+Tab". (APPDEV-20483)

#### DQLEditor

- Fixed the issue that left the editor empty when entering text with Playwright's `fill()` in Firefox. (APPDEV-20683)

#### EmptyState

- You can now set `maxSize` to cap the size that `size="auto"` resolves to. (APPDEV-20535)
- You can now use the `preset` prop to show an empty state with or without a visual, plus a title and details about why the view is empty. (APPDEV-19760)
- Long details text no longer shrinks the visual or overflows when `size` is `large`. (APPDEV-19760)

#### FilterComposition

- Custom controls placed between `SegmentSelector` and `FilterField` now stay left aligned next to the `SegmentSelector` at tablet and mobile widths. (APPDEV-20689)
- Fixed the "Refresh" button switching to "Apply" when the `FilterField` value only differs from the applied value by leading or trailing whitespace. (APPDEV-20033)
- Controls next to the `FilterField` now stay aligned to the top when the `FilterField` grows to multiple lines.

#### FocusScope

- Fixed focus being lost to the page body when a scope closes after being opened from a control that was removed in the meantime, such as a button in a closing popover. Focus now returns to the element that was focused when the scope opened. (APPDEV-20773)

#### HelpMenu

- Fixed missing behavior tracking attributes on the built-in items and the package versions dialog, so user interactions with them are attributed to the correct component. (APPDEV-19830)

#### HoneycombChart

- Fixed the tile labels sometimes rendering in a fallback font because they were not redrawn once the fonts finished loading. (APPDEV-20419)

#### Menu

- Fixed the `Menu.ItemTooltip` being cut off at the viewport edge. It now narrows to the space beside the menu and moves above or below the item when neither side has room. (APPDEV-19818)
- Fixed the app icon of disabled intent items not being dimmed, so the whole item now looks disabled. (APPDEV-20792)

#### MessageContainer

- The close button now sets `data-dt-children-name`, so clicks on it are behaviorally tracked. (APPDEV-19827)

#### Modal

- Fixed tall content causing a second scrollbar and empty space at the bottom, so only the content area scrolls. (APPDEV-20716)
- Fixed the bottom padding on screens up to 640px wide, which is now 16px instead of 24px. (APPDEV-20540)

#### Page

- Fixed missing behavior tracking attributes on the drawers and the sidebar controls, so user interactions with them are attributed to the correct component. (APPDEV-19830)

#### PageLayout

- Fixed missing behavior tracking attributes on the root element, drawers, resize handles, and layout toggle, so user interactions with them are attributed to the correct component. (APPDEV-19830)

#### Radio

- You can now set behavior tracking attributes on `RadioGroup`. (APPDEV-19827)

#### Select

- Options now set `data-dt-children-name` by default, so clicks on them are behaviorally tracked. (APPDEV-19827)

#### Sheet

- Fixed the uneven padding around the content, so the scrollbar is now positioned by the browser. The padding on larger screens is now 20px. (APPDEV-18234)

#### TimeframeSelector

- Fixed the stepper losing the original duration after reaching the min or max value in controlled mode. (APPDEV-20490)
- Fixed an invalid timeframe being produced when the remaining time until the max value is smaller than the step precision. (APPDEV-20490)
- Fixed the Apply button not applying a valid calendar selection when the `defaultValue` lies outside `min` and `max`. (APPDEV-20490)
- Fixed the focus trap that prevented users from moving focus backwards out of the custom timeframe input field with "Shift+Tab". (APPDEV-20483)
- Clicks in the `Calendar` are now attributed correctly for behavior tracking. (APPDEV-19827)

#### TimeseriesChart

- Fixed mouse-wheel and two-finger scroll zoom moving too far per step, which made the zoomed range hard to control. Trackpad pinch zoom steps now shrink on narrow charts. (APPDEV-20729)

#### ToggleButtonGroup

- `ToggleButtonGroup.Item` now sets `data-dt-children-name` by default instead of `data-dt-name`, so clicks on its content are behaviorally tracked. (APPDEV-19827)

#### Tooltip

- Fixed the open delay still running after the trigger was unmounted, which let the next tooltip skip its delay and caused unhandled `window is not defined` errors in jsdom-based test runs. (APPDEV-20717)

#### TopList

- Fixed visual artifacts in printed bar labels. (APPDEV-20369)

#### TreeMap

- Fixed the rendering error caused by repeated legend color updates. (APPDEV-20481)

#### XYChart

- Fixed span colors flickering and the hover highlight rendering partially or not at all after zooming in and out repeatedly in the FlameGraph. (APPDEV-20668)
- Fixed the relative axis domain not matching the drawn stacked and grouped bars and stacked areas with a varying mix of positive and negative values, which clipped the bars or left the axis too wide. (APPDEV-20488)
- The default tooltip header now shows seconds for timeframes shorter than 1 minute. (APPDEV-13027)
- Fixed visual artifacts in printed bar labels and duplicated axis tick labels in printed charts. (APPDEV-20369)
- Fixed mouse-wheel and two-finger scroll zoom moving too far per step, which made the zoomed range hard to control. Trackpad pinch zoom steps now shrink on narrow charts. (APPDEV-20729)
