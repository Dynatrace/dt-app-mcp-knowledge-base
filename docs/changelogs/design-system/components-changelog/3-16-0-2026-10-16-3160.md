## 3.16.0 (2026-10-16) \{#3160}

[Agentic upgrade instructions](https://developer.dynatrace.com/changelogs/design-system/components-changelog/agentic-update/3.16.0.md)

### Deprecations

#### DQLEditor

- The `enableValidationState` migration flag, the legacy `onValidityChange` payload (`DQLEditorValidityInfo[]`), and the `onValidationStart` / `onValidationEnd` props will be removed in the next major release. `ValidationState` will become the default. (APPDEV-18724)

### Updates

#### Charts

- Fixed the missing error details in the logs when a chart fails to render. (APPDEV-20185)
- Fixed the premature truncation of chart labels that contain non-breaking spaces, such as currency values. (APPDEV-20376)
- Zooming via mouse wheel or trackpad pinch now produces a visible domain change per gesture on every chart that supports zoom (previously either gesture required dozens of small events to shift the domain noticeably). (APPDEV-20018)

#### Layouts

- Fixed the crosshair axis labels of charts in the page content rendering on top of the details panel in overlay mode. (APPDEV-20358)

#### AnnotationsChart

- `AnnotationsActionsHandler` now also accepts a deferred callback (`() => SeriesActionsTemplate`) so operations are not triggered on every mouse event. (APPDEV-18339)
- Fixed time tooltip headers displaying a redundant x-axis label. (APPDEV-20446)

#### Breadcrumbs

- Fixed the overflow menu missing behavior tracking attributes. (APPDEV-19828)

#### CodeEditor

- Fixed clicks on the "Reset" button in the error state not being attributed to the component for behavioral tracking. (APPDEV-19861)
- Form validation messages are now routed correctly to the form outlet, and failed submissions move focus to the invalid editor. (APPDEV-18724)

#### DataTable

- Fixed the horizontal scroll position being slightly offset in virtualized tables. (APPDEV-20095)
- Fixed the issue that kept row reordering and column reordering in the column settings active after clicking elsewhere while dragging with the keyboard. (APPDEV-20328)
- Fixed the "Pinned to left" and "Pinned to right" sections not showing in the column settings modal when it is rendered without `DataTable.ColumnPinningSettings`. (APPDEV-20387)
- Columns of a `fullWidth` table with right-pinned columns now resize together, so shrinking one no longer opens a gap in front of the pinned columns. The freed width goes to the last non-pinned column, or to the first right-pinned column when the last non-pinned one is the one being shrunk. (APPDEV-17640)

#### DQLEditor

- You can now opt into the standard `ValidationState` API with the `enableValidationState` flag. The editor also supports `required`, `validate()` on the ref, and `<Form>` submission. (APPDEV-18724)
- Fixed clicks on the "Reset" button in the error state not being attributed to the component for behavioral tracking. (APPDEV-19861)

#### EmptyState

- Added `size="auto"`, which automatically adapts the size of the empty state to the width of its parent element. (APPDEV-19808)
- Fixed the brief jump of `size="large"` in the layout when the component first appeared. (APPDEV-19808)

#### FilterField

- Fixed clicks on the "Reset" button in the error state not being attributed to the component for behavioral tracking. (APPDEV-19861)
- Fixed `addFilter` duplicating existing statements instead of merging into them when the value contains JSONPath keys or an incomplete statement for the target key. (APPDEV-20257)

#### FocusScope

- Fixed the focus that returned to the wrong element and caused an unwanted scroll in Safari after closing an overlay opened with a pointer click. (APPDEV-20319)
- Fixed the issue that opened the soft keyboard on mobile viewports because initial focus moved to a text field. (APPDEV-20363)

#### HistogramChart

- Fixed pinned annotation tooltips remaining visible while zooming or panning. (APPDEV-20446)

#### Menu

- Fixed behavior tracking not capturing pointer interactions on the trigger when clicking to open the menu. (APPDEV-19828)

#### NotificationSettings

- Fixed the notification toggle button missing behavior tracking attributes. (APPDEV-19828)

#### Page

- Fixed the root layout element forming a scroll container, which caused the page to scroll out of view when a hidden native input inside the layout received focus. (APPDEV-19972)

#### ResponsiveGrid

- You can now use `ResponsiveGrid`, a responsive alternative to `Grid`, to change the column count based on the grid's own width. (APPDEV-19762)

#### SegmentSelector

- Fixed the identical accessible names of the remove buttons in the overlay, which now include the segment name and its selected variable values. (APPDEV-20395)
- Fixed the on-screen keyboard opening automatically when the overlay opens on mobile viewports. (APPDEV-20365)
- Fixed the full-screen application error when reopening the overlay while segments load. (APPDEV-20470)

#### Select

- Fixed the inconsistent semantics for the "Select all" control in multi-select lists. (APPDEV-20177)
- Reduced unnecessary rerenders when the parent of the `Select` updates. (APPDEV-20240)
- Fixed the on-screen keyboard opening automatically when the menu opens on mobile viewports. (APPDEV-20365)

#### Sheet

- Fixed the soft keyboard opening on mobile viewports when the sheet finishes opening, because initial focus no longer moves to a text input. (APPDEV-20366)
- Fixed the issue that squeezed the actions when the title is long. The actions now keep their width and wrap, and the title truncates with an ellipsis. (APPDEV-18495)

#### SingleValue

- Fixed the issue that clipped the label text or made its font size smaller than necessary, and stabilized the font size calculation when fonts load. (APPDEV-20149)

#### SingleValueGrid

- Stabilized the font size calculation when fonts load, fixed value font size. (APPDEV-20149)

#### Tabs

- Fixed missing or incorrect behavior tracking attributes on the tabs, the tab list scroll buttons, and the component itself. (APPDEV-19828)

#### TimeframeSelector

- Fixed typed characters being ignored after an expression trigger key when both expression inputs were selected. (APPDEV-19967)
- Fixed typing being ignored in expressions when space was selected. (APPDEV-19968)
- Fixed expression trigger characters being placed in the "to" input instead of "from" when selecting all in a mixed relative/absolute picker. (APPDEV-19968)
- Fixed placeholder text being visually selected when pressing Ctrl+A on an empty picker. (APPDEV-19968)

#### TimeseriesChart

- Fixed pinned annotation tooltips remaining visible while zooming or panning and removed redundant x-axis labels from time tooltip headers. (APPDEV-20446)

#### Toast

- The `data-dt-component` attribute is now set correctly on the toast element. (APPDEV-19828)

#### XYChart

- Fixed the axis tick labels showing the unit before the number (for example "ms 10") when `truncation` is set to `start`. (APPDEV-20409)
- Fixed pinned annotation tooltips remaining visible while zooming or panning. (APPDEV-20446)
