## 3.15.0 (2026-10-01) \{#3150}

[Agentic upgrade instructions](https://developer.dynatrace.com/changelogs/design-system/components-changelog/agentic-update/3.15.0.md)

### Dependency updates

- `@dynatrace/strato-design-tokens` was updated to version `1.8.0`.

### Deprecations

#### CategoricalBarChart

- `DownloadCSV` will be removed once the download button is enabled by default for this chart. (APPDEV-18945)

#### CodeSnippet

- `showCopyAction` and `onCopy` will be removed and replaced by `CodeSnippet.ActionsMenu` with `CodeSnippet.Copy`, which takes the `onCopy` prop. (APPDEV-19581)

#### HistogramChart

- `DownloadCSV` will be removed — the download button is now enabled by default and the slot is no longer needed. (APPDEV-18945)

### Updates

#### General

- The visual refresh is now the default styling; the design tokens now carry visual-refresh values. Setting `globalThis.dtVisualRefreshEnabled` to `false` restores the classic values. (APPDEV-19979)
- Fixed a tree shaking regression where importing any component from a subpackage entry point (e.g. `@dynatrace/strato-components/content`) caused unrelated dependencies to be included in the bundle.

#### Charts

- Fixed the panning controls slide-in animation playing when `prefers-reduced-motion: reduce` is active. (APPDEV-19888)
- Fixed the tooltip header overflowing its container when the text contained no word-break opportunities, in `start`, `middle`, and single-line truncation modes. (APPDEV-20098)
- Fixed a crash that occurred when drawing canvas gradients. (APPDEV-19841)
- Fixed the `seriesActions` callback receiving data from the wrong series when 10 or more series were present. (APPDEV-20030)
- Fixed `Legend` not updating its series labels when the chart re-renders with new series names but the same series IDs and colors. (APPDEV-20263)

#### Core

- You can now register a keyboard shortcut from any component with the `useKeyboardShortcut` hook. (APPDEV-19758)

#### Filters

- Portaled overlays in `FilterField`, `SegmentSelector`, `TimeframeSelector`, and `FilterBar` now carry the correct behavioral tracking attributes. (APPDEV-19825)

#### Layouts

- Fixed the resize separator being exposed as a zero-sized element under the visual refresh, which hid it from assistive technology. (APPDEV-19979)
- Fixed the mobile drawer width of `Page.Sidebar`, `Page.DetailView`, `PageLayout.Sidebar`, and `PageLayout.DetailView` to use 85% of the available width instead of 75%. (APPDEV-19995)
- Fixed the sidebar collapse and expand buttons announcing a redundant state to assistive technology. (APPDEV-19993)

#### AiResponse

- Markdown tables are now rendered using `DataTable`, with sortable, resizable, and line-wrappable columns. (APPDEV-19223)

#### AvatarGroup

- Added `data-dt-children-name` on the overflow trigger button for behavioral tracking. (APPDEV-19826)

#### Chip

- Updated border and close button styling based on visual refresh (APPDEV-18674)
- Fixed behavioral tracking on `Chip.DeleteButton`. (APPDEV-19826)

#### CodeEditor

- Fixed `onValidityChange` emitting a spurious `'aborted'` state on every keystroke during async linting, which caused validation messages to flicker mid-edit; errors are now preserved from the last settled lint run while revalidation is in progress. (APPDEV-20042)

#### CodeSnippet

- You can now add `CodeSnippet.Copy` and/or `CodeSnippet.Download` actions via the new `CodeSnippet.ActionsMenu` slot. (APPDEV-19581)

#### DataTable

- Improved interaction performance for scrolling, hiding a column, opening column settings, and activating a row, with the largest gains in tables that have many hidden columns. (APPDEV-19021)
- Fixed the initial header height estimate overshooting by 1px under the visual refresh, which added an unnecessary vertical scrollbar on the first render. (APPDEV-19979)
- Fixed an issue with keyboard navigation where closing a row actions menu moved focus to the page instead of back to the trigger. (APPDEV-20022)
- Fixed an issue where the arrow key navigation closed an open cell or row actions menu and moved focus to the next row when row interactivity was enabled.
- Fixed datetime and numeric column types producing incorrect output for invalid inputs across all rendering paths (with formatter, without formatter, and CSV export): whitespace-only strings in `datetime` columns rendered as epoch zero, empty strings and non-numeric values (booleans, arrays, `Infinity`) in `number`, `currency`, and `bit` columns were formatted as numbers, and invalid `Date` instances threw a `RangeError` during CSV export. (APPDEV-19594)
- Datetime and numeric cell values now produce consistent output for all input types (ISO-8601 strings, epoch timestamps, numeric strings, and Date instances) regardless of whether a column `formatter` is configured, including during CSV export. (APPDEV-19594)
- Fixed keyboard activation and double-click on the column resize handle incorrectly triggering column sort. (APPDEV-20123)
- Fixed behavior tracking attributes across interactive sub-elements and added tracking for drag-and-drop interactions. (APPDEV-19054)
- Added the `anchorScrollTo` prop to control which edge of the list the scroll position is anchored to when data changes. (APPDEV-20147)

#### DateTimePicker

- Fixed `onChange` to fire when selecting a date from the calendar popover with `type="date"` in UTC or UTC-equivalent timezones. (APPDEV-20094)

#### DQLEditor

- Autocomplete suggestions now display type and description text inline below the label on smaller viewports, replacing the side overlay panel with a compact layout. (APPDEV-13419)

#### FilterComposition

- You can now offer filter actions from any menu with `_FilterCompositionMenuGroup`. It renders one menu item per filter operation available for a key/value pair, and selecting an item writes the statement into the composition's `FilterField`. The group names its composition by id, so it works from a menu rendered anywhere in the app, such as a table cell menu. (APPDEV-19484)

- You can now wire `FilterField`, `TimeframeSelector`, and `SegmentSelector` into a single apply lifecycle with shared validation, cancellation, and server-error handling. (APPDEV-18400)

#### FilterField

- Added additional safeguards against crashes when clicking into the input. (APPDEV-19024)
- Fixed the duplicate submission that occurred when the field was the only control in a form and also handled `onFilter`. (APPDEV-19297)
- Added `getFilters`, the read counterpart to `addFilter` and `removeFilter`. It returns every statement a FilterField value string holds for a key, with the operator and the values each one carries, so you can check whether a key is already filtered before adding another statement. Pass the optional `valueType` and `options.parserConfig` arguments to get back only the statements whose value is of the type you declared. (APPDEV-19484)
- Fixed the issue that prevented `removeFilter` from removing statements whose key is a JSONPath. (APPDEV-19484)
- Fixed the visual refresh styling of the suggestion prefix icons: data type icons now sit in a 20x20 pixel container with chip styling, while the search, recent and pasted content icons are shown as plain 20x20 pixel icons. (APPDEV-19814)
- Fixed the left icon inset and icon-to-text gap in visual refresh mode to match the spacing of other input fields. (APPDEV-19657)
- Fixed an error when importing `FilterField` in non-browser contexts like SSR or Node builds. (APPDEV-20227)
- Fixed the suggestions in the visual refresh using the default hover background instead of the emphasized one. (APPDEV-19623)
- Fixed the issue that made IP address, UID, timestamp, and Smartscape ID values render as an empty token in pinned and recent filter suggestions. (APPDEV-20091)
- Fixed the dotted error underline rendering inconsistently when a token has overlapping or neighbouring errors. (APPDEV-19777)
- Fixed the missing "use as value" suggestion and the validation of free-form values for keys that combine literal `valuePredicate` values with `valueType`. (APPDEV-20124)

#### HelpMenu

- Fixed the `feedback` entry set to `'default'` opening the "Open with" app chooser instead of the feedback form, which now also receives the app name and version. (APPDEV-19670)
- `aria-label`, `aria-labelledby`, `aria-describedby`, and `aria-details` can now be passed to `HelpMenu` and are forwarded to the menu content panel. (APPDEV-19984)

#### HistogramChart

- `HistogramSeries` now accepts custom user-defined properties, which are forwarded to each XY bin and available in `seriesActions` callbacks. (APPDEV-18698)

#### KeyboardShortcut

- Fixed the shortcut losing contrast when placed inside a `Button` prefix/suffix on an accent surface. (APPDEV-19926)
- Fixed the keys inside an accent `Container` always using the neutral on-accent text color instead of the one matching the container's color, which made them fall below the WCAG AA contrast threshold. (APPDEV-19979)
- `keys` now accepts `mod`, which renders as "Cmd" on macOS and "Ctrl" on every other platform, or as an appropriate object for a combination that differs per platform. (APPDEV-19759)

#### KeyboardShortcutTooltip

- `keys` now accepts `mod`, which renders as "Cmd" on macOS and "Ctrl" on every other platform, or as an appropriate object for a combination that differs per platform. (APPDEV-19759)

#### Menu

- Added a push animation to the mobile drill-down menu, with simultaneous slide and fade transitions for entering and exiting panels. (APPDEV-19507)

- You can now handle pointer and focus events outside an open menu via the new `onInteractOutside` prop on `Menu.Content`. (APPDEV-19583)

- `Menu.Content` now accepts an `aria-describedby` prop to associate a supplementary description with the menu panel. (APPDEV-20146)

- Fixed the issue that prevented navigating and selecting menu items with the keyboard on mobile viewports. (APPDEV-19952)

- SubTrigger, SubContent, Label, and ItemTooltip now expose default props (className, style, data-testid, `aria-*`, `data-dtrum-*`) on their root elements (APPDEV-18015)

#### Modal

- Fixed the stacking order when responsive details drawers open. (APPDEV-19780)

#### Page

- Fixed the panels rendering 8px wider than their `minWidth` under the visual refresh, where the resize handle no longer takes space of its own. (APPDEV-19979)

#### SegmentSelector

- Added a non-blocking warning in the overlay when the selected segment doesn't cover a view's declared data needs, set via `<SegmentsProvider requires>` or `<SegmentApplicabilityProvider requires>`. (PAPA-34065)

#### Select

- Fixed the `onBlur` callback not being called when `controlState` is set. (APPDEV-20176)

#### TimeframeSelector

- Fixed the cursor always jumping to the beginning of the expression field when clicking inside it. (APPDEV-19626)

#### TimeseriesChart

- Fixed the tooltip accumulating duplicate name entries on successive hovers when multiple series dimensions share the same display name. (APPDEV-20143)
- Areas now render with a more translucent fill, so large and overlapping areas stay readable. The area outline and its data points keep their previous opacity.

#### XYChart

- Fixed the pinned tooltip remaining visible and interactive while dragging an x-zoom selection. (APPDEV-20066)
- Fixed the stacking of area series with millisecond-precision timestamps and no `end` field when multiple datapoints fall within the same second on TimeSeries adoption. (APPDEV-20154)
- Fixed drag interactions triggering tooltip and crosshair side effects when `XYChart.Select` was disabled. Selection magnifier labels are now also suppressed when `hideCrosshair` is set on the axis. (APPDEV-19964)
- `AreaSeries` now renders with a more translucent fill, so large and overlapping areas stay readable. The area outline and its data points keep their previous opacity.
- Fixed an issue where datapoints outside the visible viewport were shown in the shared tooltip. (APPDEV-19860)
