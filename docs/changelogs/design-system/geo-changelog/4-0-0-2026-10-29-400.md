## 4.0.0 (2026-10-29) \{#400}

[Agentic upgrade instructions](https://developer.dynatrace.com/changelogs/design-system/geo-changelog/agentic-update/4.0.0.md)

### Breaking changes

#### MapView

- The `@dynatrace-sdk/client-classic-environment-v2` peer dependency was replaced with `@dynatrace-sdk/client-settings@^1.1.0`. Install `@dynatrace-sdk/client-settings` in your app dependencies to continue fetching map settings. (APPDEV-18503)

- The bundled `maplibre-gl` dependency was upgraded from v5 (`~5.24.0`) to v6 (`~6.11.0`). The CJS build was removed; only the ESM build is published. (APPDEV-20772)

- React 18 is no longer supported. The `react` and `react-dom` peer dependency requirement was tightened to `^19.0.0`. (APPDEV-20772)

### Dependency updates

- `@dynatrace/strato-design-tokens` was updated to version `1.8.1`.
- `@dynatrace/strato-components` was updated to version `3.17.0`.
- Removed `@dynatrace-sdk/client-classic-environment-v2` as a peer dependency. (APPDEV-18503)
- Added `@dynatrace-sdk/client-settings` as a peer dependency with version range `^1.1.0`. (APPDEV-18503)
- Changed peerDependency version range for `react-intl` from `^6.0.8 || ^7.0.0` to `^7.0.0`. (APPDEV-20772)
- Changed peerDependency version range for `@dynatrace-sdk/client-platform-management-service` from `^1.7.0` to `^1.9.0`. (APPDEV-20772)

### Updates

#### ChoroplethLayer

- Fixed an issue where deselecting a country while zoomed in left countries outside the viewport incorrectly dimmed. (APPDEV-20747)
