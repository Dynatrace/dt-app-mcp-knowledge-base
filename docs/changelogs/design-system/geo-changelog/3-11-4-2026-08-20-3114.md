## 3.11.4 (2026-08-20) \{#3114}

### Dependency updates

- `@dynatrace/strato-components` was updated to version `3.11.3`.

### Updates

#### MapView

- Fixed the issue that caused custom map tooltips to crash when users pinned a tooltip and moved focus to the toolbar. (APPDEV-19530)
- `MapView` now accept `aria-label`, `aria-labelledby`, `aria-describedby`, and `aria-details` props, allowing you to provide meaningful accessible names for screen readers. (APPDEV-18646)
