## Build different types of apps

Imagine the **App Toolkit** as a set of building blocks you can pick and choose from to achieve your task. You can use them to:

- Extend a [workflow](https://dt-url.net/2r235v0) with [custom actions](https://developer.dynatrace.com/develop/guides/workflows/create-custom-action.md).
- Employ [app functions](https://developer.dynatrace.com/develop/guides/app-functions/create-consume.md) to build an API-only app:
  - Ensure that you can [access platform APIs from outside](https://developer.dynatrace.com/develop/guides/access-platform-apis-from-outside.md).
- Build a custom app with [DQL](https://dt-url.net/DQL-Docs) and the [Strato Design System](https://developer.dynatrace.com/contents/docs/design/index.md/), as you've done in the tutorial.
