## 1. Create our first component

First, open the `host-insights` directory in your preferred code editor. You'll notice a fair amount of code. It's all generated by the [App Toolkit](https://developer.dynatrace.com/quickstart/app-toolkit.md).

Create a new file called `HostList.tsx` in `ui/app/pages`. It will be the main component of the app. As a starting point, copy the following code into the `HostList.tsx` file:

```tsx testable title="ui/app/pages/HostList.tsx"
import React from 'react';
import { Flex } from '@dynatrace/strato-components/layouts';
import { TitleBar } from '@dynatrace/strato-components/layouts';

export const HostList = () => {
  return (
    <Flex width="100%" flexDirection="column" justifyContent="center" gap={16}>
      <TitleBar>
        <TitleBar.Title>Hosts Insights</TitleBar.Title>
      </TitleBar>
    </Flex>
  );
};
```

> **Tip**
>
> Learn more about [Flex](https://developer.dynatrace.com/contents/docs/design/components/layouts/Flex/index.mdx/) and [TitleBar](https://developer.dynatrace.com/contents/docs/design/components/layouts/TitleBar/index.mdx/).

Next, update `ui/app/App.tsx` to include the `HostList` component and adapt the app header like the following:

```tsx title="ui/app/App.tsx"
import {
  PageLayout,
  // highlight-next-line
  AppHeader,
} from '@dynatrace/strato-components/layouts';
import React from 'react';
import {
  Route,
  Routes,
  // highlight-next-line
  Link,
} from 'react-router-dom';
// highlight-next-line
import { HostList } from './pages/HostList';

export const App = () => {
  return (
    <PageLayout>
      <PageLayout.Header>
        // highlight-start
        <AppHeader>
          <AppHeader.Navigation>
            <AppHeader.Logo as={Link} to="/" />
          </AppHeader.Navigation>
        </AppHeader>
        // highlight-end
      </PageLayout.Header>
      <PageLayout.Content>
        // highlight-start
        <Routes>
          <Route path="/" element={<HostList />} />
        </Routes>
        // highlight-end
      </PageLayout.Content>
    </PageLayout>
  );
};
```

> **Tip**
>
> Learn more about [AppHeader](https://developer.dynatrace.com/contents/docs/design/components/layouts/AppHeader/index.mdx/) and [Link](https://reactrouter.com/v6/components/link).

After saving all the files, you should see the title bar from the `HostList` component in the browser.
