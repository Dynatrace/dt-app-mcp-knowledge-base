## Before you start

You should have a basic understanding of React and TypeScript to do this tutorial manually. See [Learn React](https://developer.dynatrace.com/quickstart/learn-react.md) and [Learn TypeScript](https://developer.dynatrace.com/quickstart/learn-typescript.md) to brush up on those. Alternatively, see [Build apps with AI](https://developer.dynatrace.com/quickstart/app-development-with-ai.md) to build your Dynatrace App with AI—no React or TypeScript knowledge needed.

To continue this tutorial, head to the [Create a new app](https://developer.dynatrace.com/quickstart/tutorial/create-new-dynatrace-app.md) page, and let's begin.
