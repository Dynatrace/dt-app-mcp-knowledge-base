## 1. Create app function

First, execute the following command in the project's root directory:

```bash
npx dt-app function create get-status-history
```

You'll notice that the [App Toolkit](https://developer.dynatrace.com/quickstart/app-toolkit.md) creates a file named `get-status-history.function.ts` in the `api` directory within your root project directory and prints information about the newly created function.
