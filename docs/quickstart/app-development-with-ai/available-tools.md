## Available tools

The App Development MCP server exposes these tools:

- `list_strato_components`—lists Strato components by name or keyword.
- `get_strato_component`—gets detailed component docs, props, and examples.
- `get_strato_usecases`—gets the full code for Strato component use cases.
- `get_experience_standard`—gets app experience standards by keywords.
- `get_dql_knowledgebase`—gets a semantic search over the DQL knowledge base.
- `list_sdks`—lists available Dynatrace SDK documentation packages.
- `get_sdk`—gets the complete documentation for a specific SDK package.
