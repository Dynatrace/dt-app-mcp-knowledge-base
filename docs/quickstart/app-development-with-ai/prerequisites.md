## Prerequisites

Before setting up AI assistance for app development:

- You'll need a code editor, such as **Visual Studio Code**. Run `node --version` in the terminal of your code editor and ensure that it returns a version starting with `v24`.
- Install an AI development tool that supports MCP. We recommend [Claude Code](https://claude.ai/code).
- Optionally—only if you plan to use an AI tool inside Visual Studio Code—make sure you have Visual Studio Code 1.102 or higher, which is required for MCP support.
