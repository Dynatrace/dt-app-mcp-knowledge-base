## Installation

You can install the Dynatrace Apps extension for Visual Studio Code from the [Microsoft Visual Studio Code Marketplace](https://marketplace.visualstudio.com/items?itemName=dynatrace.dynatrace-apps) or directly from the extensions tab inside your VS Code IDE.

For **Cursor** or other compatible editors, install the Dynatrace Apps extension from [open-vsx.org](https://open-vsx.org/extension/dynatrace/dynatrace-apps).
