Build smarter and faster for the Dynatrace platform: The **Dynatrace Apps extension for Visual Studio Code and Cursor** helps developers create, test, and debug apps for the Dynatrace platform directly in their favorite IDEs.

:::note Supported IDEs
The Dynatrace Apps extension is available for **Visual Studio Code**, **Cursor**, and any editor that supports extensions from [open-vsx.org](https://open-vsx.org/extension/dynatrace/dynatrace-apps). To install in these editors, download the extension from [open-vsx.org](https://open-vsx.org/extension/dynatrace/dynatrace-apps).
:::
