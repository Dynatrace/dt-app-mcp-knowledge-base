- [Learn React](https://developer.dynatrace.com/quickstart/learn-react.md): Learn the basics to start building apps with React.
- [Learn TypeScript](https://developer.dynatrace.com/quickstart/learn-typescript.md): Get started with TypeScript with these basics.
