## Plan ahead for Strato 4.0

The next major Strato version (expected around end of CQ1) will require React 19, replace Jest with Vitest, and ship ES modules only. Nothing to act on today, but worth bookmarking [Upcoming changes](pathname:///release-notes/design-system/upcoming-changes/)—and if you're still on Jest, [Create unit tests with Vitest](pathname:///develop/test-and-troubleshoot/test/create-unit-tests-vitest/) is already published.
