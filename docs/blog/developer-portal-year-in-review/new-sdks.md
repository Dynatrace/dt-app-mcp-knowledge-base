## New SDKs

Four new `@dynatrace-sdk` packages are now documented on the portal:

- **[client-filter-segment-management](pathname:///develop/sdks/client-filter-segment-management/)** — manage filter segments programmatically.
- **[client-resource-store](pathname:///develop/sdks/client-resource-store/)** — read and write resources in the Dynatrace resource store.
- **[client-service-level-objectives](pathname:///develop/sdks/client-service-level-objectives/)** — query and manage SLOs from your app.
- **[client-synthetic](pathname:///develop/sdks/client-synthetic/)** — interact with Dynatrace Synthetic from app code.

The [SDKs overview](pathname:///develop/sdks/overview/) page is also new — a single place to see all available packages and what each one does. A version picker on each SDK reference page lets you switch between the latest publicly released version, the latest internal preview release, and past major versions.
