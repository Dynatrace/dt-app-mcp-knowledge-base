## From the Strato design system

- **PageLayout**—the new, more flexible replacement for `Page`, with composable slots and a split-or-overlay details panel. See the [PageLayout component](pathname:///design/components/layouts/PageLayout/) and its [migration guide](pathname:///design/components/layouts/PageLayout/migration/).
- **Accessibility foundation**—a new design-foundation page covering what you need to build inclusive apps — WCAG 2.2 AA, and what Strato handles for you. See [Accessibility](pathname:///design/foundations/accessibility/).
- **TimeframeSelector**—from `@dynatrace/strato-components` v3.1+, it shows users their recently used timeframes automatically — no code changes required. See [TimeframeSelector](pathname:///design/components/filters/TimeframeSelector/).
- **XYChart**—a low-level, composable option for charts the ready-made components can't build — heatmaps, scatterplots, and more. See [XYChart](pathname:///design/data-visualizations/charts/XYChart/).
