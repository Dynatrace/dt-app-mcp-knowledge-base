## Fields that read as interactive

Fields are now outlined and bright rather than filled. An empty field reads
immediately as somewhere you can enter text, and a form full of different
fields feels lighter and uncrowded.

Gray now does a more specific job. Read-only and disabled fields keep a gray
background, which makes those states unmistakable at a glance. Now, gray
reliably means "you can't edit this." Chips follow the same rule, trading
solid blocks for outlines.
