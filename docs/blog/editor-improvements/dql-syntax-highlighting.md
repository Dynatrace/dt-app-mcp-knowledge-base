## DQL syntax highlighting

Several DQL token types that had no highlighting before now have distinct highlighting:

- Boolean keywords (`true`, `false`)
- Numbers and unit tokens (`1h`, `500ms`)
- The `null` keyword
- Triple-quoted strings (improved highlight boundaries)

These are automatic. No configuration required.
