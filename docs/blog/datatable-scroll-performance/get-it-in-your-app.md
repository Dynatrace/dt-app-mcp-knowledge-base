## Get it in your app

Update to `@dynatrace/strato-components` 3.18 or later. Your heavy tables get faster with no code changes. For the full list of changes, see the [Strato components 3.18.0 changelog](pathname:///changelogs/design-system/components-changelog/#3180).

:::tip Let virtualization do its work
`DataTable` only renders the rows you can see when its height is limited. In development, the table now warns you when it renders more than 100 rows because its height isn't limited. Place the table in a container with a definite height to get the full benefit.
:::
