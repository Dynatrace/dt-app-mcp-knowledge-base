## When not to use

- To choose one or more options from a predefined list of related items that don't trigger immediate events. For example, selecting a timezone in a form. Use [Select](https://developer.dynatrace.com/design/components/forms/Select.md) instead.
- For disclosure patterns, such as revealing a panel of links or text. Use [Accordion](https://developer.dynatrace.com/design/components/content/Accordion.md) or [ExpandableText](https://developer.dynatrace.com/design/components/content/ExpandableText.md) instead.
