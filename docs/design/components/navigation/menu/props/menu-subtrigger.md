## Menu.SubTrigger

Use the `Menu.SubTrigger` to wrap the element that should open the submenu.

**`MenuSubTriggerProps`**

| Prop        | Type      | Default | Description                                                                                                                                                                                        |
| ----------- | --------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `disabled`  | `boolean` |         | Whether the menu trigger item is disabled. If true, it prevents the user from interacting with the item.                                                                                           |
| `textValue` | `string`  |         | Optional text used for typeahead purposes. By default, the typeahead behavior will use the .textContent of the item. Use this when the content is complex, or you have non-textual content inside. |
