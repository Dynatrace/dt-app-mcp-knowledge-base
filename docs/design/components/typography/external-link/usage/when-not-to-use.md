## When not to use

- When the information is critical, when users need to stay in their current flow, or when the destination isn't trustworthy or secure.
- To navigate to another page within an app or view. Use [Link](https://developer.dynatrace.com/design/components/typography/Link.md) instead.
- To continue a user flow in another Dynatrace app. Use [IntentButton](https://developer.dynatrace.com/design/components/buttons/IntentButton.md) instead.
- To trigger actions or events. Use [Button](https://developer.dynatrace.com/design/components/buttons/Button.md) instead.
