The `Blockquote` component wraps longer text blocks and indicates that the passage is quoted from another source.

**`BlockquoteProps`**

| Prop   | Type     | Default | Description                                                                                                                                                                      |
| ------ | -------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cite` | `string` |         | A URL that designates a source document or message for the information quoted. This attribute is intended to point to information explaining the context for the quoted content. |
