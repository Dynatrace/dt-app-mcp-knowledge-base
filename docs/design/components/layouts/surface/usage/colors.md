## Colors

Surfaces come in five semantic colors, which are noticeable when interactive and selected or focused.

![Five Surface colors — Neutral, Primary, Success, Warning, and Critical — each shown as a white surface with a colored border.](https://developer.dynatrace.com/assets/images/surface-colors-light-5a0ad73db6eca20f587ec280bf04323a.webp)&#x20;

### Neutral

- Use the neutral color for surfaces that shouldn't stand out.
- Use the neutral color to indicate that a surface is currently selected.
- The neutral color has no semantic meaning and is therefore used by default.

### Primary

- Use the primary color to highlight a surface without conveying concern.
- Use primary colored surfaces sparingly, once per view or context at most.
- Avoid using the primary color to indicate a selected surface. Use `'neutral'` instead.

### Success

- Use the success color to indicate a positive condition of the surface's content.
- Don't overuse the success color. Doing so would diminish the relative visibility of warning and critical conditions that require the user's attention.

### Warning

- Use the warning color to indicate an upcoming or potential negative condition of the surface's content.

### Critical

- Use the critical color to indicate a negative condition of the surface's content that requires immediate attention. :::tip

Learn more about the semantic meaning of colors in [Status and health](https://developer.dynatrace.com/design/patterns/status-and-health.md).

:::
