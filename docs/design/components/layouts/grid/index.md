The `Grid` component can be used to layout its children with the help of CSS Grid. The component can be customized with CSS grid props.

To change the column count with the width of the component, use the [ResponsiveGrid](https://developer.dynatrace.com/design/components/layouts/ResponsiveGrid.md) component.

More information about [CSS Grid](https://developer.mozilla.org/en-US/docs/Web/CSS/grid).
