## Responsive behavior

Below its `breakpoint` a panel renders as a `Drawer`. An uncontrolled sidebar auto-collapses at the breakpoint. A details panel keeps its open/closed state. See [Responsive behavior](https://developer.dynatrace.com/design/components/layouts/PageLayout.md#responsive-behavior) in the Overview tab for the full contract, and [Layout hierarchy](https://developer.dynatrace.com/design/components/layouts/PageLayout.md#layout-hierarchy) in the Overview tab for how the breakpoint is measured for each panel.
