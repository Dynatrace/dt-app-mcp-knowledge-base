## PageLayout.Details

The `PageLayout.Details` is the optional right panel. It supports two layout modes (`split` and `overlay`) in addition to the responsive drawer mode.

**`PageLayoutDetailsProps`**

| Prop             | Type                                           | Default   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------- | ---------------------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `minWidth`       | `PanelWidth`                                   | `320`     | The minimum width of the details panel, applied in both split and overlay layouts. Accepts a pixel value or a percentage string.                                                                                                                                                                                                                                                                                                                                                                                                             |
| `maxWidth`       | `PanelWidth`                                   |           | The maximum width of the details panel, applied in both split and overlay layouts. Accepts a pixel value or a percentage string. The container edge is always the hard ceiling. Unset by default: in split the panel is bounded by the content keeping \~half the width, and in overlay only by the container. In split mode, the effective maximum is also constrained by \`PageLayout.Content\`'s \`minWidth\` (default \`'50%'\`); to allow a wider details panel in split mode, lower \`PageLayout.Content\`'s \`minWidth\` accordingly. |
| `defaultWidth`   | `PanelWidth`                                   | `'25%'`   | The initial width of the details panel. Accepts a pixel value or a percentage string.                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `width`          | `PanelWidth`                                   |           | Controlled width of the details panel. Accepts a pixel value or a percentage string and is clamped to fit the current layout mode (\`minWidth\`/\`maxWidth\`, always bounded by the available container width). Pair with \`onResize\` to follow drag-resizing; when omitted the panel manages its own width starting from \`defaultWidth\`.                                                                                                                                                                                                 |
| `layout`         | `PageLayoutDetailsLayoutMode`                  |           | The current layout mode of the details panel (controlled).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `defaultLayout`  | `PageLayoutDetailsLayoutMode`                  | `'split'` | Default layout mode of the details panel (uncontrolled).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `onLayoutChange` | `(value: PageLayoutDetailsLayoutMode) => void` |           | Fired when the layout mode changes or should change.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `breakpoint`     | `number`                                       | `600`     | Container width in pixels below which the details panel renders as a drawer. Unlike the sidebar, the details panel never collapses itself here: the drawer stays open until it is dismissed.                                                                                                                                                                                                                                                                                                                                                 |
