## TitleBar.Title

**`TitleBarTitleProps`**

| Prop                  | Type                                           | Default | Description                                                                                                                   |
| --------------------- | ---------------------------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `children` (required) | `ReactNode`                                    |         | Elements to be displayed in the TitleBar Title slot.                                                                          |
| `as`                  | `'h1' \| 'h2' \| 'h3' \| 'h4' \| 'h5' \| 'h6'` | `'h2'`  | The semantic HTML heading element rendered by TitleBar.Title. Use this to fit the TitleBar into your page's document outline. |
| `level`               | `1 \| 2 \| 3 \| 4 \| 5 \| 6`                   | `3`     | The visual heading size. Corresponds to the heading scale defined in the design system.                                       |
