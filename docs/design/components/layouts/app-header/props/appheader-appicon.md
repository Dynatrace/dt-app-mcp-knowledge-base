## AppHeader.AppIcon

You can use the `AppHeader.AppIcon` component to render the icon used for the app on the platform.

**`AppIconProps`**

| Prop  | Type     | Default | Description                                                                                                     |
| ----- | -------- | ------- | --------------------------------------------------------------------------------------------------------------- |
| `src` | `string` |         | The path to the app icon. If not specified, the icon from the app registry is retrieved automatically.          |
| `alt` | `string` |         | The alternative text representation for the image when it's not loaded. If not specified, the app name is used. |
