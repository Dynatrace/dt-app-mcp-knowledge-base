## 3.17.0 (2026-10-29) \{#3170}

### Updates

#### Layouts

- `PageLayout.Details` now opens directly as a drawer on narrow screens when mounted conditionally, instead of briefly rendering its desktop layout. (APPDEV-20753)
- Fixed the top padding of the drawers in `PageLayout` and `Page`, which is now 20px instead of 16px. (APPDEV-20538)
- Fixed missing behavior tracking attributes on the drawers and the sidebar controls, so user interactions with them are attributed to the correct component. (APPDEV-19830)
