## Page.DetailView

The `Page.DetailView` can be leveraged to provide additional information related to the main content. Take a look at the [UI and design guidelines](https://developer.dynatrace.com/design/patterns/app-structure.md#page) for information on which content we recommend to use in the detail view.

**`DetailViewProps`**

```ts
export declare type DetailViewProps = ControlledDetailViewProps | UncontrolledDetailViewProps;
```
