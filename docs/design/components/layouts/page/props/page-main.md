## Page.Main

You should use the `Page.Main` compound to display the main content of your application. Take a look at the [UI and design guidelines](https://developer.dynatrace.com/design/patterns/app-structure.md#page) for information on which content we recommend to use in the main view.

**`MainProps`**

| Prop       | Type     | Default | Description                                    |
| ---------- | -------- | ------- | ---------------------------------------------- |
| `minWidth` | `number` | `320`   | The minimum width of the main panel in pixels. |
