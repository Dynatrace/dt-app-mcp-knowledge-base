## When not to use

- Short snippets of read-only code. Use [CodeSnippet](https://developer.dynatrace.com/design/components/content/CodeSnippet.md) instead.
- Users need to write queries using DQL syntax. Use [DQLEditor](https://developer.dynatrace.com/design/components/editors/DQLEditor.md) instead.
- Plain text inputs without code syntax or structure. Use [TextArea](https://developer.dynatrace.com/design/components/forms/TextArea.md) instead.
- Inputs that are single lines of text or short-form content. Use [TextInput](https://developer.dynatrace.com/design/components/forms/TextInput.md) instead.
- To filter or search data with structured syntax. Use [FilterField](https://developer.dynatrace.com/design/components/filters/FilterField.md) instead.
