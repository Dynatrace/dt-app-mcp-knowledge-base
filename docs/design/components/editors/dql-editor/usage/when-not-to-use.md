## When not to use

- For editing other programming languages or configuration formats than DQL. Use [CodeEditor](https://developer.dynatrace.com/design/components/editors/CodeEditor.md) instead.
- For read-only display of short snippets of code (DQL and other languages), use [CodeSnippet](https://developer.dynatrace.com/design/components/content/CodeSnippet.md).
- For predefined filtering tasks. Use [FilterField](https://developer.dynatrace.com/design/components/filters/FilterField.md) or [FilterBar](https://developer.dynatrace.com/design/components/filters/FilterBar.md) instead.
- For basic text inputs, use [TextInput](https://developer.dynatrace.com/design/components/forms/TextInput.md) or [TextArea](https://developer.dynatrace.com/design/components/forms/TextArea.md).
