### EmptyState.VisualPreset

**`EmptyStateVisualPresetProps`**

| Prop                 | Type                                                                                         | Default | Description                                                                      |
| -------------------- | -------------------------------------------------------------------------------------------- | ------- | -------------------------------------------------------------------------------- |
| `context` (required) | `'chart' \| 'document' \| 'generic' \| 'table' \| 'query'`                                   |         | The visual context of the illustration.                                          |
| `type` (required)    | `'something-missing' \| 'no-result' \| 'something-wrong' \| 'create-new' \| 'no-permission'` |         | A visual cue added to the illustration hinting at the reason the state is empty. |
