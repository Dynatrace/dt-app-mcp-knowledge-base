## 3.17.0 (2026-10-29) \{#3170}

### Updates

- You can now set `maxSize` to cap the size that `size="auto"` resolves to. (APPDEV-20535)
- You can now use the `preset` prop to show an empty state with or without a visual, plus a title and details about why the view is empty. (APPDEV-19760)
- Long details text no longer shrinks the visual or overflows when `size` is `large`. (APPDEV-19760)
