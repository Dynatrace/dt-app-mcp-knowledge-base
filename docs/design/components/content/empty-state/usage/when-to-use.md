## When to use

- The user hasn't [created](#create-new) anything yet.
- The user hasn't [configured](#something-missing) a setting or feature yet.
- A search, filter, or query returns [no results](#no-result).
- The system [can't load data](#something-is-wrong) due to an error.
- The user [has no access](#no-permission) to the app or its data.
