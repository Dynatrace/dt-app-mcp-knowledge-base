## Sizes

Choose the component size based on where the `EmptyState` appears and how much space it takes.

| Component size   | When to use                          | Example                                                                                               | Included elements                                                                                                        |
| ---------------- | ------------------------------------ | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Hero (large)     | Fills the entire page                | - A whole page the user has no permission to access
- A page where something is not yet configured    | * Recommended:&#x20;
  **Illustration**
  ,&#x20;
  **Title**
  ,&#x20;
  **Details**
* Optional: Action, Footer         |
| Default (medium) | For a distinct section within a page | - A dashboard tile the user is creating for the first time
- A problem panel with no root cause found | * Recommended:&#x20;
  **Illustration or icon**
  ,&#x20;
  **Title**
  ,&#x20;
  **Details**
* Optional: Action, Footer |
| Small            | Fits into a tight or dynamic space   | - A table with no rows matching the current filters
- A search dropdown with no matching metrics      | * Recommended:&#x20;
  **Title, Details**
* Optional: Illustration or icon, Action
* Avoid: Footer                       |
