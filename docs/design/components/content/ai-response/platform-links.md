## Platform links

Links to intents, apps, and documents in the current environment open inside the platform, in the same tab. These are the links that `getIntentLink`, `getAppLink`, and `getDocumentLink` create. For details, see [Navigation SDK](https://public-developer.central.internal.dynatrace.com/develop/sdks/navigation.md). Users can still open these links in a new tab, for example with Ctrl+click (Cmd+click on macOS) or a middle-click.

All other links open in a new tab, including links to another environment. This also applies to intent links with a compressed payload, which the platform creates only for very large payloads.
