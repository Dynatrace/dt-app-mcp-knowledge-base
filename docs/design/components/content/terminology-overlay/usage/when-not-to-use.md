## When not to use

- For information other than a definition or explanation of a term. Instead, use [InformationOverlay](https://developer.dynatrace.com/design/components/content/InformationOverlay.md).
- For short messages, such as action names. Use [Tooltip](https://developer.dynatrace.com/design/components/overlays/Tooltip.md) for these.
- If most users understand the term.
- If the definition is critical to the user's task and should always be visible. For this, use inline text.
