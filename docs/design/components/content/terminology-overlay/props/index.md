Use the `TerminologyOverlay` component to define or explain unusual or technical terms in the UI.

**`TerminologyOverlayProps`**

| Prop                  | Type        | Default | Description                                                                                                                  |
| --------------------- | ----------- | ------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `defaultOpen`         | `boolean`   | `false` | Whether the overlay is open by default                                                                                       |
| `children` (required) | `ReactNode` |         | The component accepts TerminologyOverlay.Trigger, TerminologyOverlay.Description, and TerminologyOverlay.Footer as children. |
