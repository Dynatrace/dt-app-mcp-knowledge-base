## Content guidelines

![Anatomy of an InformationOverlay with three numbered callouts mapping to the parts described below: Trigger icon, Trigger text, and Details.](https://developer.dynatrace.com/assets/images/informationoverlay-content-anatomy-light-c44d24f527e0b7bc50d5b2bc1c0cbb60.webp)&#x20;

1. Trigger icon (required)
2. Trigger text (optional)
3. Details (required)

### General guidelines

- Use sentence case (capitalize only the first word and any proper nouns, such as brand names).
- State the situation clearly in 1-2 sentences.
- End sentences with a period.
- Don't repeat the trigger text.
- Don't use all caps, exclamation marks, or alarmist words.
- Provide a descriptive text with links if additional help is available.

![Example of a correct InformationOverlay with a "Share access" trigger text and concise details, and an incorrect one repeating the trigger text as the details title.](https://developer.dynatrace.com/assets/images/informationoverlay-do-dont-light-a78d3863d9382a6ef7065d79e996168a.webp)&#x20;
