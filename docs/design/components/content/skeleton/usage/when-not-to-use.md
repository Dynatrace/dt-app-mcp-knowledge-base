## When not to use

- When indicating that a specific part of the page is loading or saving. Use [ProgressBar](https://public-developer.central.internal.dynatrace.com/design/components/content/ProgressBar.md) or [ProgressCircle](https://public-developer.central.internal.dynatrace.com/design/components/content/ProgressCircle.md) instead.
- When representing loading text content. Use [SkeletonText](https://public-developer.central.internal.dynatrace.com/design/components/content/SkeletonText.md) instead.
