Use the `Skeleton` to represent a loading state when the app loads for the first time or most of the page is loading.

**`SkeletonProps`**

| Prop      | Type                      | Default     | Description                         |
| --------- | ------------------------- | ----------- | ----------------------------------- |
| `variant` | `'default' \| 'rounded'`  | `'default'` | Defines the shape of the Skeleton.  |
| `width`   | `CSSProperties['width']`  | `100%`      | Width of the Skeleton placeholder.  |
| `height`  | `CSSProperties['height']` | `100%`      | Height of the Skeleton placeholder. |
