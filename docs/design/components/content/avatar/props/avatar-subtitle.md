## Avatar.Subtitle

Use the `Avatar.Subtitle` component to render additional information below the `Avatar` label, as shown above.

**`AvatarSubtitleProps`**

| Prop                  | Type        | Default | Description                                           |
| --------------------- | ----------- | ------- | ----------------------------------------------------- |
| `children` (required) | `ReactNode` |         | Elements to be displayed in the Avatar Subtitle slot. |
