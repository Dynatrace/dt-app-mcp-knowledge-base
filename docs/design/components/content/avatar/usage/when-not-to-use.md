## When not to use

- To represent entities such as objects, hosts, or services. Use the corresponding [functional icon](https://developer.dynatrace.com/design/icons/functional-icons.md) instead.
- To represent an app, for example, in ready-made documents. Use the corresponding [app icon](https://developer.dynatrace.com/design/icons/app-icons.md) instead.
- To display several users together in a limited space. Use [AvatarGroup](https://developer.dynatrace.com/design/components/content/AvatarGroup.md) instead.
