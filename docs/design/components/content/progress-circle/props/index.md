Use the `ProgressCircle` to indicate an ongoing loading process in a specific part of the page.

**`ProgressCircleProps`**

| Prop               | Type                                                             | Default                                    | Description                                                                                                                                                                                                                                                                                                                    |
| ------------------ | ---------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `value`            | `number \| 'indeterminate'`                                      | `'indeterminate'`                          | The current value.                                                                                                                                                                                                                                                                                                             |
| `min`              | `number`                                                         | `0`                                        | The smallest allowed value.                                                                                                                                                                                                                                                                                                    |
| `max`              | `number`                                                         | `100`                                      | The maximum allowed value.                                                                                                                                                                                                                                                                                                     |
| `size`             | `'small' \| 'large'`                                             | `'large'`                                  | Controls the size of the rendered progress.                                                                                                                                                                                                                                                                                    |
| `color`            | `'neutral' \| 'primary' \| 'success' \| 'warning' \| 'critical'` | `'primary' or a container's color.`        | Controls the color of the progress.                                                                                                                                                                                                                                                                                            |
| `'aria-valuetext'` | `string`                                                         | `the value of the progress as percentage.` | The aria-valuetext attribute defines the human-readable text alternative of aria-valuenow for a range widget. Default the value as percentage will be provided. If the value is not a percentage please provide the aria-valuetext. https\://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-valuetext |
