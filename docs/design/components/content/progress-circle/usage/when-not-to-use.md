## When not to use

- When indicating an ongoing saving or uploading process. Use [ProgressBar](https://developer.dynatrace.com/design/components/content/ProgressBar.md) instead.
- When the app is loading for the first time or most of the page is in a loading state. Use [Skeleton](https://developer.dynatrace.com/design/components/content/Skeleton.md) instead.
- When indicating that AI-generated content is being loaded. Use [AiLoadingIndicator](https://developer.dynatrace.com/design/components/content/AiLoadingIndicator.md) instead.
