## Behavior

- Trigger an introductory microguide automatically the first time a user opens your app. When it's closed, use [FeatureHighlight](https://developer.dynatrace.com/design/components/content/FeatureHighlight.md) to show users where they can reopen it.
- Let users dismiss or skip the guidance. It is meant to be non-intrusive and optional.
- Let users revisit microguides from the "Get started" option in the app help menu.
