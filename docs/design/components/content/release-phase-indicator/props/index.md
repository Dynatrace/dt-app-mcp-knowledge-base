Use the `ReleasePhaseIndicator` to communicate the release phase of a feature (Preview, New, Early Access, Deprecated).

**`ReleasePhaseIndicatorProps`**

| Prop               | Type           | Default | Description                                                        |
| ------------------ | -------------- | ------- | ------------------------------------------------------------------ |
| `phase` (required) | `ReleasePhase` |         | The release phase to display. Determines the chip label and color. |
