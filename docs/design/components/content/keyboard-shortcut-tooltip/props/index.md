Use the `KeyboardShortcutTooltip` component to display a keyboard shortcut inside a tooltip.

**`KeyboardShortcutTooltipProps`**

| Prop               | Type                   | Default   | Description                                                   |
| ------------------ | ---------------------- | --------- | ------------------------------------------------------------- |
| `keys` (required)  | `KeyboardShortcutKeys` |           | The combination the component should display.                 |
| `shortcutDisabled` | `boolean`              | `'false'` | Whether the component should be rendered in a disabled state. |
| `text`             | `ReactNode`            |           | Text displayed in the tooltip component.                      |

**`TooltipBaseProps`**

| Prop                  | Type                                                                                                                                                                        | Default     | Description                                                                                                                                                             |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children` (required) | `ReactElement`                                                                                                                                                              |             | Single child of the tooltip considered to trigger the tooltip element.                                                                                                  |
| `disabled`            | `boolean`                                                                                                                                                                   | `false`     | Defines if the tooltip is disabled or not.                                                                                                                              |
| `placement`           | `'top' \| 'right' \| 'bottom' \| 'left' \| 'top-start' \| 'top-end' \| 'bottom-start' \| 'bottom-end' \| 'right-start' \| 'right-end' \| 'left-start' \| 'left-end'`        | `'top'`     | Placement of the tooltip relative to its trigger element.                                                                                                               |
| `defaultOpen`         | `boolean`                                                                                                                                                                   | `false`     | Defines if the tooltip should be open initially when used uncontrolled.                                                                                                 |
| `open`                | `boolean`                                                                                                                                                                   |             | Defines if the tooltip is open / closed in a controlled component. In this case, you need to react to \`onOpenChange\` yourself in order to open and close the tooltip. |
| `delay`               | `'default' \| 'none'`                                                                                                                                                       | `'default'` | Defines the type of delay which is used for the tooltip.                                                                                                                |
| `onOpenChange`        | `(isOpen: boolean) => void`                                                                                                                                                 |             | Callback fired when the tooltip opens.                                                                                                                                  |
| `fallbackPlacements`  | `Array<'top' \| 'right' \| 'bottom' \| 'left' \| 'top-start' \| 'top-end' \| 'bottom-start' \| 'bottom-end' \| 'right-start' \| 'right-end' \| 'left-start' \| 'left-end'>` |             | Array of placements to be used as fallback if the tooltip doesn't fit at the specified placement.                                                                       |
