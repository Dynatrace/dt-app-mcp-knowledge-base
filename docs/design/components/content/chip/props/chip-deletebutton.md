## Chip.DeleteButton

**`ChipDeleteButtonProps`**

| Prop       | Type                | Default | Description                                                                                                                               |
| ---------- | ------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `disabled` | `boolean`           | `false` | If a button is disabled e.g. it cannot be interacted with. By default, it inherits the disabled prop of the Chip, but can be overwritten. |
| `onClick`  | `MouseEventHandler` |         | Called when the button is interacted with.                                                                                                |
