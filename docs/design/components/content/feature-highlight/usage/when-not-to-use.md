## When not to use

- When you need to communicate a longer message. Users are more likely to dismiss lengthy content without reading.
- When the user may need to refer to the information again. `FeatureHighlight` can't be revisited unless your app retriggers it, so it's only suitable for non-critical, one-time announcements.
- When you need to walk users through multiple steps in sequence or build a product tour. Use [Microguide](https://developer.dynatrace.com/design/components/content/Microguide.md) instead.
- For content that isn't highly relevant or doesn't add value in the user's current context. Any content shown should provide meaningful value.
