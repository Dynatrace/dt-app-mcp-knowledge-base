## Content guidelines

![Anatomy of a FeatureHighlight component with four numbered callouts mapping to the parts described below: Title, Visual, Content, and Actions.](https://developer.dynatrace.com/assets/images/featurehighlight-content-anatomy-light-25386aa4d878889be347999ceaa7e354.webp)

1. Title (optional)
2. Visual (optional)
3. Content (optional)
4. Actions (optional)

### General guidelines

- Use sentence case (capitalize only the first word and any proper nouns, such as brand names).

### Title

- Keep it clear and concise and don't include a period.
- Avoid questions as titles.

### Visual

- Make sure any visuals you add are clear and legible. Use high-quality images, GIFs, or videos that are crisp and legible at the scale of the feature highlight.
- For best results, use an 8:5 aspect ratio. The actual size is 400x250px.
- Crop images to show the specific element or action you're explaining. Don't shrink a full-page screenshot to fit.
- Make sure the visual reflects the content, and vice versa.
- Test visuals with users at actual size to confirm they're clear.
- Don't include a visual unless it adds value.

### Content

- Keep the content brief and action-oriented. Avoid excessive detail.
- Don't repeat the title in the content.
- If you include links, follow the usage guidance for [Link](https://developer.dynatrace.com/design/components/typography/Link/usage.md).

### Actions

- Use buttons for actions and follow the usage guidance for [Button](https://developer.dynatrace.com/design/components/buttons/Button/usage.md).
- If you need to point to more information, include a link in the content instead.
