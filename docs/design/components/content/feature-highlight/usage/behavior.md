## Behavior

- Only show one at a time.
- Place the component in a suitable position for the layout. See [Change placement](https://developer.dynatrace.com/design/components/content/FeatureHighlight.md#change-placement) for options.
- Ensure it's shown once only. Once dismissed, no other conditions should allow it to reappear.
- Be selective. Although `FeatureHighlight` doesn't block interaction, showing too many will annoy users.
