Use the `ProgressBar` to indicate an ongoing saving or uploading process in a specific part of the page.

**`ProgressBarProps`**

| Prop               | Type                                                             | Default                                    | Description                                                                                                                                                                                                                                                                                                                        |
| ------------------ | ---------------------------------------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `value`            | `number \| 'indeterminate'`                                      | `'indeterminate'`                          | The current value.                                                                                                                                                                                                                                                                                                                 |
| `min`              | `number`                                                         | `0`                                        | The minimum allowed value.                                                                                                                                                                                                                                                                                                         |
| `max`              | `number`                                                         | `100`                                      | The maximum allowed value.                                                                                                                                                                                                                                                                                                         |
| `density`          | `'default' \| 'condensed'`                                       | `'default'`                                | Controls the density of the rendering.                                                                                                                                                                                                                                                                                             |
| `color`            | `'neutral' \| 'primary' \| 'success' \| 'warning' \| 'critical'` | `'primary' or a container's color.`        | Controls the color of the progress.                                                                                                                                                                                                                                                                                                |
| `'aria-valuetext'` | `string`                                                         | `the value of the progress as percentage.` | The aria-valuetext attribute defines the human-readable text alternative of aria-valuenow for a range widget. By default, the value will be given as a percentage. If the value is not a percentage, you should provide aria-valuetext. https\://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-valuetext |
