## AvatarGroup.Item

You can use the `AvatarGroup.Item` component to render an item belonging to the group of [`Avatar`](https://developer.dynatrace.com/design/components/content/Avatar.md) elements, as shown above.

**`AvatarGroupItemProps`**

```ts
export declare type AvatarGroupItemProps<E extends ElementType> = PolymorphicComponentProps<E, AvatarGroupItemOwnProps>;
```
