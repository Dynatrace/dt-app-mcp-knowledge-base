Use the `KeyboardShortcut` to display one or more keys that represent a keyboard shortcut for a specific action.

**`KeyboardShortcutProps`**

| Prop              | Type                     | Default     | Description                                                   |
| ----------------- | ------------------------ | ----------- | ------------------------------------------------------------- |
| `keys` (required) | `KeyboardShortcutKeys`   |             | The combination the component should display.                 |
| `variant`         | `'default' \| 'minimal'` | `'default'` | The variant that should be used for styling the keys.         |
| `disabled`        | `boolean`                | `'false'`   | Whether the component should be rendered in a disabled state. |
