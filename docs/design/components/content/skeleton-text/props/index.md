Use the `SkeletonText` to represent loading text content with animated placeholder lines.

**`SkeletonTextProps`**

| Prop    | Type                     | Default | Description                                      |
| ------- | ------------------------ | ------- | ------------------------------------------------ |
| `width` | `CSSProperties['width']` | `100%`  | Width of the SkeletonText placeholder.           |
| `lines` | `number`                 | `3`     | Number of Lines of the SkeletonText placeholder. |
