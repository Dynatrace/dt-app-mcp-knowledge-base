## When not to use

- To explain complex terms, use [TerminologyOverlay](https://developer.dynatrace.com/design/components/content/TerminologyOverlay.md).
- To share keyboard shortcuts, use [KeyboardShortcutTooltip](https://developer.dynatrace.com/design/components/content/KeyboardShortcutTooltip.md).
- For detailed information use [InformationOverlay](https://developer.dynatrace.com/design/components/content/InformationOverlay.md).
- If you need to include a link, use [InformationOverlay](https://developer.dynatrace.com/design/components/content/InformationOverlay.md).
- If the information is critical for the user to complete their task, put it directly in the UI.
