## When not to use

- For tasks that can happen directly on the main page without the need for a separate, focused step.
- For information that can be shown in a simpler, less disruptive way. Consider using [InformationOverlay](https://developer.dynatrace.com/design/components/content/InformationOverlay.md) instead.
- For complex forms or large amounts of information. Use a dedicated page instead.
- For temporary messages or notifications. Use [Toast](https://developer.dynatrace.com/design/components/notifications/Toast.md) instead.
