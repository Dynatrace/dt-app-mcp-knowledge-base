## 3.18.0 (2026-11-12) \{#3180}

### Updates

#### Forms

- Fixed form fields inside a `Form` that showed a control's error message twice, for example a min or max error. (APPDEV-19307)
- Disabled and read-only fields now use the neutral disabled background in visual refresh mode, and read-only error fields retain their surface background with an emphasized critical outline. Error fields also now use the surface background instead of a critical background in visual refresh mode. (APPDEV-19745)
- Placeholder text on interactive inputs now renders at reduced opacity in visual refresh mode to improve differentiation between placeholder text and user-entered content. (APPDEV-19745)
- You can now pass `null` as `value` or `defaultValue` to `TextInput`, `PasswordInput`, `SearchInput`, `TextArea`, `Checkbox`, `Switch`, `RadioGroup`, `ToggleButtonGroup`, and `Select`, so the control starts empty and keeps its controlled or uncontrolled mode.
- `onValidityChange` now behaves the same for every form control: it reports errors once they are shown to the user, emits only when the set of errors changes, and reports a `pending` state once while an asynchronous validation runs. (APPDEV-19740)
