## When not to use

- Users must select from a predefined set of numbers. Use [Select](https://developer.dynatrace.com/design/components/forms/Select.md) or [Radio](https://developer.dynatrace.com/design/components/forms/Radio.md) instead.
- The number is part of a formatted string, as with phone numbers, credit cards, or currency with symbols. Use a [TextInput](https://developer.dynatrace.com/design/components/forms/TextInput.md) with the appropriate formatting and validation.
