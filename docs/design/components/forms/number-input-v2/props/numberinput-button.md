### NumberInput.Button

You can use the `NumberInput.Button` component to render a button inside the `NumberInput.Prefix` or `NumberInput.Suffix` component.

**`BaseInputButtonProps`**

| Prop                             | Type                    | Default | Description                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------- | ----------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children` (required)            | `ReactNode`             |         | Elements to be displayed in the BaseInput Button slot, preferably an icon or a similar visual element                                                                                                                                                                                                                                                                                                                            |
| `disabled`                       | `boolean`               | `false` | If a button is disabled e.g. it cannot be interacted with. By default, it inherits the disabled prop of the BaseInput, but can be overwritten.                                                                                                                                                                                                                                                                                   |
| `tooltipText`                    | `string`                |         | If specified, a tooltip is rendered with this text, which describes what the button does. The text is also used as \`aria-label\` while the tooltip is closed, ensuring a valid accessible name at all times. Please also consider translating the text in an internationalized context and use a short text description for the tooltip. The positioning and placing of the according tooltip will be handled by the component. |
| `tooltipBehavioralTrackingProps` | `BehaviorTrackingProps` |         | Behavioral tracking props to forward exclusively to the tooltip overlay. These will not be applied to the button itself.                                                                                                                                                                                                                                                                                                         |
| `onClick`                        | `MouseEventHandler`     |         | Called when the button is interacted with.                                                                                                                                                                                                                                                                                                                                                                                       |
| `readOnly`                       | `boolean`               |         | Determines whether the input is in read-only mode.                                                                                                                                                                                                                                                                                                                                                                               |
