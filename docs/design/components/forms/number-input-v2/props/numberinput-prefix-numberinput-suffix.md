### NumberInput.Prefix, NumberInput.Suffix

You can use the `NumberInput.Prefix` component to render custom content in front of the input, or the `NumberInput.Suffix` component if you need to render content after it.

**`BaseInputContentProps`**

| Prop                  | Type        | Default | Description                                  |
| --------------------- | ----------- | ------- | -------------------------------------------- |
| `children` (required) | `ReactNode` |         | Elements to be displayed in the Prefix slot. |
