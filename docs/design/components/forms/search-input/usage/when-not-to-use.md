## When not to use

- Users need to enter general text data unrelated to search or filtering. Use [TextInput](https://developer.dynatrace.com/design/components/forms/TextInput.md) instead.
- Users need structured filtering with multiple criteria (facets, date ranges, categories). Use [FilterBar](https://developer.dynatrace.com/design/components/filters/FilterBar.md) instead.
- Users are technical and need advanced filtering features. Use [FilterField](https://developer.dynatrace.com/design/components/filters/FilterField.md) instead.
