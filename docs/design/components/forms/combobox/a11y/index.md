The `Combobox` component allows users to choose one option from a collapsed dropdown, filter options by typing, or create a new one.

> **Note**
>
> See [Accessibility](https://public-developer.central.internal.dynatrace.com/design/foundations/accessibility.md) in Design Foundations for explanations of key concepts and best practices.

Strato's `Combobox` component follows the [ARIA combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/). The text input is the combobox, and the dropdown is a list of options. Screen readers announce the active option while focus stays on the input.
