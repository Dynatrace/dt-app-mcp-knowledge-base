## State announcements

The `Combobox` announces its state out of the box. It sets `aria-expanded` to `true` when the dropdown is open and to `false` when it's closed.

- **Do** provide a hint or error message through `FormField` so validation results are announced together with the field.
- **Do** make the effect of creating a value clear in the label or hint, so screen reader users know that entering new text is possible.
