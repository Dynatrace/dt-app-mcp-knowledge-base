## When not to use

- Users must choose only from predefined options. Use [Select](https://public-developer.central.internal.dynatrace.com/design/components/forms/Select.md) instead.
- Users should choose multiple options. Use [Select](https://public-developer.central.internal.dynatrace.com/design/components/forms/Select.md) with the `multiple` prop or [Checkbox](https://public-developer.central.internal.dynatrace.com/design/components/forms/Checkbox.md).
- There are only two options. Use [Radio](https://public-developer.central.internal.dynatrace.com/design/components/forms/Radio.md) or [Switch](https://public-developer.central.internal.dynatrace.com/design/components/forms/Switch.md) for binary choices.
- Users should enter free text with no suggestions. Use [TextInput](https://public-developer.central.internal.dynatrace.com/design/components/forms/TextInput.md) instead.
