## When not to use

- To organize content in sections or pages and navigate between them. Instead, use [Tabs](https://developer.dynatrace.com/design/components/navigation/Tabs.md).
- When there are more than five options. Use [Select](https://developer.dynatrace.com/design/components/forms/Select.md) instead.
- When there isn't enough space to display all options. Use [Select](https://developer.dynatrace.com/design/components/forms/Select.md) instead.
- For choices in forms that require additional context or a submit action. Use [Radio](https://developer.dynatrace.com/design/components/forms/Radio.md) instead.
- When users need to select multiple options. Use [Select](https://developer.dynatrace.com/design/components/forms/Select.md) or [Checkbox](https://developer.dynatrace.com/design/components/forms/Checkbox.md) instead.
- For simple binary decisions, such as "yes/no" or "on/off". Use [Switch](https://developer.dynatrace.com/design/components/forms/Switch.md) instead.
