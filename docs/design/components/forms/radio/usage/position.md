## Position

![Four Radio components labeled "Write", "Execute", "Read only", and "No access", shown stacked vertically on the left and in a single horizontal row on the right.](https://developer.dynatrace.com/assets/images/radio-alignment-light-2dc248b106cceb7060c1ebc9952c7ef3.webp)

### Vertical

- Use vertical alignment in most instances. It's suitable for responsive layouts, when you offer a relatively large number of options, or when vertical alignment stays consistent within a certain context, such as within a form.

### Horizontal

- If you need a horizontal layout, avoid wrapping options into a new line.

![Example of correct horizontally aligned Radio components fitting on a single line, and an incorrect group that wraps onto a second line.](https://developer.dynatrace.com/assets/images/radio-alignment-horizontal-light-d83a32c6fb1727ed7906d8534acd2fdd.webp)
