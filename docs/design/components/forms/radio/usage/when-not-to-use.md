## When not to use

- When users can select more than one option. Use [Checkbox](https://developer.dynatrace.com/design/components/forms/Checkbox.md) instead.
- When there are more than four options. Use [Select](https://developer.dynatrace.com/design/components/forms/Select.md) instead.
- When users need to toggle a setting on and off. Use [Switch](https://developer.dynatrace.com/design/components/forms/Switch.md) instead.
- To filter content or switch between different visual representations on a page. Use [ToggleButtonGroup](https://developer.dynatrace.com/design/components/forms/ToggleButtonGroup.md) instead.
