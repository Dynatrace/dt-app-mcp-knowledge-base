## Position

![Four Checkbox components labeled "AIOps", "DevOps", "Security", and "Monitoring", shown stacked vertically on the left and in a single horizontal row on the right.](https://developer.dynatrace.com/assets/images/checkbox-alignment-light-4cc032474c68d361afb4d48922ad2009.webp)

### Vertical

- Use vertical alignment in most instances. It's suitable for responsive layouts, a relatively large number of options, or when vertical alignment is consistent in its context, such as in a form.

### Horizontal

- If you need a horizontal layout, avoid having the options wrap into a new line.

![Example of correct horizontally aligned Checkbox components fitting on a single line, and an incorrect group that wraps onto a second line.](../../components-docs-assets/checkbox-alignment-horizontal-light.webp)
