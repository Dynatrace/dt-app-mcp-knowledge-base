## When not to use

- There are only two options. Use [Radio](https://developer.dynatrace.com/design/components/forms/Radio.md) or [Switch](https://developer.dynatrace.com/design/components/forms/Switch.md) for binary choices.
- Users should toggle a setting on/off for an immediate state change. Use [Switch](https://developer.dynatrace.com/design/components/forms/Switch.md) instead.
- Users should see all the options in the UI. Use [Radio](https://developer.dynatrace.com/design/components/forms/Radio.md) for a single selection or [Checkbox](https://developer.dynatrace.com/design/components/forms/Checkbox.md) for multiple selections.
- Users should trigger an action or navigation, use [Menu](https://developer.dynatrace.com/design/components/navigation/Menu.md) or [Button](https://developer.dynatrace.com/design/components/buttons/Button.md).
