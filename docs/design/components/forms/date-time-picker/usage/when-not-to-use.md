## When not to use

- Users need to select a time range. Use [TimeframeSelector](https://developer.dynatrace.com/design/components/filters/TimeframeSelector.md) instead.
- Users need to choose partial or approximate dates that don't fit the DD/MM/YYYY format of the `DateTimePicker`, for example "March 2025" or "Q2 2024". Use [Select](https://developer.dynatrace.com/design/components/forms/Select.md) instead.
