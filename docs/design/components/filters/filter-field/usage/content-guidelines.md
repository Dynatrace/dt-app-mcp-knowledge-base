## Content guidelines

### Label (optional)

Only include a label if it's needed to provide context. The label should be descriptive but short (1-2 words).

- Do: Advanced filtering
- Don't: Filter field

### Placeholder (required)

Default text: **Type to filter**

We recommend keeping the default placeholder text.

:::note Use hint for essential information

Don't use the placeholder for information users need to complete the task, as placeholders disappear when users start typing.

:::

### Hint (optional)

As FilterField supports dynamic suggestions with explanations and error states, and the placeholder text suggests how to begin, a hint text is probably unnecessary. However, if your use case requires an additional hint text, keep it short and add periods after sentences.
