## When not to use

- For simple filtering where users don't need to control logical or comparison operators themselves. For these scenarios, use [FilterBar](https://public-developer.central.internal.dynatrace.com/design/components/filters/FilterBar.md).
- Never combine FilterField and FilterBar for the same dataset.

For best practices on when to use which filter component, see [Filtering](https://public-developer.central.internal.dynatrace.com/design/patterns/filtering.md).
