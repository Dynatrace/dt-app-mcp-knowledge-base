## Variants

`SegmentSelector` comes in two variants that control how much information the trigger shows.

![Two SegmentSelector trigger variants: Default, which expands to show the selected segment label, and Compact, which shows only a count at a fixed width.](../../components-docs-assets/segmentselector-variants-light.webp)&#x20;

### Default

Use the default variant if the trigger has enough space to grow without breaking the layout. It provides context when one segment is selected and keeps a consistent width when multiple segments are selected.

### Compact

Use the compact variant if the trigger needs to keep a predictable width and space is limited.
