## Position

![Two filter compositions showing the SegmentSelector placed as the first element: one combined with a FilterField, and one combined with a FilterBar.](https://developer.dynatrace.com/assets/images/segmentselector-where-to-position-light-8991478d3dfd1793adefdd40bd5f4105.webp)&#x20;

If `SegmentSelector` is part of a larger filter composition, for example, combined with a `FilterField` or `FilterBar`, place it as the first element so users select a segment before applying other filters.
