### SegmentApplicabilityProvider

**`SegmentsRequirements`**

| Prop       | Type                   | Default | Description                                                                                                                                    |
| ---------- | ---------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `requires` | `RequiredDataObject[]` |         | Data sources and entity types the host view operates on. The Segment Selector warns when a selected segment does not cover all declared needs. |
