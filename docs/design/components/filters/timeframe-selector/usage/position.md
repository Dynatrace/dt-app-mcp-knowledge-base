## Position

Place `TimeframeSelector` directly above the content it affects so users can see which data the timeframe controls. If `TimeframeSelector` is part of a filter composition such as one with a [FilterField](https://developer.dynatrace.com/design/components/filters/FilterField.md), place it last.
