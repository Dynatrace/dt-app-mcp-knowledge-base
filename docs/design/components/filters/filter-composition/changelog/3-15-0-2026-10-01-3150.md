## 3.15.0 (2026-10-01) \{#3150}

### Updates

- You can now offer filter actions from any menu with `_FilterCompositionMenuGroup`. It renders one menu item per filter operation available for a key/value pair, and selecting an item writes the statement into the composition's `FilterField`. The group names its composition by id, so it works from a menu rendered anywhere in the app, such as a table cell menu. (APPDEV-19484)

- You can now wire `FilterField`, `TimeframeSelector`, and `SegmentSelector` into a single apply lifecycle with shared validation, cancellation, and server-error handling. (APPDEV-18400)
