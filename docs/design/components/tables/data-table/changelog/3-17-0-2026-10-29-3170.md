## 3.17.0 (2026-10-29) \{#3170}

### Updates

- You can now disable the interactivity of individual rows with `interactiveRows.disableRowInteractivity`. (APPDEV-18040)
- Right pinned columns now resize in the direction of the arrow keys. (APPDEV-20496)
- Pinned columns now stay aligned with their header cells after resizing via the keyboard or double-click. (APPDEV-20496)
- Updated hover and focus states in interactive rows previously overriding the row's background color. (APPDEV-19746)
- Updated the cell and column action trigger button styles. (APPDEV-19746)
- Fixed layout when the table is empty and uses row actions: right-pinned columns are no longer offset by a gap. (APPDEV-20370)
- The Gantt column header now shows "No timestamps available." instead of an empty axis when the table has no data and the column has neither an `annotationsHeader` nor an explicit `min` and `max`. (APPDEV-20370)
- Fixed the issue that prevented keyboard navigation from moving past expanded rows when using `interactiveRows`. (APPDEV-18040)
