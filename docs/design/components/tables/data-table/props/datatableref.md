## DataTableRef

**`DataTableRef`**

| Prop                            | Type                                                                                                                                                                                     | Default | Description                                                                                                                                                             |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `element` (required)            | `HTMLDivElement \| null`                                                                                                                                                                 |         | Root element ref of the component.                                                                                                                                      |
| `getConfig` (required)          | `() => DataTableConfig`                                                                                                                                                                  |         | Returns the current config of the DataTable.                                                                                                                            |
| `downloadData` (required)       | `(subset: 'all' \| 'page' \| 'selected', excludeColumns?: string[], formatDownloadHeader?: (context: DataTableDownloadHeaderContext) => string \| undefined, fileName?: string) => void` |         | Downloads all data, the data on the current page or the selected data. Optionally, columns can be excluded by their IDs, and header names can be overridden per column. |
| `scrollToRow` (required)        | `(rowId: string, align?: 'start' \| 'center' \| 'end') => void`                                                                                                                          |         | Scrolls the table to the row with the given \`rowId\`, aligning the row at the given scroll position.                                                                   |
| `openColumnSettings` (required) | `(columnSettings?: DataTableColumnSettingsConfig) => void`                                                                                                                               |         | Opens the column settings modal.                                                                                                                                        |
| `getDisplayedRowIds` (required) | `() => string[]`                                                                                                                                                                         |         | Returns the row IDs in their current display order, reflecting active sorting and the current page when pagination is enabled.                                          |
