## DataTableColumnSort

Rule for sorting a column.

**`DataTableColumnSort`**

| Prop              | Type      | Default | Description                   |
| ----------------- | --------- | ------- | ----------------------------- |
| `id` (required)   | `string`  |         | Column ID.                    |
| `desc` (required) | `boolean` | `false` | Descending sorting direction. |
