## DataTableSortingColumnDef

Extension interface to extend the types of the `columnDefinition` from the TanStack table.

**`DataTableSortingColumnDef`**

| Prop             | Type                                                                                          | Default  | Description                                                                                                                                                                                                                                                                              |
| ---------------- | --------------------------------------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `disableSorting` | `boolean`                                                                                     |          | Setting to true disables sorting for this column even if sorting is enabled globally.                                                                                                                                                                                                    |
| `sortType`       | `'text' \| 'number' \| 'textCaseSensitive' \| 'datetime' \| DataTableCustomSortingFn<TValue>` | `'text'` | Used to compare two rows of data and order them correctly. If a function is passed, it must be memoized.                                                                                                                                                                                 |
| `sortDescFirst`  | `boolean`                                                                                     |          | Setting to true means the first sorting direction for this column will be descending instead of ascending.                                                                                                                                                                               |
| `sortInverted`   | `boolean`                                                                                     |          | Setting this to true means the underlying sorting direction will be inverted but the UI will not. This could be useful for example where a lower score is better.                                                                                                                        |
| `sortAccessor`   | `string \| ((row: TData) => TValue)`                                                          |          | Optional - to be used for providing the value used for sorting. This enables the value used for sorting to be different from the value returned by the accessor. For example, if the accessor returns an object, the sortAccessor may return a number or string field within the object. |
