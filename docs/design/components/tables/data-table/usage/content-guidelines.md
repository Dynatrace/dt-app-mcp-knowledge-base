## Content guidelines

### Table actions

- For table actions, refer to the [Button content guidelines](https://developer.dynatrace.com/design/components/buttons/Button/usage.md#content-guidelines).

### Columns and rows

- Column headers should be one or two simple words and sentence case.
- If the column header is a noun, make it singular.
- Action names can be one to three words. See [Common actions](https://developer.dynatrace.com/design/patterns/common-actions.md) for patterns.

### Table data

- Display data in a consistent format. Learn more about [formatting data](https://developer.dynatrace.com/design/components/tables/DataTable.md#format-cell-data).
- Show an empty state when there's no data or there's an error. Learn more about [EmptyState](https://developer.dynatrace.com/design/components/content/EmptyState.md).
