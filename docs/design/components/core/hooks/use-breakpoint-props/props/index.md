**`BreakpointProps`**

| Prop                 | Type      | Default | Description                                                    |
| -------------------- | --------- | ------- | -------------------------------------------------------------- |
| `matches` (required) | `boolean` |         | Whether the breakpoint is matched.                             |
| `props` (required)   | `T`       |         | The props that should be applied if the breakpoint is matched. |
