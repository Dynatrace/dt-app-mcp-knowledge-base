## When not to use

- For stand-alone actions that don't relate to the surrounding text, such as a "Submit" button in a dialog. Use [Button](https://developer.dynatrace.com/design/components/buttons/Button.md) instead.
- For links that navigate to another page or view. Use [Link](https://developer.dynatrace.com/design/components/typography/Link.md) or [ExternalLink](https://developer.dynatrace.com/design/components/typography/ExternalLink.md) instead.
- In combination with other `InlineButton` components, as a substitute for a toolbar or actions.
