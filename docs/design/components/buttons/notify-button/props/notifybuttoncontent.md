## NotifyButtonContent

The `NotifyButtonContent` component renders custom content inside the `NotifyButton` overlay.

**`NotifyButtonContentProps`**

| Prop       | Type                                                                                                                                                                                                                                | Default | Description |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- | ----------- |
| `children` | `(({ disabled, headingText, infoText, hasReadPermission, hasWritePermission, }: { disabled: boolean; headingText: string; infoText: string; hasReadPermission: boolean; hasWritePermission: boolean; }) => ReactNode) \| ReactNode` |         |             |
