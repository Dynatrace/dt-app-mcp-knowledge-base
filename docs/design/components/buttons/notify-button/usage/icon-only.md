## Icon only

If space is limited, the `NotifyButton` can be displayed with just an icon. The icon reflects the current state (on or off), so users can tell at a glance whether notifications are on without having to interact with the button.

![Side-by-side comparison of a NotifyButton in icon-only mode (bell icon without label) and the default NotifyButton with a bell icon and the label "Notifications".](../../components-docs-assets/notifybutton-icon-only-light.webp)&#x20;
