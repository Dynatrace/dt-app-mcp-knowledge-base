## Variants

`NotifyButton` comes in two variants: `'default'` and `'emphasized'`.

![Two NotifyButton variants: default with no background for lower emphasis, and emphasized with a filled background for higher emphasis.](../../components-docs-assets/notifybutton-variants-light.webp)&#x20;

### Default

Use the default variant in most cases.

### Emphasized

Use the emphasized variant if the notification feature needs to stand out and draw the user's attention.
