### Icon only

- **Do** provide an `aria-label` with the button's name.
- **Do** set the SVG's role to `img` and hide it from assistive technology with `aria-hidden="true"`.
- **Do** use a [Tooltip](https://developer.dynatrace.com/design/components/overlays/Tooltip.md) to show the button's name. Ensure that the tooltip text and the `aria-label` match exactly.
