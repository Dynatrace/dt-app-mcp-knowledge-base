## Additive states

Additive states can appear while an element is in `rest`, `hover`, `active`, `drag`, or `disabled` state. You can apply additive states to an element simultaneously.

![Additive states](./assets/interaction-states-additive-light.webp)

### Focus

Focus states communicate that a user is currently focused on an interactive element with their keyboard.
Focus states are indicated with a visually contrasting border inside of an element.

### Selected

Selected states communicate a user’s current selection within a range of options.
Selected states are indicated using primary color tokens and an additional indicator (typically, a line or a checkmark-like icon).
