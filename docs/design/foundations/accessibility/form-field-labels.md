## Form field labels

> **Tip**
>
> Relates to [WCAG 1.3.1](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships) and [WCAG 2.4.6](https://www.w3.org/WAI/WCAG22/Understanding/headings-and-labels).

Input fields should have visible and persistent labels. This supports users who may need to refer back to a label while entering data. Placeholder text alone never substitutes for a proper label, since placeholders disappear when users start typing.

For compliant labelling out of the box, use the `FormField` component plus an appropriate form component inside it. See the individual Strato component documentation for component-specific guidance on labels, placeholders, and hints.

**Example components:** [FilterField](https://developer.dynatrace.com/design/components/filters/FilterField/usage.md), [PasswordInput](https://developer.dynatrace.com/design/components/forms/PasswordInput/usage.md), [SearchInput](https://developer.dynatrace.com/design/components/forms/SearchInput/usage.md), [TextArea](https://developer.dynatrace.com/design/components/forms/TextArea/usage.md), [TextInput](https://developer.dynatrace.com/design/components/forms/TextInput/usage.md)
