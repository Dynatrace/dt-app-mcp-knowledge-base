## Information experience

Information is clear, concise, organized, and scannable.

### Clarity, concision, and accuracy

| Content standard                                                                    | Resources                                                                                           |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| The meaning is easy to understand using as few words as possible.                   | - Validate with a grammar checker.                                                                  |
| Technical and business jargon are explained. Acronyms are spelled out on first use. | - [Dynatrace terminology](https://styleguide.dynatrace.com/docs/terminology/dynatrace-terminology/) |
| Links are descriptive and function correctly.                                       | - [Link text](https://styleguide.dynatrace.com/docs/style/link-text/)                               |
| All information is accurate (instructions and journeys work as described).          | - Validate with subject matter experts and test with users or colleagues.                           |

### Structure and scannability

| Content standard                                                                                    | Resources                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Contextual help and information is provided where needed.                                           | - [Link text](https://styleguide.dynatrace.com/docs/style/link-text/)<br /> - [Guided interaction](https://developer.dynatrace.com/design/foundations/guided-interaction.md)<br /> - [Error messages](https://developer.dynatrace.com/design/patterns/error-messages.md) |
| Nothing important is truncated.                                                                     | - [Lead with what's important](https://styleguide.dynatrace.com/docs/best-practices/top-10-tips/#lead-with-value)                                                                                                                                                        |
| Information order is logical and doesn't distract users from completing tasks.                      | - [Write for scannability](https://styleguide.dynatrace.com/docs/best-practices/scannability/)                                                                                                                                                                           |
| Subheadings, bullets, or numbered lists, and tables are used instead of long, dense blocks of text. | - [Write for scannability](https://styleguide.dynatrace.com/docs/best-practices/scannability/)<br /> - [Use tables](https://styleguide.dynatrace.com/docs/best-practices/scannability/#use-tables)                                                                       |

### UI interaction

| Content standard                                                                             | Resources                                                                                                                                                                              |
| -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Standardized UI interaction terms are used to set the right expectation for what comes next. | - [Interactions with web UIs](https://styleguide.dynatrace.com/docs/style/ui-interactions/)                                                                                            |
| Items in a group are structured alike (e.g., all headers start with a verb)                  | - [Use parallel writing structures](https://styleguide.dynatrace.com/docs/best-practices/scannability/#use-parallel-writing-structures)                                                |
| Primary and secondary actions are understandable and consistent.                             | - [Common actions](https://developer.dynatrace.com/design/patterns/common-actions.md)—standard labels and icons for recurring actions such as New, Add, Delete, Edit, Save, and Share. |
