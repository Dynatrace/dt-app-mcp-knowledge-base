## Accessibility

The content is inclusive and accessible to all its users.

| Content standard                                                                                                   | Resources                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| Content is direct and uses active voice when possible.                                                             | - [Active voice](https://styleguide.dynatrace.com/docs/style/grammar/#active-voice)                             |
| Images and components have alt-text and aria labels, as needed.                                                    | - [Accessibility](https://developer.dynatrace.com/design/foundations/accessibility.md)                          |
| Content is inclusive and doesn't make assumptions about users.                                                     | - [Inclusive language](https://styleguide.dynatrace.com/docs/accessibility-and-inclusivity/inclusive-language/) |
| UI content uses digits (1, 2, 3). Other content types, such as documentation, spell out numbers from zero to nine. | - [Numbers in sentences](https://styleguide.dynatrace.com/docs/style/numbers#numbers-in-sentences)              |
| Content doesn't use emoji.                                                                                         | - [Emoji](https://styleguide.dynatrace.com/docs/style/emoji/)                                                   |
