### Punctuation

| Content standard                                                                                                         | Resources                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| Headings and UI elements (such as buttons or menu items) don't use closing punctuation, "-ing" verbs, or question marks. | - [Page titles, headings, and subheadings](https://styleguide.dynatrace.com/docs/style/titles-and-headings) |
| Content is sentence case (except for branded names and proper nouns).                                                    | - [Sentence case](https://styleguide.dynatrace.com/docs/style/punctuation/#sentence-case)                   |
| Content uses the serial (Oxford) comma.                                                                                  | - [Serial commas](https://styleguide.dynatrace.com/docs/style/punctuation/#serial-commas)                   |
| Punctuation is correct and simple. Ampersand (&) is only used in app names and menu labels.                              | - [Punctuation](https://styleguide.dynatrace.com/docs/style/punctuation/)                                   |
