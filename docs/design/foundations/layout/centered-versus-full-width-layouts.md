## Centered versus full-width layouts

Both centered and full-width layouts are effective in different situations. The right choice will depend on the specific needs of your app.

### Centered layouts

![Centered layouts](./assets/layout-centered-light.webp)

Centered layouts restrict the width of the main content and center it on the page. Use the centered layout if your app has lots of reading content, such as text-heavy articles or documentation.

When using the centered layout, restrict the main content to 960px, which corresponds with our breakpoint token for the maximum width of tablet screens.

### Full-width layouts

![Full-width layouts](./assets/layout-full-width-light.webp)

Full-width layouts don't restrict the width of the main content. Use the full-width layout for data-heavy apps where the primary focus is displaying large amounts of data.
