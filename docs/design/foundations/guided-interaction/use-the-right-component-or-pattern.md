## Use the right component or pattern

Before anything else, check that your app has an app help menu. It's mandatory for every Dynatrace app, and it's where users look for app-level help: onboarding, documentation, release notes, keyboard shortcuts, and a way to give feedback. See [HelpMenu](https://developer.dynatrace.com/design/components/layouts/HelpMenu.md).

| **Component or pattern**                                                                                        | **Purpose** | **When to use**                                                 | **When not to use**                                  |
| --------------------------------------------------------------------------------------------------------------- | ----------- | --------------------------------------------------------------- | ---------------------------------------------------- |
| [Microguide](https://developer.dynatrace.com/design/components/content/Microguide/usage.md)                     | Onboarding  | Walk users through an app or feature in a few steps             | Basic functionality, or to fix a confusing UI        |
| [Dismissible card](https://developer.dynatrace.com/design/components/layouts/Surface/usage.md#dismissible-card) | Onboarding  | Announce something that isn't visible in the UI                 | Critical information, or anything users must revisit |
| [FeatureHighlight](https://developer.dynatrace.com/design/components/content/FeatureHighlight/usage.md)         | Onboarding  | Draw attention to one specific feature                          | Product tours, or anything users must revisit        |
| [Tooltip](https://developer.dynatrace.com/design/components/overlays/Tooltip/usage.md)                          | Inline help | Name actions, explain something briefly, or show truncated text | Longer text, links, or critical information          |
| [InformationOverlay](https://developer.dynatrace.com/design/components/content/InformationOverlay/usage.md)     | Inline help | Explain an element whose purpose isn't obvious                  | Temporary error states, or required input            |
| [TerminologyOverlay](https://developer.dynatrace.com/design/components/content/TerminologyOverlay/usage.md)     | Inline help | Define a technical term inline                                  | Terms most users know, or anything but a definition  |
| [ExpandableText](https://developer.dynatrace.com/design/components/content/ExpandableText.md)                   | Inline help | Offer more detail where space is tight                          | Content users need to understand or decide           |
| [Placeholders and hints](https://developer.dynatrace.com/design/patterns/forms-validation.md#placeholders)      | Inline help | Show the expected format for an input field                     | As a replacement for a label                         |
| [ExternalLink](https://developer.dynatrace.com/design/components/typography/ExternalLink/usage.md)              | Inline help | Send users to a resource outside the platform                   | Critical information, or mid-flow                    |
| [KeyboardShortcut](https://developer.dynatrace.com/design/components/content/KeyboardShortcut/usage.md)         | Inline help | Show the keys for an often-repeated action                      | Uncommon actions, or mobile and touch views          |
