## Status related components

### HealthIndicator

[HealthIndicators](https://developer.dynatrace.com/design/components/content/HealthIndicator/index.mdx/) allow you to quickly communicate the **status of a system, process, or object in a subtle and accessible way**. They either come with a shape or icon as visual. For more details, see the [HealthIndicator usage guidelines](https://developer.dynatrace.com/design/components/content/HealthIndicator/usage.mdx/).

![Examples of HealthIndicators that show the staus of a system, process or object](./assets/status-and-health-healthindicator-light.webp)

### Chip

[Chips](https://developer.dynatrace.com/design/components/content/Chip/index.mdx/) allow you to **prominently tag objects or processes** to inform users about their status. For more details, see the [Chip usage guidelines](https://developer.dynatrace.com/design/components/content/Chip/usage.mdx/).

![Example of Chips in multiple colors that are used for visualizing statuses](https://developer.dynatrace.com/assets/images/status-and-health-chips-light-f5637bd869811ab58bd65201485fbb22.webp)

### MessageContainer

[MessageContainers](https://developer.dynatrace.com/design/components/content/MessageContainer/index.mdx/) allow you to communicate important **conditions, statuses, or changes related to the current section or page**. For more details, see the [MessageContainer usage guidelines](https://developer.dynatrace.com/design/components/content/MessageContainer/usage.mdx/).

![An example of a primary colored MessageContainer that has a title and description](https://developer.dynatrace.com/assets/images/status-and-health-messagecontainer-light-c3e53bfec73af775053240c63b07bfa1.webp)

### Toast

[Toasts](https://developer.dynatrace.com/design/components/notifications/Toast/index.mdx/) allow you to **notify users about a status change**. For more details, see the [Toast usage guidelines](https://developer.dynatrace.com/design/components/notifications/Toast/usage.mdx/).

![Example of a toast component that informs about a successful process](https://developer.dynatrace.com/assets/images/status-and-health-toast-light-1b61506448eade2077b608e55bc0be3c.webp)

### InformationOverlay

[InformationOverlays](https://developer.dynatrace.com/design/components/content/InformationOverlay/index.mdx/) allow you to **add detailed status information in a contextual overlay**. The trigger is usually a status-indicating icon with a label. For more details, see the [InformationOverlay usage guidelines](https://developer.dynatrace.com/design/components/content/InformationOverlay/usage.mdx/).

![Example of an information overlay that shows status details](https://developer.dynatrace.com/assets/images/status-and-health-informationoverlay-light-8c95096d09a26f200bdab2ac9e950e1e.webp)
