The content in this section describes best practices for composing great UIs and user experiences for Dynatrace, using the Strato Design System.

- [AI presence](https://developer.dynatrace.com/design/patterns/ai-presence.md): Learn how to show artificial intelligence (AI) in Dynatrace.
- [App naming guidelines](https://developer.dynatrace.com/design/patterns/app-naming-guidelines.md): Learn the basic rules for naming new Dynatrace Apps.
- [App structure](https://developer.dynatrace.com/design/patterns/app-structure.md): Discover how to design the base structure of a Dynatrace App.
- [Common actions](https://developer.dynatrace.com/design/patterns/common-actions.md): Discover the design and content patterns to use for common actions throughout Dynatrace.
- [Error messages](https://developer.dynatrace.com/design/patterns/error-messages.md): Write clear, actionable error messages for Dynatrace. Covers component selection, effective writing principles, severity levels, and placement guidance.
- [Filtering](https://developer.dynatrace.com/design/patterns/filtering.md): Get an overview of Strato's filter components and best practices for building filtering experiences.
- [Forms and validation](https://developer.dynatrace.com/design/patterns/forms-validation.md): Learn best practices for creating forms in Dynatrace Apps.
- [Loading and saving](https://developer.dynatrace.com/design/patterns/loading-saving.md): Discover how to show loading and saving states in Dynatrace.
- [Status and health](https://developer.dynatrace.com/design/patterns/status-and-health.md): Discover how to show a system's health status visually in Dynatrace Apps.
