The `CategoricalBarChart` visually displays the frequencies or values of distinct categories using rectangular bars. Each bar's length or height corresponds to the quantity or value associated with a specific category, making it easy to compare the relative differences among categories.

**`CategoricalBarChartProps`**

| Prop                  | Type                                                         | Default                                         | Description                                                                                                                                                                       |
| --------------------- | ------------------------------------------------------------ | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data` (required)     | `CategoricalBarChartData[]`                                  |                                                 | Data object for the categorical bar chart                                                                                                                                         |
| `height`              | `number \| string`                                           | `300px`                                         | Chart height. When a number is specified, is considered as pixels, otherwise a valid height string is expected.                                                                   |
| `width`               | `number \| string`                                           | `100%`                                          | Chart width. When a number is specified, it's treated as pixels, otherwise a valid width string is expected.                                                                      |
| `layout`              | `Layout`                                                     | `'vertical'`                                    | Whether the bars are displayed in a 'vertical' or 'horizontal' layout.                                                                                                            |
| `groupMode`           | `GroupMode`                                                  | `'stacked'`                                     | Strategy used for grouping the bars within a category. "stacked" will mount one on top of each other, and "grouped" will place one next to the other                              |
| `colorPalette`        | `ColorPalette \| CustomColorPalette`                         | `"categorical"`                                 | Color palette to be used for the bar category.                                                                                                                                    |
| `valueRepresentation` | `ValueRepresentation`                                        | `"absolute"`                                    | The way values are represented. "absolute" will display the value as it is, and "relative" displays a percentage value considering the other dimensions values within a category. |
| `seriesActions`       | `(series: Record<string, unknown>) => SeriesActionsTemplate` |                                                 | Category actions to be shown in the legend and tooltip actions                                                                                                                    |
| `truncationMode`      | `TruncationMode`                                             | `'middle'`                                      | Truncation mode to use (start, middle, end) Applied to all the parts that truncate text.                                                                                          |
| `colorPaletteMode`    | `ColorPaletteMode`                                           | `"single-color" - each bar gets the same color` | Mode in which bars are colored when single dimension data is shown                                                                                                                |
| `loading`             | `boolean`                                                    | `false`                                         | Show the loading indicator when truthy.                                                                                                                                           |
