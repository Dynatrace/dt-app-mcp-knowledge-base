## CategoricalBarChart.Tooltip

To configure the tooltip, add `CategoricalBarChart.Tooltip` to the categorical bar chart.

**`CategoricalBarChartTooltipProps`**

| Prop                 | Type                             | Default | Description                                                                                                     |
| -------------------- | -------------------------------- | ------- | --------------------------------------------------------------------------------------------------------------- |
| `variant` (required) | `CategoricalChartTooltipVariant` |         | Tooltip variant. 'single' displays only the closest category, and 'grouped' all the category within a category. |
