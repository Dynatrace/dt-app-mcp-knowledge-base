## TimeseriesChart.XAxis

To configure the x-axis, add `TimeseriesChart.XAxis` to the time series chart.

**`TimeseriesChartXAxisProps`**

| Prop    | Type                           | Default | Description                                                                                                                                  |
| ------- | ------------------------------ | ------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `max`   | `number \| DateString \| Date` |         | The maximum point in time for the X axis. It can either be: a number representing a timestamp, an ISO8601-compliant string, or a Date object |
| `min`   | `number \| DateString \| Date` |         | The minimum point in time for the X axis. It can either be: a number representing a timestamp, an ISO8601-compliant string, or a Date object |
| `label` | `string`                       |         | The label to display alongside the axis.                                                                                                     |
