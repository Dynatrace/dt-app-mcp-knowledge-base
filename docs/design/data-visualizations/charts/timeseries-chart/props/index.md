The `TimeseriesChart` visually represents data in sequential order of time. It's used to observe trends, patterns, and fluctuations in the data over a specific time period.

**`TimeseriesChartProps`**

| Prop                  | Type                                                                                                         | Default         | Description                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------ | --------------- | ------------------------------------------------------------------------------------------------------------ |
| `data`                | `Timeseries[]`                                                                                               |                 | The series data passed to the chart                                                                          |
| `height`              | `number \| string`                                                                                           | `300px`         | The height of the chart. If a number is passed, it will be treated as px.                                    |
| `width`               | `number \| string`                                                                                           | `100%`          | Chart width. When a number is specified, it's treated as pixels, otherwise a valid width string is expected. |
| `variant`             | `ChartVariant`                                                                                               | `'line'`        | Variant to configure the type of chart                                                                       |
| `seriesActions`       | `(timeseries: unknown, datapoint?: TimeseriesDatapoint \| TimeseriesBandDataPoint) => SeriesActionsTemplate` |                 | Exposed callback to display series actions for a series                                                      |
| `onMessage`           | `(messages: ChartMessage[]) => void`                                                                         |                 | Messages emitted by the chart.                                                                               |
| `gapPolicy`           | `TimeGapPolicy`                                                                                              |                 | The gap policy to be applied to all series of the chart                                                      |
| `pointsDisplay`       | `PointsDisplay`                                                                                              | `'auto`         | Show the datapoints always, never or based on a threshold amount.                                            |
| `valueRepresentation` | `ValueRepresentation`                                                                                        |                 | The value representation to be used, either absolute or relative                                             |
| `loading`             | `boolean`                                                                                                    | `false`         | Show the loading indicator when truly.                                                                       |
| `colorPalette`        | `ColorPalette \| CustomColorPalette`                                                                         | `'categorical'` | Color palette that will be applied to the chart.                                                             |
| `truncationMode`      | `TruncationMode`                                                                                             | `'middle'`      | Truncation mode to use (start, middle, end) Applied to all the parts that truncate text.                     |
| `curve`               | `SeriesCurve`                                                                                                | `'linear'`      | Defines the curve shape of the series                                                                        |
| `infiniteZoom`        | `boolean`                                                                                                    | `'false'`       | Enables infinite zooming                                                                                     |
| `children`            | `ReactNode`                                                                                                  |                 |                                                                                                              |
