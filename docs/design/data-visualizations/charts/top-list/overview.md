## Overview

A `TopList` is a chart that displays a ranked list of items as horizontal bars with a label inside each bar—essentially a horizontal bar chart optimized for showing top-N rankings. For full control over axis configuration, coloring rules, or layout direction, use [XYChart.BarSeries](https://developer.dynatrace.com/design/data-visualizations/charts/XYChart-BarSeries.md#top-list-configuration) directly.
