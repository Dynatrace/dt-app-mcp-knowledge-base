**`TopListProps`**

| Prop                       | Type                                                | Default          | Description                                                                                                                                                                                      |
| -------------------------- | --------------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `data` (required)          | `Data[]`                                            |                  | Records to display as ranked bars. Sorted by \`valueAccessor\` descending unless a custom \`comparator\` is provided. Index-keyed internally before being forwarded to the underlying chart.     |
| `height`                   | `number \| string`                                  | `300px`          | Chart height. When a number is specified, it's treated as pixels, otherwise a valid CSS height string is expected.                                                                               |
| `width`                    | `number \| string`                                  | `100%`           | Chart width. When a number is specified, it's treated as pixels, otherwise a valid CSS width string is expected.                                                                                 |
| `colorPalette`             | `ChartColorPalette`                                 | `'categorical'`  | Color palette for the chart.                                                                                                                                                                     |
| `loading`                  | `boolean`                                           | `false`          | Show the loading indicator when truthy.                                                                                                                                                          |
| `truncationMode`           | `TruncationMode`                                    | `'middle'`       | Truncation mode applied to bar labels.                                                                                                                                                           |
| `labelAccessor` (required) | `string`                                            |                  | Accessor for the text rendered inside each bar.                                                                                                                                                  |
| `valueAccessor` (required) | `string`                                            |                  | Accessor for the numerical value that determines bar width.                                                                                                                                      |
| `valueFormatter`           | `Formatter \| FormatOptions<Unit, ConvertibleUnit>` |                  | Formats numerical values shown in tooltips and Y-axis tick labels.                                                                                                                               |
| `comparator`               | `(a: Data, b: Data) => number`                      |                  | Custom comparator function for sorting data items. When omitted, data is sorted by value in descending order.                                                                                    |
| `actions`                  | `(datapoint: Data) => SeriesActionsTemplate`        |                  | Callback that returns the series action menu for the hovered bar. Return a \`\<ChartSeriesAction>\` tree (or a \`Promise\` of one for async menus).                                              |
| `colorPaletteMode`         | `ColorPaletteMode`                                  | `'single-color'` | Controls how the color palette is applied to bars. - \`'single-color'\`: all bars share the same color from the palette. - \`'multi-color'\`: each bar gets a sequential color from the palette. |
| `children`                 | `ReactNode`                                         |                  | Slot children forwarded to the internal \`XYChart\`.                                                                                                                                             |
