## AnnotationsChart.Track

**`AnnotationsTrackProps`**

| Prop     | Type        | Default | Description                                                                                                                                                                                                |
| -------- | ----------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `color`  | `string`    |         | Defines the marker background for all the markers inside a track, supporting any valid CSS color. It will be overridden by any particular marker that has color prop defined.                              |
| `label`  | `string`    |         | The track label                                                                                                                                                                                            |
| `symbol` | `ReactNode` |         | Defines the marker symbol for all the markers inside a track, which can be a letter, an emoji, an icon or a Unicode character It will be overridden by any particular marker that has symbol prop defined. |
| `hidden` | `boolean`   | `false` | Specify whether a track should hide.                                                                                                                                                                       |
