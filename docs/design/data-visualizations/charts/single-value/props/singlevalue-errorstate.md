## SingleValue.ErrorState

`SingleValue.ErrorState` provides a subcomponent where the Error state wrapper can be set.

**`ErrorStateProps`**

| Prop                  | Type                                                   | Default | Description |
| --------------------- | ------------------------------------------------------ | ------- | ----------- |
| `children` (required) | `ReactNode \| ((errorMessage: string) => JSX.Element)` |         |             |
