## Borders.Width

| Name                       | Value | CSS variable                    | Description                                                               |
| -------------------------- | ----- | ------------------------------- | ------------------------------------------------------------------------- |
| `Borders.Width.Default`    | `1px` | `--dt-borders-width-default`    | Use as the default border width.                                          |
| `Borders.Width.Emphasized` | `2px` | `--dt-borders-width-emphasized` | Use to emphasize borders. This can be useful to clearly separate content. |
