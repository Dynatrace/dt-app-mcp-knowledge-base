## Borders.Style

| Name                    | Value    | CSS variable                 | Description                       |
| ----------------------- | -------- | ---------------------------- | --------------------------------- |
| `Borders.Style.Default` | `solid`  | `--dt-borders-style-default` | Use as the default border style.  |
| `Borders.Style.Dashed`  | `dashed` | `--dt-borders-style-dashed`  | Use to indicate interactive text. |
