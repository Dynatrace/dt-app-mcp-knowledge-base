## BoxShadows.Surface.Flat

Surfaces are flat by default and do not have any shadow.

| Name                             | Value                                                                         | CSS variable                           | Description                                                                                 |
| -------------------------------- | ----------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------- |
| `BoxShadows.Surface.Flat.Rest`   | `0px 0px 0px 1px #eaeaed`                                                     | `--dt-box-shadows-surface-flat-rest`   | Use as the default level of elevation.                                                      |
| `BoxShadows.Surface.Flat.Hover`  | `0px 1px 2px #3838420d, 0px 4px 8px -2px #38384212, 0px 0px 0px 1px #eaeaed`  | `--dt-box-shadows-surface-flat-hover`  | Use as the default level of elevation when a user's pointer is over an interactive surface. |
| `BoxShadows.Surface.Flat.Active` | `0px 0px 0px 1px #eaeaed`                                                     | `--dt-box-shadows-surface-flat-active` | Use as the default level of elevation when the user is pressing an interactive surface.     |
| `BoxShadows.Surface.Flat.Drag`   | `0px 1px 2px #3838420d, 0px 7px 17px -2px #38384252, 0px 0px 0px 1px #eaeaed` | `--dt-box-shadows-surface-flat-drag`   | Use as the default level of elevation when moving a surface, on drag-and-drop interaction.  |
