## BoxShadows.Surface.Floating

Floating surfaces have a noticeable shadow, and are used in elements that overlay other content.

| Name                                 | Value                                                                         | CSS variable                               | Description                                                        |
| ------------------------------------ | ----------------------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------ |
| `BoxShadows.Surface.Floating.Rest`   | `0px 1px 2px #3838420d, 0px 5px 11px -2px #38384229, 0px 0px 0px 1px #eaeaed` | `--dt-box-shadows-surface-floating-rest`   | Use for floating surfaces.                                         |
| `BoxShadows.Surface.Floating.Hover`  | `0px 1px 2px #3838420d, 0px 6px 14px -2px #3838423d, 0px 0px 0px 1px #eaeaed` | `--dt-box-shadows-surface-floating-hover`  | Use when a user's pointer is over an interactive floating surface. |
| `BoxShadows.Surface.Floating.Active` | `0px 1px 2px #3838420d, 0px 5px 11px -2px #38384229, 0px 0px 0px 1px #eaeaed` | `--dt-box-shadows-surface-floating-active` | Use when the user is pressing an interactive floating surface.     |
| `BoxShadows.Surface.Floating.Drag`   | `0px 1px 2px #3838420d, 0px 7px 17px -2px #38384252, 0px 0px 0px 1px #eaeaed` | `--dt-box-shadows-surface-floating-drag`   | Use when moving a floating surface, on drag-and-drop interaction.  |
