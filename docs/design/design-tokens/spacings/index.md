Spacings define the distances between elements. Use to style gaps, paddings, and margins. The scale follows a non-linear progression that starts with an increase of 2px, grows to 4px, and finally 8px.

```ts
import Spacings from '@dynatrace/strato-design-tokens/spacings';
```
