## Semantic meaning

Before you use an icon, make sure its semantic meaning fits your use case: select the icon in the [Functional icons library](https://public-developer.central.internal.dynatrace.com/design/icons/functional-icons.md) to read the icon description and tags.

Never use the same icon for unrelated purposes, as that would dilute its meaning and confuse users.
