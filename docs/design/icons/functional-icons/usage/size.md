## Size

The icons come in three predefined sizes which are set using the `size` prop:

- Default (20px) - Pairs best with `Typography.Text.Base` tokens. This is the
  size to use in most cases.
- Small (16px) - Pairs best with `Typography.Text.Small` tokens. Use this size
  when space is limited.
- Large (32px) - Use sparingly for thumbnails, headers, or other prominent
  placements.

Use the predefined sizes to maintain consistency. If your use case absolutely
requires a different size, you can pass a custom pixel value to the `size` prop.
