## Position

### Prefix slot

Place the icon in front of the label (prefix slot) if it represents and
clarifies the label itself.

![Asset explanation](https://developer.dynatrace.com/assets/images/functional-icon-guidelines-prefix-light-2dccf1004c75fe2e5adbf237b5d05e30.webp)

### Suffix slot

Place the icon after the label (suffix slot) if it indicates additional
functionality or extra information beyond the label.

![Asset explanation](https://developer.dynatrace.com/assets/images/functional-icon-guidelines-suffix-light-4a63bc14d08ba3bd8ae5019cc4761267.webp)
