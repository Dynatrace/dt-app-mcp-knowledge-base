## Position

### Prefix slot

Place the icon in front of the label (prefix slot) if it represents and clarifies the label itself.

![Asset explanation](https://public-developer.central.internal.dynatrace.com/assets/images/functional-icon-guidelines-prefix-light-a327112bdb4bdd0ac53accbf571cb670.webp)&#x20;

### Suffix slot

Place the icon after the label (suffix slot) if it indicates additional functionality or extra information beyond the label.

![Asset explanation](https://public-developer.central.internal.dynatrace.com/assets/images/functional-icon-guidelines-suffix-light-bcf611a942ab5a474f5f72fa3da50269.webp)&#x20;
