## Special use cases

| Icon                                                                                           | Usage                                                                                                                                                                              |
| ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ![Filled icons](./icons-docs-assets/functional-icon-guidelines-LocationMarkerIcon-light.webp)  | **Outlined icons:** Use this default style everywhere in the interface except the geospatial map.                                                                                  |
| ![Filled icons](./icons-docs-assets/functional-icon-guidelines-ShipFilledIcon-light.webp)      | **Filled icons:** Use on the geospatial map or to indicate a selected state, as with the Favorite icon.                                                                            |
| ![Subscript icons](./icons-docs-assets/functional-icon-guidelines-Subscript-light.webp)        | **Subscripted icons:** Use on the geospatial map to point to a specific place. Icon starts at the bottom of the grid.                                                              |
| ![Filled icons](./icons-docs-assets/functional-icon-guidelines-ArrowRightIcon-light.webp)      | **Arrows:** Use to link to other pages within the product or to show direction or trends.                                                                                          |
| ![Filled icons](./icons-docs-assets/functional-icon-guidelines-ChevronRightIcon-light.webp)    | **Chevrons:** Use to indicate expandable and collapsable components in a list or dropdown, option to navigate to the next or previous step, view overflow items, or expand a tree. |
| ![Filled icons](./icons-docs-assets/functional-icon-guidelines-OptionsIcon-light.webp)         | **Options:** Use for configurations that only influence a selected area and preferences.                                                                                           |
| ![Filled icons](./icons-docs-assets/functional-icon-guidelines-SettingIcon-light.webp)         | **Settings:** Use for platform-wide configurations, for example, to change defaults.                                                                                               |
| ![Filled icons](./icons-docs-assets/functional-icon-guidelines-ExternalLinkIcon-light.webp)    | **External link:** Use for external links, which open apps or pages outside of the Dynatrace product.                                                                              |
| ![Filled icons](./icons-docs-assets/functional-icon-guidelines-LinkIcon-light.webp)            | **Link:** Use for links.                                                                                                                                                           |
| ![Filled icons](./icons-docs-assets/functional-icon-guidelines-ShareIcon-light.webp)           | **Share:** Use to share with other people or apps, or to see more share options.                                                                                                   |
| ![Filled icons](./icons-docs-assets/functional-icon-guidelines-GroupIcon-light.webp)           | **Group:** Use to share with a group of people.                                                                                                                                    |
