## Outlined or filled

Functional icons come in outlined and filled versions. Each version serves a
different purpose.

**Outlined icons** have a light, clean style that works well in dense UIs with
plain backgrounds. Use the outlined icon style for basic interface elements,
such as buttons, navigation, and toolbars.

**Filled icons** are designed specifically for use on geospatial maps. They have
a bold, solid appearance that ensures visibility against complex map
backgrounds.

The outlined and filled versions of certain icons, such as the Favorite icon,
can also be used to represent states.
