Functional icons visually highlight key functionalities. Used well, they can
reduce clutter and help users easily understand the interface and their options.

To use a functional icon, import it as a component from the
`@dynatrace/strato-icons` library. See [Usage](https://developer.dynatrace.com/design/icons/functional-icons/usage.md) for guidance on
style, placement, size, accessibility, and more.
