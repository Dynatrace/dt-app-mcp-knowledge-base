# Contributing

## What to contribute

Most content in this repository (`meta.json`, `index.json`, `docs/`) is
generated by the preprocessing pipeline and will be overwritten on the next
run. Contributions to generated files are out of scope.

Meaningful contributions include:

- Bug fixes or improvements to the preprocessing pipeline under `preprocessing/`
- Schema changes to `schemas/`
- Documentation improvements

## Getting started

Node 24 or newer is required. All npm scripts run from `preprocessing/`.

```sh
cd preprocessing
npm install
npm test
npm run typecheck
npm run lint
```

See [AGENTS.md](AGENTS.md) for the conventions this repository expects from
automated agents.

## Pull requests

- Open an issue first for non-trivial changes so the approach can be agreed on.
- Keep pull requests focused; one logical change per PR.
- Ensure `npm test`, `npm run typecheck` and `npm run lint` pass before opening a PR.
- Changes to `.github/workflows/` are checked by [actionlint](https://github.com/rhysd/actionlint). To run it locally, install the binary (see its [install guide](https://github.com/rhysd/actionlint/blob/main/docs/install.md)) and run `actionlint` from the repository root.
- Every PR must contain exactly one commit.

## Code of conduct

Be respectful. Constructive feedback is welcome; personal attacks are not.
